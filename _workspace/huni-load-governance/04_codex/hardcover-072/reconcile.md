## 2. 불일치 → 조사 후 수렴 (관찰 2건 심각도)

### 불일치-A · O-2 부모 print_opt (codex 가설3 DISAGREE)
- **Claude**: 컨펌큐 Low — UI 전파 예외 가능성·처분 아님.
- **codex**: §3-4 실질 위반 후보 → Low 과소평가·"UI 전파 계약 확인 전 BLOCKED"로 격상.
- **라이브/규범 판정**:
  - 규범 §3-4 문언(셋트 부모 도수/인쇄옵션 **금지**) 그대로면 부모 072의 POPT_001/002는 **위반이 맞다** → codex 지적 타당, Claude의 "Low"는 과소평가.
  - 단 내지 284도 동일 보유 = 도수축이 인쇄 구성원에 실재 → [[postcard-book-sim-convergence-260702]] siz_cd 전파 계층과 동형(부모=손님선택 UI 전파 계층) 가능성 높음.
  - codex의 "BLOCKED" 용어는 **부정확**: BLOCKED는 가격종속 **옵션** 처분어인데, print_opt는 옵션이 아니라 **기준정보(도수) 레이어** → 본 옵션 감사(Phase 2)의 처분 대상이 애초에 아니다.
- **수렴 채택**: O-2 심각도 **Low → Medium**(codex 격상 채택). 단 처분 아님 — **규범 §3-4 예외 조항 보강 여부 + 셋트 UI print_opt 전파 계약 확인**으로 라우팅(규범 큐럼레이터 §1 / §23 셋트 트랙). **즉시 제거 금지**(오차단 0 — 손님이 단면/양면 못 고르면 매출 손실, 양측 합의).

### 불일치-B · O-1 면지 멤버 074/075/076 (codex 가설1·4 부분AGREE)
- **Claude**: O-1 컨펌큐 Low — 빈 껍데기·무해·지금 처분 금지·latent 합산 위험 기록.
- **codex**: latent RETIRE 후보/조건부 멤버 모델 미완성·"완전 정상" 표현은 안일·Low보다 강한 구조정리 필요.
- **라이브/규범 판정**:
  - 라이브 확증: 멤버 3종 전 바인딩 0(색 자재조차 없음) → codex의 "빈 껍데기·미완성" 사실 정확.
  - **범위 정정**: 074/075/076은 셋트 **구성원(t_prd_product_sets)**이지 **옵션이 아니다** → Phase 2 옵션 감사에서 "옵션 미보유=해당없음"으로 처리한 것은 정확. 멤버 구조 결함은 **§23 셋트 설계 트랙 소관**이지 옵션 거버넌스 처분 대상이 아니다(codex가 옵션/셋트구조 범위를 일부 혼동).
  - 방향은 실질 동일: 양측 모두 "지금 삭제 금지". Claude가 이미 O-1에 latent 위험을 명시했고 codex가 심각도만 격상.
- **수렴 채택**: O-1 심각도 **Low → Medium**(codex 격상 채택). 처리 방향 구체화 = **§23 셋트 트랙**에서 택일: ① 옵션 선택색만 멤버로 포함하는 조건부 구성(옵션↔멤버 연결) or ② 멤버 3종 제거하고 색은 옵션 전담. **지금 처분 금지**(오차단 0·동작 검증된 셋트·§23 PRICE≠0 골든 무손상). 옵션 감사 처분 판정(KEEP×3)은 **불변**.

- **옵션 레이어 처분**: **전건 KEEP×3·RETIRE/MOVE/EXTEND/BLOCKED 0건 — 확정**(codex 독립 재판정으로 재확인·divergence 0).
- **가격종속 N·BLOCKED 불필요**: **확정**(라이브 무가격 실측 + codex AGREE).
- **정정 2건**(codex 지적 채택): O-1·O-2 심각도 **Low → Medium** 격상 + 처리 방향 구체화. 단 **처분 등급은 불변**(둘 다 옵션 레이어 처분 아님·즉시 제거 금지·오차단 0).
- **codex "BLOCKED 격상"(가설3) 용어 정정**: print_opt는 옵션 아님 → BLOCKED 부적용. §3-4 규범 보강 + 셋트 트랙 라우팅으로 대체.
- **후속 큐**: ① O-2 §3-4 예외 조항 보강 여부(규범) ② O-1 멤버 구조 §23 셋트 트랙 택일 ③ OPT_064 work-order 경로 검증(codex 단독).
- **가격 무손상 최종 잣대**: §23 evaluate_set_price PRICE≠0·이중합산 0 골든 정합 — 본 reconcile은 이를 깨는 판정 0(전건 KEEP·처분 0). **LG5 셋트 정합 GO 방향**.

**독립성 확인**: codex에 Claude의 처분 결론을 노출하지 않고 원자료로 독립 재도출 요청 → 옵션 본체는 합의 수렴(고신뢰), 불일치는 관찰 심각도에만 국한. codex가 정상 배치(옵션·자재)를 결함으로 오판(FP)한 건 없고, 오히려 FP를 경고. 라이브 반증 필요 사례 0.
