## 횡단 원칙 (전 단계 공통)

1. **결정론 우선, LLM은 의미 부여만** — 반복·수치 작업은 스크립트(토큰 0), LLM은 의미 판단·모호 해소·예외만. LLM에게 큰 표를 통째로 주지 말고 구조 앵커(머리글·경계·타입 전이)만 압축 투입. [학술 권고 1·4, LLM 연구: 코드 실행이 토큰 98%+ 절감]
2. **LLM은 숫자를 절대 전사·계산하지 않는다 [HARD]** — 자릿수·연쇄 계산에서 정확도 붕괴가 실증됨. 값 이동은 100% 스크립트, 계산은 엔진/DB.
3. **생성≠검증 [HARD]** — 만든 에이전트와 다른 에이전트가 직접 재실측으로만 판정. 가능하면 다른 모델 계열(codex 등) 독립 2차 병행(외부 주장=가설).
4. **대표 파일럿→동형 전파** — 시트/상품군 1개를 종단 완주해 정답 매핑을 확립한 뒤 같은 모양에 전파(FlashRelate 예시기반 전파의 실전형).
5. **종료척도 선정의 [HARD]** — "권위 셀 반영 누락 0 + 대사 차이 0 + 골든 표본 재현 오차 0" 같은 수치 기준을 2단계에서 선언. 없으면 분석만 무한 반복(이 레포 최대 시행착오).
6. **silent 금지** — 매핑 없는 값·타입 오류·미추출 시트를 조용히 건너뛰지 않는다. 전건 사유 명시. 합계 일치가 셀 오배선을 은폐할 수 있으니 표본 셀 대조 병행.
7. **되돌릴 수 있게** — 백업·DRY-RUN·undo·논리삭제·인간 승인 없이 운영 쓰기 금지.

## 연구가 경고한 함정 (요약)

- 엑셀 통째 LLM 투입 = 토큰 폭발 (SpreadsheetLLM)
- LLM 스키마/FK 추론 환각 → 프로파일링으로 후보를 데이터에서 확정 후 LLM은 판단만
- 병합셀·소계(GroupHeader)·계산셀(Derived)을 데이터로 오적재 → 셀 역할 태깅 선행
- 매트릭스 미전개 = 차원 붕괴 (명함 자재·아크릴 실증)
- 엑셀 타입 자동강제 = 코드값 유실 (업계 COVID 사건)
- DRY-RUN 통과·합산 일치 ≠ 값 정합 (교차 상쇄 은폐)
- 단가행 존재 ≠ 배선 완료 (고아 구성요소→견적 0)
- fuzzy 병합 false-positive = 의미구분 파괴 (작업 vs 재단 사이즈)
