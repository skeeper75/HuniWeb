## 3. 건별 판정

### A. A4 — `SIZ_000172` vs `SIZ_000258` 🔴 라이브 과다청구

`SIZ_000172` 는 이름이 `A4(210x297mm)` 인데 **작업치수가 290×377** 이다(A4 + 사방 40mm).
이름과 값이 어긋난 코드다. 살아있는 사용처가 정확히 둘이고, **둘이 서로 다른 것을 원한다**:

| 사용처 | 무엇으로 쓰나 | 판형 환산 쓰나 | 290×377 이 맞나 |
|---|---|---|---|
| `PRD_000132` 레더아트액자 | 상품 사이즈 + edicus 템플릿 + `TMPL-000129`(`dim_sels`) | ✗ (`use_dims=["siz_cd","min_qty"]`) | **맞다** — 액자 실작업 크기로 보인다 |
| `PRD_000286` 하드커버 링책자-내지 | 상품 사이즈(A4 내지) | **✓** (`COMP_PAPER`·`COMP_PRINT_DIGITAL_S1` 둘 다 `use_dims` 에 `plt_siz_cd`) | **틀렸다** — 내지 A4 는 210×297 |

실측(`prd286_pansu.txt`) — 판형은 `SIZ_000499` 국4절:

| PRD_000286 사이즈 | work | `fn_calc_pansu` |
|---|---|---:|
| `SIZ_000007` A5 148x210 | 150×212 | 4 |
| `SIZ_000380` B5 182x257 | 182×257 | 2 |
| **`SIZ_000172` A4** | **290×377** | **1** ← A4 가 B5 보다 적다 |

정상값은 **2판**이다(`SIZ_000258` 210×297 → 306×457 에 회전배치 1×2). `pricing.py:264`
`plate_qty = ⌈qty ÷ pansu⌉` 이므로 **판수가 절반이면 청구 판수가 정확히 2배**가 된다.
`COMP_PAPER` 는 판당 단가(예: `MAT_000072` 30.73원/판, `plt_siz_cd='SIZ_000499'`)라
**용지비·디지털인쇄비가 그대로 2배 과다청구**된다. `PRD_000286` 은 `use_yn='Y'` — 게시 중이다.

**교정 명세**
1. `PRD_000286` 의 A4 사이즈를 `SIZ_000172` → `SIZ_000258` 로 교체(상품 사이즈 재배선).
   `SIZ_000258` 은 이미 이 DB 의 A4 정본이다 — 스티커 낱장완칼(PRD_000055·056)도
   `SIZ_000172` → `SIZ_000258` 로 이미 이관을 마쳤다(172 행이 `del_yn='Y'`).
2. `SIZ_000172` 는 **논리삭제하지 않는다** — 레더아트액자가 살아서 쓴다.
   대신 **이름을 값에 맞게 교정**한다: `A4(210x297mm)` → `레더아트액자 A4 (작업 290x377)`.
   이름만 바꾸는 것이므로 `TMPL-000129`·edicus 템플릿 참조는 코드 기준이라 안 깨진다.
3. ⚠ 선행 확인: `SIZ_000258` 이 `PRD_000286` 의 A4 단가행과 매칭되는지
   (`COMP_PAPER`·`COMP_PRINT_DIGITAL_S1` 는 `siz_cd` 를 안 쓰고 `plt_siz_cd` 만 쓰므로
   사이즈 교체가 단가 매칭을 깨지 않는다 — 판수만 1→2 로 바뀐다). 적용 전 시뮬레이터 재확인.

### B. 94x94 — `SIZ_000036` vs `SIZ_000064` 🟢 중복이 아니다

권위 「판걸이수」 시트가 둘을 **따로 적는다**:

```
r41  94 x 94 mm - 기본형   94x94  여분 2.0  작업 98x98    인쇄배경지  판걸이 12  316x467  사방 5mm제외
r42  94 x 94 mm - 커팅형   94x94  여분 5.0  작업 104x104  인쇄배경지  판걸이  8  316x467  좌우6/상13/하16 제외
```

라이브가 이걸 그대로 담고 있다 — `SIZ_000036`=98×98(여분 2), `SIZ_000064`=104×104(여분 5).
쓰는 상품도 각각이다: `PRD_000043 인쇄배경지(일반형)` ↔ `SIZ_000036`,
`PRD_000044 인쇄배경지(커팅형)` ↔ `SIZ_000064`. **재단치수가 같을 뿐 작업치수가 다른, 서로 다른 상품의
서로 다른 사이즈**다.

판수도 권위와 정확히 맞는다:
- `SIZ_000036` 98×98 → 316x467 사방 5mm(306×457): `⌊306/98⌋×⌊457/98⌋ = 3×4 = 12` ✓ r41
- `SIZ_000064` 104×104 → 커팅형 여백(304×438): `⌊304/104⌋×⌊438/104⌋ = 2×4 = 8` ✓ r42

**교정 명세**: 통합·논리삭제 **하지 않는다**. 결함은 이름 오타 하나뿐 —
`94x94mmm` → `94x94mm-커팅형`. `SIZ_000036` 이름도 `94x94mm-기본형` 으로 맞추면 헷갈림이 준다.

> 카드의 「94x94 중복」 전제는 재단치수만 보고 세운 것이다. FINDINGS 부수문제와
> `pansu_check.md` §5 도 같은 전제였다 — 이 항목은 **정정**이 필요하다.

### D. `SIZ_000518`(100x148) · `SIZ_000519`(90x110) 🔴 처분 대상이 아니다

카드는 「고아 단가 576행 처분」이라 했다. **권위를 보면 처분할 것이 아니다.**

권위 「스티커」 시트 r4(반칼 자유형/규격 스티커 · 국4절) 옵션축:

```
A5(4판)/124x186(4판) | A4(2판) | A3(1판) | 90*190(6판) | A6(8판)/100*148(8판) | 90*110(12판)
```

**`100*148`(8판)과 `90*110`(12판)은 권위 가격표의 정식 옵션열**이고, 단가도 붙어 있다
(r7 기준 6,700 / 7,700 / 7,700원 — 라이브 단가행 min 4,500 ~ max 7,700 과 정합).
두 코드의 `note` 도 「판걸이=8.0 / 적용=반칼스티커」·「판걸이=12.0 / 적용=반칼스티커」로
권위와 같은 말을 한다.

즉 상태는 **「고아 데이터」가 아니라 「값은 다 넣어놓고 상품에 연결을 안 한 미완 배선」**이다:

- 단가행 1,296행 적재 완료(각 `COMP_STK_PRINT` 360 + `STK_KISSCUT_PRINT` 288)
- 그런데 `t_prd_product_sizes` 연결 0건 → **손님이 고를 수 없다 = 매출 누락**
- 게다가 치수 미입력 → `fn_calc_pansu` = `NULL`

⚠ **순서 의존(중요)**: t41 이 `STK_KISSCUT_PRINT.use_dims` 에 `plt_siz_cd` 를 넣었다.
**치수를 채우기 전에 상품 사이즈부터 연결하면** 판수 `NULL` → `pricing.py:982` `ERR_NO_PLATE`
→ 그 사이즈가 **가격 불가로 막힌다**(fail-closed). 반드시 **치수 → 연결** 순서.

참고로 t41 이 넣은 `STK_KISSCUT_PRINT` 2,592행의 사이즈별 분포(`kisscut_rows.txt`):
9사이즈 × 288행, 그중 `SIZ_000518`·`519` 두 개만 상품 연결 0 → **576행**이 카드가 말한 숫자다.

**교정 명세**
1. 치수 채움: `SIZ_000518` = work 100×148 · cut 100×148 · 여백 0.
   검증 — 반칼 판형 `SIZ_000498`(317×440, 여백 10 → 297×420):
   `⌊297/148⌋×⌊420/100⌋ = 2×4 = 8` ✓ 권위 8판.
2. `SIZ_000519`(90x110) 는 **치수를 확정하지 못했다 — Gap(§6 참조)**. 어떤 등록 판형으로도
   권위 12판이 재현되지 않는다. 실무진 확인 전에는 채우지 않는다.

## 6. 미검증 (Gap) — 정직하게 남긴다

1. **`SIZ_000519`(90x110) 판걸이 12 가 재현되지 않는다.** 권위 「스티커」 r4 는 12판이라 하는데,
   `SIZ_000498`(317×440, 여백10 → 297×420)에서 90×110 은 9판, `SIZ_000521`(330×470, 여백5 → 320×460)
   에서는 12판이지만 같은 판형이 A6·100x148 의 권위 8판을 재현하지 못한다.
   → **치수를 추정해 채우지 않았다.** 실무진에게 「90x110 은 어느 판에 몇 mm 여분으로 앉히나」를
   물어야 한다.
2. **`SIZ_000518`·`519` 를 어느 반칼 상품에 붙이나.** 권위 시트는 옵션축을 상품별로 나눠 적지
   않는다. 반칼 10상품 전부인지 일부인지 미확정.
3. **소량자유형스티커(`PRD_000064`) 전용 단가블록 유무.** 권위 「스티커」 시트에서 확인하지 못했다.
   신규 6사이즈를 등록해도 단가행이 없으면 가격이 안 나온다.
4. **`SIZ_000508`(80×80) 재사용 가부.** 치수는 맞지만 note 가 합판도무송 원형 50mm 를 가리켜
   의미가 다르다. 코드 재사용이 옳은지는 도메인 판단.
5. **인쇄배경지 커팅형 판형(316x467, 좌우6/상13/하16)이 라이브에 미등록.** 이번 스코프 밖이지만
   `PRD_000044 인쇄배경지(커팅형)` 의 판수 정확성에 영향이 있을 수 있다 — 별건 카드 후보.
6. **`PRD_000286` 과다청구 기 주문 집계 미착수.** 언제부터 잘못됐는지, 얼마인지 세지 않았다.
7. **webadmin 실화면 미확인.** 이 카드는 읽기전용 DB 진단까지다. 적재 트랙으로 넘어갈 때
   가격시뮬레이터 실화면 확인이 [HARD] 선행 조건이다.
