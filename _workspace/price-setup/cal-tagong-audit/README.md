# 벽걸이캘린더 `PRD_000111` 타공 확인 — 그리고 110 배선 재검토 (2026-08-30)

지시: 「111도 확인해줘」 · **조사 전용 — 라이브 변경 0건**

---

## 0. [HARD] 먼저 말할 것 — 이 확인이 방금 한 110 배선을 뒤집는다

`77fa301c` 에서 엽서캘린더 `PRD_000110` 에 「타공비(6mm)」(합가 · 작업 1건 고정 2,000)를
배선했다. 그때 남긴 우려(`../tagong-110-wire/README.md` §5.2 — 「권위 §19 는 ×제작수량인데
이 표는 합가다」)가 **실제 결함으로 확인됐다.**

권위 상품마스터 「캘린더」 시트는 엽서캘린더의 가공 옵션 가격을 명시한다:

| 상품 | 가공 옵션 | 추가가격 |
|---|---|---:|
| **엽서캘린더** | 가공없음(재단만) / **1구타공+끈** | 0 / **1,000** |
| **벽걸이캘린더** | 고리형트윈링제본 / 가공없음(재단만) / **2구타공+끈** | 2,000 / 0 / **1,500** |
| 와이드벽걸이캘린더 | 고리형트윈링제본 / 제본없음(재단만) | 2,000 / 0 |

그리고 **캘린더 가공비는 수량을 곱한다** — 실측으로 확인했다(§3).

100개 기준 엽서캘린더 타공:

| | 금액 |
|---|---:|
| 권위(1,000 × 100) | **100,000** |
| 현재 라이브(내가 배선한 합가) | **2,000** |

**50배 언더차지다.** 0원이던 것을 2,000원으로 만든 것이 개선처럼 보이지만,
**틀린 가격을 넣은 것**이라 0원보다 위험하다 — 0원은 미완성 신호로 보이지만
2,000원은 정상처럼 보인다.

⇒ **110 배선은 되돌리기를 권한다**(§6).

## 1. 111은 왜 못 받나 — 확정

| 층 | 실측 |
|---|---|
| 상품 공정 | `PROC_000127` **2구 6mm 타공** 보유 (선택 N · 구수 1~8) |
| 공식 `PRF_DGP_CAL_WIDE` | 구성요소 3개 — 디지털인쇄비 · 용지비 · **제본비 벽걸이캘린더**. **타공비 없음** |
| 실계산(100개) | 타공을 골라도 **33,129 그대로** |

공식 공유 상품은 `111` 벽걸이캘린더 · `112` 와이드벽걸이캘린더 둘이고,
**타공 공정 보유는 111 하나뿐**이다(112는 없음).

## 2. 옵션그룹 「가공」은 아무것도 안 보낸다

111에는 옵션그룹 `OPT_000273` 「가공」이 있고 옵션 3개가 **권위 목록과 정확히 일치**한다:

| 라이브 옵션 | 권위(상품마스터 캘린더 S/T) |
|---|---|
| 재단만 | 가공없음(재단만) 0 |
| **2구타공+면끈** | **2구타공+끈 1,500** |
| 고리형트윈링제본 | 고리형트윈링제본 2,000 |

그런데 그룹 속성이 `constraint_only: true` · `price_relevant: false` 이고
**모든 옵션의 `maps`가 비어 있다**(dims·procs 둘 다 `[]`).

⇒ 고객이 「2구타공+면끈」을 골라도 **공정도 차원도 안 실린다.** 가격에 영향이 없다.
같은 것을 공정(`PROC_000127`)과 옵션그룹 두 곳에서 표현하고 있는데, 둘 다 값이 안 붙는다.

## 3. [HARD] 캘린더 가공비는 「개당 × 수량」이다 — 제본비가 증명한다

`COMP_BIND_CAL_WALL`(제본비 벽걸이캘린더) 24행이 가격표 「제본」 시트
**「캘린더 제본비」 표와 전건 일치**한다:

| 수량 | 권위 벽걸이캘린더제본 | 라이브 |
|---:|---:|---:|
| 1 | 5,000 | 5,000 |
| 4 | 4,000 | 4,000 |
| 10 | 3,000 | 3,000 |
| 50 | 2,500 | 2,500 |
| 100 | 2,000 | 2,000 |
| 1,000 | 2,000 | 2,000 |

그리고 실계산: 111 · 100개 · 제본 선택 → **33,129 → 233,129**.
차이 200,000 = **2,000 × 100** — **수량을 곱한다.**

이것이 권위 §19 「캘린더가공비 = [가공비] **X [제작수량]**」이다.
상품마스터 T21 「고리형트윈링제본 2,000」은 그 표의 대량구간 값과 같다 —
**T열은 대표값이고 실단가는 가격표 시트**라는 관계가 성립한다.

⇒ 타공도 같은 계열이면 **개당 × 수량**이어야 한다. 합가(작업 1건 고정)가 아니다.

## 4. [HARD] 그런데 권위가 내부에서 충돌한다 — 111은 단정할 수 없다

두 권위 문서가 벽걸이캘린더 타공에 대해 다른 값을 준다.

| 출처 | 값 | 계산 형태 | 100개 |
|---|---:|---|---:|
| 상품마스터 「캘린더」 T23 「2구타공+끈」 | 1,500 | 개당 × 수량(§3 유추) | **150,000** |
| 가격표 「커팅타공」 타공**(합가)** 2구 | 4,000 | 작업 1건 고정 | **4,000** |

가격표 「커팅타공」 시트 42행의 배치를 정확히 보면:

```
A42:C42 [병합] "타공 (단가)"      D42 "헤더택 / 벽걸이캘린더"      F42:H42 [병합] "타공 (합가)"
```

- `D42` 라벨은 **어느 표에도 병합돼 있지 않다** — 두 표 사이 빈 컬럼에 떠 있어
  어느 쪽을 가리키는지 문서만으로는 정해지지 않는다.
- 왼쪽 **「타공(단가)」 표는 1구 컬럼이 전부 `0`**, 2구 컬럼은 **아예 비어 있다** — **미기입 표**다.
- 오른쪽 「타공(합가)」 표만 값이 채워져 있다.

**「타공(단가)」가 캘린더용 개당 단가 그릇인데 아직 안 채워진 것**이라면 §3과 아귀가 맞는다.
그렇다면 T열 1,000/1,500 이 그 자리에 들어갈 값이다. 다만 이것은 **추론이고, 확정이 아니다.**

**엽서캘린더는 `D42` 에 이름조차 없다** — 110에 합가 표를 붙일 근거는 애초에 없었다.

## 5. 정리 — 확정된 것과 미확정인 것

**확정(실측·권위 인용으로 뒷받침됨)**

1. 111은 타공비를 못 받는다 — 공식에 배선 자체가 없다.
2. 111의 옵션그룹 「가공」은 `constraint_only` 라 가격에 아무 영향이 없다.
3. 캘린더 가공비는 **개당 × 제작수량**이다(제본비 실측 200,000 = 2,000 × 100).
4. 권위는 벽걸이캘린더 2구타공+끈 = **1,500**, 엽서캘린더 1구타공+끈 = **1,000** 이라고 적는다.
5. 라이브 제본비는 가격표 「제본」 시트와 전건 일치한다 — 라이브가 가격표를 단가 권위로 쓴다.
6. 「타공(단가)」 표는 **전부 0(미기입)**, 「타공(합가)」 표만 값이 있다.

**미확정(실무진 확인 필요)**

- 캘린더 타공이 「타공(합가)」인지, 「타공(단가) × 수량」인지. 후자면 **단가가 미정(0)** 이다.
- 상품마스터 T열 1,000/1,500 이 개당 단가인지, 주문당 정액인지.
- `D42` 「헤더택 / 벽걸이캘린더」가 어느 표의 라벨인지.

**이 셋이 정해지기 전에는 111에 어떤 값도 배선할 수 없다.** 값을 지어내는 셈이 된다.

## 6. 권고

1. **`PRD_000110` 타공비 배선을 되돌린다** (`77fa301c` 취소).
   근거가 뒤집혔고, 현재 값은 권위 대비 50배 언더차지다.
   되돌리면 0원으로 돌아가지만 **「아직 안 정해짐」이 정확한 상태**다.
2. **`PRD_000111` 은 배선하지 않는다.** §5 미확정 3건이 먼저다.
3. 실무진에 물을 것 — 캘린더(엽서·벽걸이)의 타공 가격이
   ① 「타공(단가)」 개당 × 수량인지 ② 「타공(합가)」 작업 1건 고정인지,
   ①이면 「타공(단가)」 표의 0 자리에 들어갈 값이 T열의 1,000/1,500 인지.
4. 헤더택 `045` 는 그대로 둔다 — `D42` 가 이름을 부르고 합가 형태도 맞는다(§4).
