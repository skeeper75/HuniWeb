## 2. R5 재판정 — **뒤집힌다. 권위 r63 이 옳고, 480x320 은 불필요했다**

t9 판정: 「권위 r63 이 316x467 을 지정했는데 판걸이 0 → 권위 모순 또는 mint 필요」
**t44 재판정: 틀렸다.** 지니 관점대로 Max Page 로 표지를 산출하면 452x303 이고,
국4절 316x467 에 **판걸이 1 로 들어간다**(5mm 여유).

t9 이 판걸이 0 을 본 이유는 시트 고정치수 454x297(작업 460x303)을 그대로 썼기 때문이다

### 결론

  라이브 표지 사이즈를 Max Page 값으로 되돌리면 이 판형은 쓰이지 않는다.

## 3. R1 재판정 — **단가 재산정이 아니라 판형 철회로 푼다**

t9 R1: 「SIZ_000641 COMP_PAPER 7행이 316x467 복사본, 면적 +4.09% 미반영 → 과소청구」

R5 가 뒤집히면 R1 의 성격이 바뀐다. 480x320 은 **애초에 쓰이면 안 되는 판형**이므로,
그 단가를 면적비례로 올리는 것은 잘못된 판형을 정당화하는 교정이다.

### 가격 영향 = 0 (실증 `price_parity_check.txt`)

표지 6개 자재 전건, 316x467 단가 = 480x320 단가:

| 자재 | 316x467 | 480x320 |
|---|---:|---:|
| 백색모조지 220g | 70.64 | 70.64 |
| 아트지 250g | 77.75 | 77.75 |
| 아트지 300g | 93.30 | 93.30 |
| 스노우지 250g | 77.75 | 77.75 |
| 스노우지 300g | 93.30 | 93.30 |
| 몽블랑 240g | 142.20 | 142.20 |

판걸이도 1 = 1. → **판형을 316x467 로 되돌려도 청구액은 한 푼도 안 바뀐다.**
동시에 t9 이 지적한 4.09% 미반영 문제는 **원인 자체가 사라진다**(그 판형을 안 쓰므로).

### 명세 (권장 A안 — DRY-RUN 완료)

`r1_remediation.sql` / `dryrun.log`:

1. `t_siz_sizes` SIZ_000633 → 재단 **446x297** · 작업 **452x303** (여백 3 유지)
2. `t_prd_product_plate_sizes` 에서 `siz_cd='SIZ_000641' AND item_siz_cd='SIZ_000633'`
   2행(PRD_000290·PRD_000292) 논리삭제 → 공통 풀(316x467 dflt Y)로 복귀

DRY-RUN 결과: `pansu(316x467, 표지A4)` **0 → 1**, `SIZ_000641 잔여 배선 0`,
ROLLBACK 후 원상 확인. 라이브 무변경.

### 대안 B — 표지치수를 안 건드리는 길

시트 고정 454x297 을 유지하되 **블리드 없이 조판**하면(작업 = 재단 454x297)
316x467 실영역 306x457 에 회전 배치로 판걸이 1 이 된다(3mm 여유).
표지 물리치수를 줄이지 않아도 되지만 블리드 0 은 재단 안전여백을 포기하는 것이라
인쇄 실무 판단이 필요하다.

### ⚠ A안의 실무 리스크 — 확인 없이 COMMIT 금지

A안은 표지를 **8mm 좁힌다**(454→446). 현재 등록 자재 기준으로는 안전하지만
(최대두께 0.170mm → 책등 26mm), 시트의 34mm 여유는 두께 0.2233mm 용지까지 커버한다.
앞으로 그보다 두꺼운 내지를 등록하면 표지가 모자란다. 아래 §5 질의 2 의 답이 먼저다.

## 4. R6 재판정 — **유지된다. 550x375 mint 는 정당하다**

하드커버 표지(SIZ_000635 532x355)는 종이 접지가 아니라 **보드 케이스 랩**이고,
엔진의 펼침식(`표지가로×2 + 책등`)으로 재현되지 않는다(`spine_cover_calc.md` §5).
즉 「Max Page 로 다시 계산하면 더 작다」는 논증이 성립하지 않는다.

- 532x355 는 라이브 판형 5종 중 **550x375 에만 들어간다**(나머지 전부 판걸이 0).
- 특히 권위 r65 가 지정한 **330x660(3절)에도 안 들어간다** — 실영역 320x650 에
  532 도 355 도 320 을 넘는다. 이건 Max Page 관점과 무관한 순수 기하 사실이다.
- 책등 보드 상한 26mm 가 엔진 산출 책등 26mm 와 일치하므로, 532x355 자체는
  이미 Max Page 봉투로 보인다(더 줄일 여지 없음).

### 결론

- **권위 r65 의 판형 지정(330x660)은 오기다** — 역반영 요청 대상(§6).
- **SIZ_000640(550x375) 신설은 정당**하다. 철회 대상 아님.
- 다만 550x375 가 실재하는 인쇄판인지는 확인이 필요하다(§5 질의 3).
  실판형이 아니라면 케이스 랩을 담을 **다른 실판형**을 찾아야 한다.

## 5. 실무진 확인 질의 (COMMIT 전 선결)

1. **무선/PUR A4 표지를 8mm 좁혀도 되는가?**
   현재 454x297(책등 여유 34mm) → Max Page 산출 446x297(책등 26mm).
   좁히면 권위 판형 국4절에 들어가고 신설 판형이 필요 없어진다.
2. **시트의 34mm 책등 여유는 무엇을 위한 값인가?**
   현재 최대 내지(몽블랑130g 0.170mm)로는 26mm 다. 34mm 는 두께 0.2233mm 용지까지
   커버한다 — 앞으로 넣을 두꺼운 내지를 위한 헤드룸인가, 아니면 단순 관행값인가?
   (헤드룸이면 A안 대신 대안 B 를 택해야 한다.)
3. **480x320 · 550x375 는 실재하는 인쇄판인가?**
   권위 「판걸이수」 시트의 판형 어휘는 316x467·330x660·330x540·330x470·304x629 뿐이다.
   두 판형 모두 시트에 없다. 550x375 는 하드커버 케이스를 담을 유일한 후보이므로
   실판형 여부가 특히 중요하다.
4. **하드커버 케이스 랩 치수(390x268 · 532x355)의 산출 근거는?**
   보드(142x218 / 204x304) + 책등보드(최대 26) 로는 폭이 80·98mm 모자란다.
   경첩 홈·싸개 접힘 규칙이 코드·DB 어디에도 없어 상수로만 존재한다.

## 6. ④ 권위 시트 역반영 요청문 초안

> 수신: 인쇄상품 가격표 「판걸이수」 시트 관리 담당
> 건: r65 행 판형 지정 정정 요청 (하드커버무선책자 A4)

**요청 1 — r65 판형 지정 정정 (오기로 판단)**

`판걸이수` 시트 r65 「하드커버무선책자 A4」는 재단 532x355 · 블리드 0 이고,
판형이 **8열 디지털인쇄(3절) = 330x660** 으로 지정돼 있습니다.

그런데 330x660 은 「사방 5mm 제외」 적용 시 인쇄 실영역이 **320x650** 이라,
532x355 는 정방향(532>320)으로도 90° 회전(355>320)으로도 **들어가지 않습니다**.
같은 시트 r64(하드커버무선 A5 390x268)는 국4절 316x467 에 정상적으로 들어갑니다.

현재 라이브는 이 행을 담기 위해 **550x375** 판형을 별도로 만들어 쓰고 있습니다
(실영역 540x365 · 판걸이 1). 다만 550x375 는 시트의 판형 어휘
(316x467 · 330x660 · 330x540 · 330x470 · 304x629)에 없습니다.

→ **r65 의 실제 판형이 무엇인지 확인 부탁드립니다.** 550x375 가 맞다면 시트에
반영해 주시고, 다른 판형이라면 알려 주시면 라이브를 그에 맞추겠습니다.

**요청 2 — r62·r63 표지 재단치수 확인 (정정 요청 아님 · 의도 확인)**

r62 무선/PUR 표지 A5 = 330x210, r63 A4 = 454x297 은 각각 완제품 폭 × 2 에
**책등 34mm** 를 더한 값입니다(296+34 / 420+34).

한편 현재 등록된 내지 최대두께(몽블랑130g 0.170mm)와 최대 페이지(300p 양면 = 150장)로
가격엔진이 산출하는 책등은 **26mm** 입니다. 시트가 8mm 더 여유를 잡고 있습니다.

이 8mm 차이 때문에 r63 의 작업사이즈(454+블리드 6 = 460x303)가 국4절 316x467 의
실영역 306x457 을 **3mm 초과**해, 라이브가 480x320 판형을 별도로 만들어 쓰고 있습니다.
책등을 26mm 로 잡으면(446x297 → 작업 452x303) 국4절에 판걸이 1 로 정상 수용됩니다.

→ **34mm 가 앞으로 등록할 두꺼운 내지를 위한 여유인지, 관행값인지 확인 부탁드립니다.**
여유 목적이면 시트값을 유지하고 라이브 조판 방식을 조정하겠고,
관행값이면 r62·r63 을 322x210 · 446x297 로 정정 요청드립니다.
