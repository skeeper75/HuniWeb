## 요약 — 스티커는 "가격 성립·UI 결손" 프로파일

| 층 | 상태 | 한 줄 |
|----|:--:|------|
| ③ 가격사슬 | ✅ **전건 성립** | 14/14 활성상품 PRICE≠0(고정가by-siz)·silent-0 0건·WIRE 갭 0 |
| ② 차원환원 | ✅ 무결 | ref_dim dangling 0·룩업 prod_dims 실행 |
| ① UI(CPQ) | 🟡 **부분** | 4상품 완비·10상품 CPQ 결손(자재 손님선택 불가/주문경로 부재) |

**결론**: 스티커는 이전 NO-GO 상품군(명함 WIRE·아크릴 이중전무·굿즈 삼중전무)과 **결함 성격이 다르다** — 가격·차원·기초는 전건 GO이고, **오직 ①UI(CPQ 옵션그룹) 미적재 단일 축**만 남았다. 결함 깊이 = 가장 얕음(적재 완료분 재사용·mint 0).

## 갭 목록 (돈영향 순)

### 1. GAP-STK-CPQ-VOID — 자재 다종 상품 CPQ 미적재 [①UI · High · 돈영향 有]
- **상품**: 반칼정사각(059)·반칼직사각(060)·반칼띠지(061)·반칼팬시(062)
- **유형**: 미적재(CPQ 옵션그룹 그릇 부재)
- **재현**: `sim_meta` → `opt_groups: []` / DB `t_prd_product_option_groups` 0행. 손님이 위젯에서 자재 선택 불가.
- **돈영향**: 059 자재별 시뮬 실측 — 비코팅/유포/미색 = 57,000 vs **무광/유광코팅 = 67,000(±10,000, qty10)**. CPQ 없으면 기본자재로 고정 → 코팅 스티커 오선택/미과금.
- **COMMIT 필요분**: **round-6 dbm-option-mapper** — 052 CPQ 패턴(종이 5옵션→`OPT_REF_DIM.03`/mat_cd + 인쇄 단면 + 커팅) 동형 복제. **신규 mint 0**(기존 mat_cd 재사용).

### 2. GAP-STK-CPQ-ORDERPATH — 단일자재 상품 주문경로 부재 [①UI · Medium · 돈영향 無]
- **상품**: 반칼자유형홀로그램(054)·낱장자유형투명(056)·대형자유형(057)·스티커팩(065)
- **유형**: 미적재(CPQ 전무)
- **재현**: CPQ 0/0/0. 자재 단일(또는 무가격)이라 선택은 무의미하나, 위젯 주문 트리거(인쇄/커팅) 자체가 없어 손님이 아무것도 못 고름.
- **돈영향**: 0 (자재 선택 무영향)·주문 UX 차단.
- **COMMIT 필요분**: round-6 — 최소 CPQ(인쇄 단면 + 커팅 + 단일자재 표시). 저위험.

### 3. GAP-STK-CPQ-WEAK — 그룹 있으나 손님선택 불완전 [①UI · Medium]
- **상품**: 반칼원형(058 전 그룹 mand=N)·타투(067 용지 1옵션/자재 2종)
- **유형**: 오적재/부분(그룹 무력화·옵션 누락)
- **재현**: 058 `mand_yn=N`(필수 통과) / 067 용지 opt_items=1(2번째 자재 미노출).
- **돈영향**: 067 미노출 자재 주문불가(low)·058 선택 누락 허용.
- **COMMIT 필요분**: round-6 — 058 mand 승격 검토 / 067 자재 옵션 추가.

### 4. GAP-STK-BUNDLE-EMPTY — 조각수 미적재 [비차단 · Low · 돈영향 無]
- **상품**: 전 16상품 `t_prd_product_bundle_qtys` = 0행.
- **유형**: 미적재
- **재현**: `SELECT COUNT(*) FROM t_prd_product_bundle_qtys WHERE prd_cd IN (스티커16)` = 0.
- **돈영향**: **0** — 조각수(C25)는 가격 무관(손님 작업 안내). **silent-0 아님(FP 가드)**.
- **처리**: 견적 비차단. 위젯 표시 필요 시에만 option dtl_opt 표시용 → **NO-OP 후보**.

## COMMIT 필요분 유무

- **필요분 有 (①UI CPQ만)**: round-6 dbm-option-mapper로 활성 10상품 CPQ 신설/보완. 대표 052/053/055/066 패턴 동형 복제·**신규 mint 0**.
- **불필요 (중복 적재 금지)**: ③가격·②차원환원·기초(siz/mat/proc/clr) 전건 GO — 적재 스킵.
- 실 COMMIT은 인간 승인 후 + webadmin 실화면 확인([HARD]).
