# 옵션그룹 `constraint_only` 계열 전수 스윕 (2026-08-30)

지시: 「옵션그룹 constraint_only 계열 전수로 훑어줘」 · **조사 전용 — 라이브 변경 0건**

---

## 0. 결론 — 가설은 대체로 오탐이었고, 다른 결함 2계열이 나왔다

「옵션그룹이 `constraint_only` 라 가격축을 못 보낸다」는 **일반 법칙이 아니었다.**
대부분의 상품은 옵션그룹과 **별개로 `opt_cd` 를 상품 차원으로 갖고 있어** 정상 과금된다.

| 판정 | 건수 |
|---|---:|
| 빈 옵션그룹(모든 옵션의 `maps` 가 비어 있음) | **113건 / 84상품** |
| 그중 게시 + 돈 관련 그룹 | 51상품 |
| **실제 결함으로 확인** | **9건** (§2·§3·§4) |
| 오탐 | 나머지 |

지난 세션 교훈(「1차 규칙 과대 82·미수금 103 이 전부 노이즈」)이 그대로 재현됐다.
**추정으로 멈추지 않고 시뮬레이터로 재서** 걸러냈다.

## 1. 방법 — 4단계로 좁혔다

1. **전 상품 292종 메타 + 전 구성요소 123종 단가표** 수집(결정론).
2. 「단가행이 요구하는 축을 상품이 보낼 수 있나」 정적 판정 → **268 후보**.
   → 판형·공정 상세입력·파생 면수는 다른 경로로 전달되므로 **대부분 노이즈**.
3. **292종 전수 실계산**(기본 선택 + 필수공정) → **0원 68건**.
4. 0원을 유형별로 갈라 오탐 제거 → **게시 완제품 0원 7건**.
   추가로 선택공정의 가격 영향을 상품별 전수 측정(`proc-movers.json`) → 51상품 중 38 후보 →
   권위 대조로 다시 좁힘.

## 3. [확정] 현수막 2종 — 가공옵션과 부자재를 **동시에 고를 수 없다**

권위 가격표 「포스터사인」 시트는 두 옵션을 **별개 표**로 둔다:

**일반현수막**(J244 가공옵션 / M244 추가옵션)

| 가공옵션 | 추가가격 | | 추가옵션(부자재) | 추가가격 |
|---|---:|---|---|---:|
| 열재단 | 3,000 | | 추가없음 | 0 |
| 타공(4개) | 3,000 | | 큐방(4개) | 3,000 |
| 타공(6개) | 4,000 | | 끈(4개) | 4,000 |
| 타공(8개) | 5,000 | | 각목(900mm이하)+끈(4개) | 4,000 |
| 양면테잎 | 3,000 | | 각목(900mm 초과)+끈(4개) | 8,000 |
| 봉미싱 | 4,000 | | | |

메쉬현수막도 같은 구조(J265 / M265).
추가옵션에 **「추가없음 0」**이 있다는 것은 두 축이 **독립이고 함께 더해진다**는 뜻이다.

**라이브는 둘을 `opt_cd` 축 하나에 합쳐 놓았다.** 실측(일반현수막 `PRD_000138`, 900×900, 1장):

| 보낸 `opt_cd` | 완제품가 | 가공옵션 | 부자재 | 합계 |
|---|---:|---:|---:|---:|
| 열재단 | 8,000 | **3,000** | — | 11,000 |
| 아일렛(4구) | 8,000 | **3,000** | — | 11,000 |
| 큐방(4개) | 8,000 | — | **3,000** | 11,000 |
| 끈(4개) | 8,000 | — | **4,000** | 12,000 |
| 각목(900mm 초과)+끈 | 8,000 | — | **8,000** | 16,000 |

**단가는 권위와 전건 일치한다.** 문제는 축이다 — `opt_cd` 는 스칼라라
「아일렛(4구) **+** 끈(4개)」를 보낼 수 없고, 구성요소는 둘 중 하나만 매칭된다.

⇒ 고객이 가공과 부자재를 함께 고르면 **한쪽 금액이 빠진다**(위 예시로 4,000원 언더차지).
옵션그룹은 「가공」·「부자재」로 정확히 둘로 나뉘어 있으나 `constraint_only` 라
가격축을 못 보내고, 실제 축인 `opt_cd` 는 하나뿐이다.

**교정은 축 설계 문제다** — 두 축(가공 / 부자재)으로 분리하거나 다중 `opt_cd` 를 허용해야 한다.
가격층만으로는 못 푼다. **지니 판단 사항.**

## 4. [오탐으로 판정] 기록해 둔다

| 건 | 왜 오탐인가 |
|---|---|
| 캔버스 행잉포스터 `133` · 린넨우드봉족자 `134` | 추가가격 구성요소가 **정상 매칭**된다(우드행거 16,000 · 우드봉 7,000). 옵션그룹이 비어도 `opt_cd` 가 상품 차원에 있다 |
| 린넨패브릭포스터 `124` | 마감가공비 매칭됨(기본 「오버로크」 0원 — 권위상 0이 맞다) |
| 스티커 8종(`052`~`063`) 「커팅」 그룹 | 커팅 모양 선택은 완제품가에 포함. 사이즈별 단가가 이미 모양을 반영 |
| 모양명함 `035` · 미니모양명함 `036` | 권위 A43/A50 블록이 **모양 무관 단일가**(18,000 / 16,000) — 포함가 |
| 아크릴 부속류 9종 | 부속 가산형 addon 모델. 별도 comp 로 처리되거나 완제품가 포함 |
| 「~포함」 표기 옵션(우드행거+면끈 포함 등) | 이름 자체가 포함가를 선언한다 |
| 코팅·모서리·링칼라 등 순수 제약 그룹 | 가격과 무관한 조합 제한용. `constraint_only` 가 정상 용법 |

**`constraint_only` 자체는 결함이 아니다.** 그것이 정상 용법인 그룹이 훨씬 많다.
