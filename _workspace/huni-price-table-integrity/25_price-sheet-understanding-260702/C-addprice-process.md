## 0. 공통 구조 (6시트 관통하는 읽기 규칙)

이 6시트는 사용자 핵심 해석 규칙과 **대체로 일치**한다:

1. **본체가 아니라 "추가가격/공정 단가표"** 다. 시트명이 상품명(명함·엽서 등)이 아니라 공정명
   (디지털인쇄비·코팅·접지·제본…)이다. 즉 상품 본체 가격표가 아니라, **선택된 옵션/공정에 대해
   별도로 찾아 합산**하는 테이블이다.
   - 단, **디지털인쇄비**만은 예외적으로 "추가가격"이 아니라 **디지털 상품군 본체 인쇄비의 핵심 축**
     이다(합산 대상이 아니라 base 인쇄비). 나머지 5시트는 옵션성 가산 공정에 가깝다.
2. **레이아웃 = 세로축 × 가로축 격자**:
   - **세로축(행)** = 거의 항상 **제작수량 밴드**(1, 2, 5, 10, 100, 1000 …). 마지막 행은 `1000000`
     같은 상한 캡(예: 코팅 A26 `1000000`).
   - **가로축(열)** = **공정 종류 × 면(단면/양면) 또는 종류만**. 헤더가 2줄인 시트는
     1줄째=종류(무광/유광, 흑백/칼라…), 2줄째=면(단면/양면).
3. **값의 의미는 두 부류로 갈린다 — 수량밴드 증가 시 값의 방향으로 판정**:
   - **부당 단가(L1-밴드 단가)**: 수량 늘수록 값이 **감소**(수량할인). → 값 = **1개(1판/1부)당 단가**,
     최종 = `단가 × 수량(또는 판수)`. 해당: 디지털인쇄비 · 코팅 · 접지옵션 · 제본.
   - **합가(band total)**: 수량 늘수록 값이 **증가**. → 값 = **해당 수량 구간 전체의 총 가공비**
     (곱하지 않고 그대로 더함). 해당: 인쇄후가공(모서리·오시·미싱·가변) · 커팅타공의 타공(합가).
   - 시트/블록 제목에 **"(합가)"** 또는 **"(단가)"** 가 명시돼 있어 이 판정을 뒷받침한다.
4. **국4절 / 3절 분리 블록**: 여러 시트가 판형(출력 대수)별로 2블록으로 나뉜다(예: 코팅 B01 국4절 /
   B02 3절). 같은 공정이라도 절수가 크면 단가가 더 높다.

### 셀 색상(fill_rgb) 관례 — meta.csv에서 관찰
- `FFFFFF00`(노랑) = 블록 제목/헤더 밴드. `FFFF00FF`(마젠타) = "합가" 계열 블록 제목.
- `FFFF0000`(빨강 글꼴) = 표 밖 증분 규칙 주석(예: "100장당 1000원씩 올립니다").
- `FFFF9900`(주황 글꼴) = 부가 설명(예: 커팅 C1 "인쇄배경지", 제본 E14 "표지비용 따로 계산").

## 1. 디지털인쇄비 (slug: digital-print)

### 1-2. 차원 축
`판형(국4절/3절)` × `색상(흑백/칼라/별색5)` × `면(단면/양면)` × `수량밴드`.

### 1-3. 값의 의미 — **부당 단가**
수량 증가 시 값 감소로 판정. 예 국4절 흑백 단면(B열): `1→3000`(B4), `2→2000`(B5), `3→1600`(B6),
`4→1400`(B7), `5→1200`(B8) … → 1판당 단가. 최종 인쇄비 = **단가 × 판수(판걸이수)**.
여기 "수량"은 출력 판(국4절/3절 대수) 수로 읽힌다.

### 1-4. 언제 어떤 본체에 합산되나
"추가가격"이 아니라 **디지털 인쇄 상품군의 base 인쇄비 그 자체**(명함·엽서·전단·리플렛·카드 등
디지털 출력물). 매핑 구성요소(run_all.py 레지스트리): `COMP_PRINT_DIGITAL_S1`(흑백·칼라),
`COMP_PRINT_SPOT_WHITE_S1`(별색). 별색은 CMYK 위에 얹는 추가 도수라 사실상 가산 성격.

### 1-5. 알려진 함정 — 흑백/칼라 축
- **구조적 사실**: 색상축에 `흑백(1도)`와 `칼라(CMYK)`가 **별개 열**로 공존(B2 vs D2). 즉 권위
  엑셀은 흑백↔칼라를 **도수(색상) 차원**으로 구분해 단가가 다르다(예 국4절 1부: 흑백단면 3000 vs
  칼라단면 4000).
- **기록된 상태의 긴장(cross-check)**: `ALL-SHEETS-summary.md`는 두 곳에서 **상충**한다 —
  요약표(line 16)는 "권위 954셀 중 954셀 100% 일치, 흑백축=§18 설계/별색=일치"로 적고,
  라우팅 B절(line 42)은 "**디지털 흑백 212셀**: use_dims 도수축 collapse(흑백/칼라 구분 차원
  없음)·차원 설계 결정(BLOCKED)"로 적는다. → 라이브 엔진 use_dims에 **흑백↔칼라를 가르는 차원이
  없어** 흑백 단가가 그대로 적재되지 못했다는 취지. 요약표의 100%는 별색·칼라 위주 매칭으로 보이며,
  흑백 212셀은 설계 미결로 남은 것으로 읽힌다. **정확한 현재 라이브 반영 여부 = [AMBIGUOUS]**
  (이 이해 문서 범위 밖, §18/§26 진단 트랙 소관).

### 1-6. [아는 것 / 모르는 것 / 애매한 것 / blind spot]
- **아는 것**: 2블록(국4절 14열/3절 4열), 색상축 7종(국4절)·2종(3절), 값=부당 단가, base 인쇄비.
- **모르는 것**: 3절에 별색이 없는 이유(장비·수요 문제인지). 국4절 별색 핑크/금/은이 5·6부부터
  단가가 화이트/클리어보다 높아지는 규칙(예 J7 핑크단면 2300 vs F7 화이트단면 2100)의 배경.

`공정(모서리/오시/미싱/가변텍스트/가변이미지)` × `세부(둥근·직각 / 줄수 1~3 / 개수 1~3)` ×

### 4-3. 값의 의미 — **합가(band total)**

→ 값 = **주문 전체(해당 수량 구간)의 총 가공비**, 곱하지 않고 그대로 합산.

### 4-4. 표 밖 증분 규칙 (빨강 주석)
- 모서리: `A12=100장당 1000원씩 올립니다`(표 상한 초과분 계단 증가).

→ 밴드 최댓값(모서리 5000, 오시 5000) 초과 시 이 계단식으로 연장 계산.

### 4-5. 언제 어떤 본체에 합산되나
- **모서리(둥근)**: 명함·카드류(둥근모서리 옵션). 매핑: 모서리비 관련(과거 교훈에 명함 모서리비
  `.01→.03` 밴드×수량 과대청구 이력 있음 → 합가는 **수량 곱 금지**가 핵심).
- **오시/미싱**: 접지 없이 누름선/절취선만 넣는 상품(카드·전단·쿠폰).
- **가변(텍스트/이미지)**: 가변데이터 인쇄(번호·이름·QR 등 개별 변동) 옵션.
run_all.py: `post-process`로 DIFFED·117셀 100% 일치("가변 공정키").

### 4-6. 알려진 함정 — 담당 트랩엔 없으나 주의
- **합가를 수량으로 곱하면 100~1000배 과대청구**(밴드총액 시트의 대표 함정, `bandtotal-x-qty`
  교훈). 이 시트 값은 이미 총액이므로 `.01`(1건 고정) 성격으로 적재해야 함.
- 오시가 **인쇄후가공(단독 오시)** 과 **접지옵션(오시+접지 묶음)** 두 시트에 분산 — 상품이 어느
  쪽을 참조하는지 반드시 구분.
- 미싱(B03 우측 F~I)이 오시와 **같은 값**(예 G17=5000=B17)인데 별도 공정으로 존재 →
  값 공유하되 공정키는 분리.

### 4-7. [아는 것 / 모르는 것 / 애매한 것 / blind spot]
- **아는 것**: 5블록, 값=합가, 직각모서리=0(무료), 증분 계단 규칙, 오시|미싱 병렬.

  금지 원칙상 원본 그대로 인용만: `D26=103000`. [AMBIGUOUS: 원본 이상치인지 의도인지].
- **blind spot**: 가변 데이터의 "개수"가 무엇 단위(가변 필드 수?)인지 상품 UI 매핑.

- **B03 타공** — **좌우 두 개의 서브표 병렬**:

### 5-5. 알려진 함정 — 타공 다중값 컬럼 ★

- **함정 재현**: 좌측 단가표의 0을 유효 단가로 오적재하면 타공이 **무료**가 되어 저청구.
  (실제 유효값은 우측 합가표.)

### 5-6. [아는 것 / 모르는 것 / 애매한 것 / blind spot]
- **아는 것**: 완칼=2000×수량 선형 단가, 타공 합가표에 실값(1구/2구·2배 관계), 증분 계단 규칙,
  UNMAPPED 사유=다중값 컬럼.
- **모르는 것**: 좌측 타공(단가) 0의 의도(폐기? 다른 상품용? 향후 채울 자리?) [UNKNOWN].

## 7. 공통 blind spot 요약 (6시트 관통)

1. **"수량" 축의 단위 이중성**: 대부분 시트가 `수량(국4절)`처럼 적지만 이게 **출력 판수(대수)** 인지
   **주문 매수/부수** 인지 시트마다 다르게 읽힌다(디지털·코팅·완칼=판 성격, 접지·제본=부수 성격,
   인쇄후가공·타공합가=주문 총량). 상품 UI 수량→이 축 환산 규칙(`fn_calc_pansu`·판걸이수)은 이
   6시트 **밖**에 있어, 시트만으로는 최종 가격을 못 낸다.
2. **단가 vs 합가 혼동 위험**: 같은 "L1-밴드"라도 **단가(수량 곱함)** 와 **합가(그대로 더함)** 가
   섞여 있다. 제목 "(단가)/(합가)" 라벨과 수량밴드 단조성으로만 구별 가능. 합가를 수량으로 곱하면
   과대청구(bandtotal-x-qty 교훈), 단가를 안 곱하면 저청구.
3. **한 시트 = 여러 독립 격자**: 인쇄후가공(5블록)·커팅타공(완칼+타공 단가+타공 합가)·제본(3군)처럼
   한 시트에 **다른 차원의 서브표가 병렬**한다. 특히 커팅타공은 같은 라벨(1구/2구)이 단가·합가 두
   곳에 중복돼 **다중값 컬럼 매핑 모호성**(UNMAPPED 사유).
4. **국4절/3절(판형) 분리**: 디지털·코팅은 절수별 별도 블록·별도 단가. 3절 디지털엔 별색이 없는
   등 판형에 따라 **차원 자체가 다르다**.
5. **권위엔 있으나 라이브 상태가 다른 항목**: 중철제본(del_yn=Y)·디지털 흑백 212셀(차원 collapse)
   ·유광코팅(스냅샷 시점 의존). 이 문서는 **권위 엑셀의 원본 구조**를 확정 인용했고, 라이브 반영
   여부/교정은 §18·§26 진단 트랙 소관(여기선 [AMBIGUOUS]로 표기).
