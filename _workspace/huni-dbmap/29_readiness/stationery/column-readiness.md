## 2. 견적 3요소별 라이브 실태

### ① UI 견적 (CPQ) — 🟡
- `t_prd_product_option_groups` = **0행 (전 10상품)**. `constraints` = 0.
- 단, 가격구동 dim(사이즈·묶음수)은 **`prod_dims`로 노출**(sim_meta 실측): 097=사이즈2+묶음수2, 179=사이즈2, 172=사이즈1. → **CPQ opt_groups 없이도 위젯이 사이즈 선택 가능**. 고정단가 완제품이라 자재/공정/코팅은 고정단가에 흡수(선택 불요).
- **미노출 = 생산전용 선택 옵션**: 면지컬러(하드커버 화이트/블랙/그레이·C27)·제본방향(좌철/상철·C28)·무지내지(C13)·포장(C35). 가격 무영향이나 생산정보 전달엔 필요.

### ② 생산정보 전달 (차원환원) — 🟡
- 가격구동 dim siz_cd/bdl_qty → 단가행 정확 환원(matched_comp 1/1, siz_cd 매칭 실측). ref_dim_cd polymorphic 이슈 없음(option_items 0).
- parent BOM: `product_materials`=0(097만 2)·`processes` 부분·members(293~308)에 상세 BOM. all-in 고정단가라 가격 무해하나 **생산 spec은 member 의존**.
- 생산선택 옵션(면지컬러·제본방향) 미모델링 → 손님 선택 시 생산 전달 불가(위 ①과 동일 갭).

### ③ 가격 계산 — ✅
- 전 10상품 공식 바인딩 + 1구성요소(PRICE_TYPE.01) + component_prices 값 실재. dims 주면 **10/10 PRICE≠0**(라이브 시뮬레이터 실호출).
- golden verbatim: 097=135,000(단가행 tier min84=1,350×100)·172=810,000·173=1,200,000·177=405,000·181=225,000. 구간할인 적용 실측.
- **단, 라이브 초기 화면은 0원**(§3 STAT-SET-SIZCD): is_set=True 완제품이 셋트 UI 경로로 dim 미전파 시 silent-0.
