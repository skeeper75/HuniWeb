## 0. 시뮬레이터 실측 — PRICE≠0 전수 (③ 가격 핵심 증거)

| 상품 | qty | PRICE(원) | 상품 | qty | PRICE(원) |
|------|:--:|--:|------|:--:|--:|
| 052 반칼자유형 | 1 | 6,000 | 059 정사각 | 1 | 6,000 |
| 053 투명 | 1 | 7,700 | 060 직사각 | 1 | 6,000 |

- **활성 14/14 상품 PRICE≠0.** 미출시 063/064 제외.
- **다양 조합 검증(052)**: A5 × {유포/미색/아트=6,000·무광/유광코팅=7,000}(base) × qty{1→6,000·10→57,000·100→520,000/620,000코팅} — 자재별 가격차·수량 스케일 정상.
- **066/067 수량구간**: 066 1000→20,000·2000→30,000·5000→60,000 / 067 3→6,000·30→42,000·300→402,000 — 구간 스케일 정상.
- **★ FP 가드 성립** (메모리 "LOAD_ENG0 15=가짜 결함" 확증): 스티커는 고정가by-siz라 정적 스캔이 "인쇄 component 기여0"으로 오적발할 수 있으나, **simulate 실호출로 전건 PRICE≠0** = 진짜 silent-0 0건.
- 066/067이 qty=1에서 0인 것은 min_qty(1000/3) 미달로 매칭 단가행 없음 = 정상(오류 아님).

## 2. 갭 보드 (차단유형 + 재현 + 돈영향 + 라우팅)

### GAP-STK-CPQ-VOID [①UI · High] — 자재 다종 상품 CPQ 미적재
- **상품**: 059 정사각·060 직사각·061 띠지(각 자재 5종·CPQ 0/0/0) + 062 팬시(자재 10종·sim_meta opt_groups=[] 무력).
- **재현**: `sim_meta("PRD_000059").opt_groups == []` (DB `t_prd_product_option_groups` 0행). 손님이 위젯에서 자재를 못 고름.
- **돈영향**: 자재별 가격차 실측 — 059 qty10 비코팅/유포/미색=57,000 vs **무광/유광코팅=67,000(±10,000)**. 손님이 코팅 선택 못하면 기본자재(비코팅)로 고정 → 코팅 주문 시 미과금/오선택.
- **COMMIT 필요분**: **round-6 `dbm-option-mapper`** — 052 CPQ 패턴(종이 5옵션 `OPT_REF_DIM.03`→mat_cd / 인쇄 단면 / 커팅) **동형 복제** to 059/060/061/062. 신규 mint 0(기존 mat_cd 재사용). 실 COMMIT 인간 승인 + webadmin 실화면(제외0·자재 드롭다운).

### GAP-STK-CPQ-ORDERPATH [①UI · Medium] — 단일자재 상품 주문경로 부재
- **상품**: 054 홀로그램·056 낱장투명·057 대형(각 단일자재) + 065 스티커팩(자재 무가격).
- **재현**: CPQ 0/0/0. 자재 선택은 무의미하나(단일) 위젯 주문 트리거(인쇄/커팅 그룹)조차 없어 손님이 아무것도 못 고름.
- **돈영향**: 0(자재 선택 무영향)·**주문 UX 차단**(위젯 렌더 대상 부재).
- **COMMIT 필요분**: round-6 — 최소 CPQ(인쇄 단면 + 커팅 + 단일자재 표시) 적재. 가격 무영향이라 저위험. 인간 승인.

### GAP-STK-CPQ-WEAK [①UI · Medium] — 그룹 있으나 손님선택 불완전
- **상품**: 058 원형(종이/인쇄/커팅 전 mand=N)·067 타투(용지 1옵션만·자재 2종 중 1노출).
- **재현**: 058 그룹 mand_yn=N(필수 아님·기본 통과) / 067 용지 opt_items=1(2번째 자재 미노출).
- **돈영향**: 067 자재 2종 가격차 시 미노출 자재 주문불가(low). 058 필수화 안 됨(선택 누락 허용).
- **COMMIT 필요분**: round-6 — 058 mand_yn=Y 승격 검토 / 067 용지 2번째 자재 옵션 추가. 인간 승인.

### GAP-STK-BUNDLE-EMPTY [비차단 · Low] — 조각수 미적재
- **상품**: 전 16상품 `t_prd_product_bundle_qtys` = 0행.
- **재현**: `SELECT COUNT(*) FROM t_prd_product_bundle_qtys WHERE prd_cd IN (스티커16)` = 0.
- **돈영향**: **0** — 조각수(C25 *최대20조각 등)는 **가격 무관**(손님 작업 안내·묶음 표시용). silent-0 아님(FP 가드).
- **처리**: 견적 비차단. 위젯 표시 필요 시 round-6 option `dtl_opt` 표시용 적재. 견적가능 판정에는 불필요 → **NO-OP 후보**.

### NON-GAP (FP 가드 — 정상 확인)
- **058 커팅 원형 10옵션 ref_key1 없음**: 형상(원형 25mm~90mm)은 UI 라벨·가격무관. 가격축 siz_cd = 시트사이즈(A4 `SIZ_000520`/A5 `SIZ_000170`)이며 단가행 매칭 확인. 형상 미배선 = **정상 설계**(오적발 금지).
- **065/067 processes 0행**: 스티커팩=시트째 팩(개별 커팅無)·타투=전사(커팅無) → 커팅 공정 부재 = 정상.
- **066 형상 37종 = sizes로 흡수**(G-SK-2): CPQ 커팅그룹 대신 prod_dims siz_cd로 형상 선택·단가행 siz_cd 매칭(222조합) PRICE≠0 = 동작. 형상 CPQ 없음은 ①UI 개선 후보이나 가격 성립.
