## 5. [HARD] 권위가 완전히 덮어주지 않는 지점 — 기록해 둔다

**진행 근거는 섰으나 권위 문언만으로는 못 닫는다.** 두 가지가 걸린다.

### 5.1 타공 표의 적용 대상 주석에 엽서캘린더가 없다

`가격표_260822_1` 「커팅타공」 시트 D42, 타공(합가) 표 위 주석:

> **헤더택 / 벽걸이캘린더**

**엽서캘린더는 이름이 없다.** 그런데도 배선한 근거는 셋이다:

1. 110의 공정은 헤더택 `045` 와 **완전히 같은 `PROC_000126`(1구 6mm 타공)** 이다.
   같은 공정이면 같은 가공비 표를 쓰는 것이 자연스럽다.
2. 「캘린더가공비」 전용 구성요소가 **라이브에 존재하지 않는다**(캘린더 계열 comp 전수:
   `COMP_BIND_CAL_WALL` 제본비 · `COMP_ACC_ENV_ETC` 봉투/케이스뿐). 대안 표가 없다.
3. 이번 세션 방침(지니) —「공정을 눌렀을 때는 어떤 형태를 하더라도 **동일한 가격테이블**을
   중심으로」— 이 타공에도 그대로 적용된다.

⇒ **주석이 열거형인지 예시인지 실무진 확인이 남는다.** 예시가 아니라 배타적 열거라면
엽서캘린더의 타공은 별도 단가여야 한다.

### 5.2 권위 §19 는 「캘린더가공비 = [가공비] X [제작수량]」인데 이 표는 합가다

권위 §19 캘린더: 판매가 = 인쇄비 + 용지비 + (제본비 **or 캘린더가공비**),
(3) 캘린더가공비 = [가공비] **X [제작수량]** — 수량을 곱한다.

반면 타공(합가) 표는 **작업 1건 고정**(수량을 곱하지 않음)이다. 계산 형태가 다르다.

헤더택 `045` 도 같은 표를 합가로 쓰고 있고 대안 표가 없으므로 현재 배선이 최선이나,
**엽서캘린더의 타공이 「캘린더가공비」 계열이라면 단가 자체가 달라야 한다.**
