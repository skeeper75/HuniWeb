## 2단계 — 옵션 가격축 값 대조 (27/27 일치)

M4-22 는 **조합 수만** 냈고 값은 재지 않았다. 이제 권위 위치를 알았으므로 단가를 대조했다.

| 상품 | 옵션 수 | 권위 | 결과 |
|---|---:|---|---|
| `PRD_000138` 일반현수막 | 10 | 가격표 r246~251 (가공 c10/c11 · 추가 c13/c14) | **10/10** |
| `PRD_000139` 메쉬현수막 | 6 | r267~270 | **6/6** |
| `PRD_000124` 린넨패브릭포스터 | 5 | r105~109 | **5/5** |
| `PRD_000133` 캔버스 행잉포스터 | 3 | 상품악세사리 r60~62 (우드행거 230/320/440mm) | **3/3** |
| `PRD_000134` 린넨우드봉족자 | 3 | 가격표 r226 (A4/A3/A2) | **3/3** |

이름은 다르고 값은 같다 — 권위 「타공(4개)」 = 라이브 「아일렛(4구)」, 권위 「양면테잎」 = 라이브 「양면테입」.
이름 차이를 결함으로 세지 않도록 값으로 대조했다.

린넨패브릭 마감 5종: 오버로크 0 · 오버로크+리본끈 800 · 말아박기 1,000 · 말아박기+면끈 2,000 · 봉미싱(7cm) 2,000.

### 이중 합산 실증 — 없다

메쉬현수막의 큐방·끈이 **두 구성요소에 중복 등록**되어 있다
(`COMP_BANNER_MESH_ADDON` + `COMP_POSTEROPT_BANNER_MESH_ADD_QBANG_4`, 값은 동일).
이중 합산이면 돈이 두 번 붙으므로 실증했다.

```
옵션 없이 : {"total": 21600}
큐방 선택 : {"total": 24600}      차이 3,000 = 큐방 단가 1회분 (2회 아님)
```

**가격은 1회만 붙는다.** 데이터 중복은 정리 대상이나 가격 결함은 아니다.

### 남은 것

값은 전부 맞지만 **38조합을 API 로 전수 실행하지는 않았다.** 큐방 1건만 실호출로 확인했다.
단가가 맞고 이중 합산이 없으므로 위험은 크게 줄었으나, 「모든 조합에서 그 단가가 붙는가」는 미검증이다.

## 3단계 — 고아 템플릿 50건 실태

「어느 상품에도 붙지 않은」 50건을 갈랐다.

| base 상태 | 단가 | base 위젯 게시 | 건수 | 해석 |
|---|---|---|---:|---|
| LIVE | 있음 | O | **30** | 준비는 끝났고 배선만 없다 |
| LIVE | 없음 | O | 15 | 조합형 — base 계산에 위임 (정상) |
| LIVE | 있음 | X | 3 | base 상품 자체가 미게시 |
| DEAD | 없음 | X | 2 | `TMPL-000010/011` 카드봉투 = M4-23 결함 2건 |

### 부분 배선 9건 — 형제는 붙었는데 이것만 빠졌다

같은 base 의 다른 템플릿은 상품에 붙어 있는데 이것만 미배선인 경우가 9건이고, **전부 봉투류**다.

| base 상품 | 권위 사이즈 | 템플릿 | 배선됨 | 미배선 |
|---|---:|---:|---:|---:|
| `PRD_000001` OPP접착봉투 | 11종 | 11 | 7 | **4** (80x180 · 100x200 · 160x230 · 230x350) |
| `PRD_000002` OPP비접착봉투 | 11종 | 11 | 10 | **1** (150x150) |
| `PRD_000283` 트레싱지봉투 | 8종 | 8 | 4 | **4** (160x110 40장 · 100x100 20/40/100장) |

**템플릿은 권위대로 전부 만들어져 있고 단가도 권위와 일치한다.** 빠진 것은 상품에 붙이는
`t_prd_product_addons` 배선 9종뿐이며, 그 결과 고객은 그 사이즈를 살 수 없다.
「데이터 없음」이 아니라 **「연결 안 됨」**이다.

의도적 미출시인지 배선 누락인지는 DB 가 답할 수 없다 — **실무진 확인 사항**이다.
다만 같은 상품의 다른 사이즈가 모두 붙어 있다는 점에서 누락 쪽에 무게가 실린다.

나머지 41건은 형제도 전부 미배선이라 상품군 단위로 아직 열지 않은 것으로 보인다.
