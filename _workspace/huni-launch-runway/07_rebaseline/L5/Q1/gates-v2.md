## 0. 무통장이 무엇을 앞당기는가 — 근거부터

| 사실 | 근거 |
|---|---|
| 무통장 주문은 **주문번호가 발급되고 재고가 차감된 「입금대기」** 로 성립한다 | `L0/N1/shopby-order-state-machine.md` T2 · §4-2 「입금대기 상태의 주문 건부터 재고가 차감된다」 |
| 운영자가 셀러어드민에서 **[입금확인 처리]를 수동 클릭**하면 「결제완료」가 된다 | 같은 문서 T4 |
| 그 전이는 **입금대기 주문리스트에서만** 가능하고, 결제완료로만 바꿀 수 있다 | 같은 문서 B2 |
| 입금기한을 넘기면 **자동취소(환불없음)** 된다 | 같은 문서 C1 |
| 후니 주문 등록은 **결제 완료를 기다리지 않는다** — 입금대기여도 등록한다 | `L0/M2/_evidence/sdk-guide-live-20260902.txt:495`, `:873` |
| 결제 완료 판별은 **`CHANGE_ORDER_STATUS` 웹훅의 상태값**으로 한다(전용 이벤트 없음) | `L0/N1/webhook-catalog.md:278` · §1.3 |
| **판매중 226건 전건 게스트 구매 가능**(297건 전건 `nonmemberPurchaseYn = Y`) — 무통장 관통을 **게스트로 돌릴 수 있다** | `L5/Q2/api-check-a13-a5.md` §2 (라이브 실측 09-02) |
| **`viewShopSpecification = false`** — 거래명세서는 고객에게 안 보인다 · **`cashReceipt = false`** — 현금영수증이 꺼져 있다 · **`pgType = null`** — 몰에 PG 미연동 | 같은 문서 §3 |

**바뀌지 않는 것**: 카드·계좌이체 등 **PG 수단 승인은 여전히 9/7(월) MID 신청 마감**이다(`L5/P1/feasibility-verdict-v2.md` §2-3). 무통장은 「먼저 돌려볼 길」이지 오픈 결제수단의 대체가 아니다.

> **9/23(수)은 게이트가 아니라 교정일로 비운다.** — v1 그대로.
