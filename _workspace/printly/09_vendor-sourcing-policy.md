# 09 · 벤더 배정(소싱) 정책 — 소비자는 비교 안 본다, 프린틀리가 상품군마다 배정한다

> 작성: 2026-07-05 (5세션) · 트리거 = 지니 재구성 4점("소비자는 인쇄소를 모른다·제휴사 기준
> 한 가격만 보여준다·상품군마다 어디로 할지 기준을 정한다·그래서 후니·와우 전 상품을 먼저 등록했다").
> **이 문서 = 프린틀리 벤더 선택의 정본 정책(keystone). 06의 "소비자가 크로스벤더 비교를 본다"는
> 프레임을 교정한다.** 상태: ★모델·뼈대 확정(relitigate 금지) · 배정 잣대 2건 = 지니 입력 대기(§4).

## 0. 핵심 재구성 (지니 확정 · relitigate 금지)

- **소비자는 벤더 가격비교를 보지 않는다.** 소비자는 **프린틀리가 배정한 한 곳의 가격 하나만** 본다.
  어느 인쇄소가 만드는지 소비자는 **모른다**(화이트라벨 브로커).
- 따라서 크로스벤더 가격비교(A-1 산출·`crossbrand_query.py`)는 **소비자 기능이 아니라
  지니(사업자)의 내부 소싱 결정 도구**다. "명함은 후니로? 와우로?"를 지니가 판단하는 화면.
  → 소비자한테 안 보이므로 이 내부 화면에서는 **순위를 정직하게 매기는 게 오히려 필요**(A-1의 정직한
  기준이 그대로 쓸모). ★단 공정 비교 위해 양쪽 **부가세 전 공급가** 기준 정렬 필요(§3).
- **후니·와우 전 상품 선등록 이유** = 상품군별 배정을 제대로 정하려면 양쪽 전체 카탈로그를 다 봐야 함(4세션 와우 324 등록·후니 §33 275).

## 1. 벤더 관계 (배정 경제성의 전제)

| 벤더 | 관계 | 프린틀리의 "원가" | 배정 우선순위 |
|---|---|---|---|
| **후니프린팅** | ★**공동사업 파트너**(지니가 후니 인쇄 자동견적서비스 **전권** 보유) | 후니 공급가(부가세 전·evaluate_price) — 공동사업이라 통제·경제성 최상 | **기본(default)** |
| **와우프레스** | 외부 파트너(도매로 사옴) | 와우 도매가(devshop `ordcost_sup` 부가세 전 / `ordcost_bill` 부가세 포함) | 전환(fallback) |
| 레드 | 미연결(향후) | 지니 WebToProduct 엔진 | 미착수 |

## 2. 배정 기준 뼈대 (v0.3 · 확정 · 지니 260705 정적→동적 교정)

★핵심 교정(지니): "능력"은 **정적(장비가 있냐)이 아니라 동적(지금 그 장비가 이 납기에 실제로 돌 수 있냐)**.
후니가 만들 수 있어도 **가동률·유휴시간이 안 맞으면 납기 차질** → 다음 생산지로 넘겨야 함. 공동사업(후니)이라도
장비 한계로 못 만들 땐 다른 결정. ★생산지가 늘수록 고려 요소가 증가 = 궁극은 **동적 주문 라우팅**.

배정 결정 = **3층 (정적 → 동적 → 경제성)**:

- **1층 — 정적 능력(온톨로지/카탈로그):** 이 인쇄소가 이 상품·사양을 **원리상** 만들 수 있나? 못 하면 후보 제외.
  (예: 매장용품 POP = 후니 미대응 → 후보 제외. A-5 비대칭.)
- **2층 — 동적 생산가능성·납기(실시간 상태):** 만들 수 있어도 **지금 그 장비가 이 주문을 필요 납기 안에
  돌릴 수 있나?** (가동률·유휴·현재 큐·특허 **C1 생산시간예측**). 못 맞추면 다음 후보로. ★이 층이 지니 교정 핵심.
- **3층 — 경제성·소비자 이득(사람 판단):** 1·2층 통과한 후보 중 [후니 기본] + 원가·소비자가·품질 **균형** 판단.
  후니가 1·2층 통과하면 기본 후니, 와우가 "확실히 나으면" 전환.

- **판단 도구 = 상품군별 배정 검토표**: [정적능력 · (표준)납기 · 후니 원가 · 와우 원가]를 나란히, 후니 기본에
  전환 신호가 있으면 표시. **최종 선택은 지니**(균형·자동 최적화 아님).

### 2.1 두 지평 (지금 정책 vs 미래 런타임)
- **정책층(지금 정함)**: 상품군별 **기본 배정 규칙** + 판단 요소 정의. 납기는 **표준 리드타임**(상품별 기본)으로 시작.
- **런타임층(미래·해소 경로 명확)**: 주문 시점 **실시간 생산상태**로 동적 라우팅(가동률·유휴·큐). §35 라우팅 층·
  fulfillment_order(E24)·특허 C1이 이 자리.
  - ★**데이터 GAP 해소 경로(지니 260705)**: 지니가 **후니프린팅 인쇄 자동견적 서비스를 직접 구축 중** →
    와우처럼 **API/MCP로 가동률·납기를 노출**하게 되면 후니 실시간 부하 자동 확보(영구 결함 아님·로드맵). 와우 이미 API.
  - ★**어댑터 인터페이스 = API/MCP**: 각 인쇄소 = 어댑터 1개(견적 + 생산가능성/납기 동시 제공). 브로커 구조·특허 C3
    장비가상화(단일 API)와 정합. 와우 jobcost는 출고예정일(exitday/exitdate) 반환(표준/실부하 여부는 확인 필요).
- **단계**: v1=표준 리드타임으로 시작(지금 착수) → v2=후니 서비스 API/MCP 연동 시 실시간 가동률 2층에 주입.
- **설계 원칙**: 벤더가 늘수록 요소가 증가하므로 처음부터 **"요소를 더할 수 있는" 구조**(1·2층 후보 필터 + 3층 가중).

## 3. 부가세 기준 (확정 · 260705)

- **후니 = 부가세 별도(공급가) 확정.** 근거: 이전사이트 huniprinting.com/product/goods.asp가 가격을
  "공급가 : N원(부가세 전)"으로 표시(`_foundation/batch/golden_fetch.py`)·evaluate_price 엔진 부가세 미가산·
  새 시스템 스키마 VAT_RATE=0.1 별도 가산. → `printshops/huni.json` price_basis.vat_included=false.
- **와우 = ordcost_bill 부가세 포함**(공급가 ordcost_sup + 부가세 ordcost_tax). 부가세 전 = `ordcost_sup`.
- **원가 공정 비교** = 후니 공급가 ↔ 와우 `ordcost_sup`(둘 다 부가세 전). ★현재 레시피는 `ordcost_bill`만
  저장 → 배정표 전에 **와우 `ordcost_sup`(부가세 전) 재수집 필요**(devshop·GAP-BASIS-3).

## 4. 미정 — 남은 결정 (지니 입력 대기)

기준 완성 전 정해야 할 것(빌드 착수 게이트):

1. ~~"확실히 낫다" 잣대~~ → **부분 확정(지니 260705)**: 납기/생산가능성은 "확실히 낫다" 티어가 아니라
   **2층 하드 게이트**로 승격(장비 가동률·유휴로 후니가 납기 못 맞추면 전환). 3층 경제성 판단의 잣대는
   여전히 "상품 성격별 균형"(저가대량=가격·고급=품질) 권장 유지.
2. ~~소비자 "한 가격" 매기는 법~~ → **확정(지니 260705)**: **원가 + 마진율.** 원가=인쇄소 제휴 조건
   (기여도·"우리 시스템으로 주문 받는" 조건)으로 정함·거기에 지니 마진율. 소비자가 = 원가 + 마진(+ 부가세).
   → **배정표 계산 가능 = 기준 완성.**
3. ~~v1 범위~~ → **확정(지니 260705)**: 납기 v1=**표준 리드타임으로 시작**. 실시간 가동률은 지니가 구축 중인
   후니 자동견적 서비스가 **API/MCP로 노출** 시 v2로 주입(해소 경로 명확). → 남은 유일 게이트 = **2번(소비자 가격)**.

## 5. 정체성·포지셔닝 (지니 260705 · relitigate 금지)

★**가격 정책의 근거 = 프린틀리의 정체성.** 이걸 놓치면 배정·가격 판단이 전부 어긋난다.

- **소비자는 인쇄 벤더 가격을 비교하지 않는다.** 소비자의 실제 선택지 = *"프린틀리로 쉽게"* vs *"디자이너/대행 고용"*.
  → 후니·와우 배정은 **순전히 프린틀리의 마진·안정성 문제**(소비자는 어느 쪽이든 이미 큰 이득).
- **경쟁자 ≠ 직접주문 인쇄사이트**(성원·와우프레스·오프린트미). 거긴 싸지만 **디자인 불가·인쇄용어 모르는
  소상공인에겐 "그림의 떡".** ★**경쟁자 = 디자인 대행사·크몽·숨고.**
- **프린틀리의 무기(moat) = 앞단 자동화**: AI 디자인 → **레이어 분리**(qwenimagelayered.com 방식) → 간단 에디터 →
  **각 인쇄소 규격 파일 자동 생성·전송**(WebToProduct·특허 C2 프리플라이트/C3 장비가상화). 대행 대비 **~1/5 예상**.
- **KPI(측정 대기)**: 대행사/크몽/숨고 대비 실제 절감률(가설 1/5) 정량 측정 필요(지니 명시).
- **함의**: "소비자 이득"(3층) = 최저 인쇄가 아니라 **접근성·done-for-you·대행 대비 저렴**. 배정 판단은 프린틀리
  경제성 중심(단 소비자가가 대행보다 확실히 싼 선은 유지).
