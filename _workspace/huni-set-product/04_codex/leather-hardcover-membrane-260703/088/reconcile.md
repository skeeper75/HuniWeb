## 2. 불일치·codex 신규 리스크 → 라이브 3자 판정 (읽기전용 SELECT 2026-07-03)

### 2-1. [codex 유일 신규 리스크] 089~093 직접단가 0건 → ★RESOLVED (설계 지지·강화)

- codex 지적: evaluate_price는 구성원을 무조건 진입시켜 **직접단가(t_prd_product_prices)를 먼저** 조회(pricing.py:470).
  따라서 "가격공식 0건"만으로는 "기여 0"이 논리적으로 불완전 — **직접단가 0건까지** 확인돼야 돈크리티컬 판정 완결.
- **라이브 실측**:
  ```
  t_prd_product_prices WHERE prd_cd IN (089,090,091,092,093) → 0건 (빈 결과)
  ```
- 코드 확인: 직접단가 부재 + 공식 부재 → evaluate_price가 `base_amount = Decimal(0)`(pricing.py:490~496) 반환 → member contribution = 0.
- 3자 결론: codex의 예방적 지적은 **정당**(설계 삼각확인이 공식 0건만 명시하고 직접단가는 암묵). 라이브가 **직접단가 0건 확증** →
  "면지 기여 0" 주장이 **완전**해짐. 설계 지지 + 게이트 실증 큐에 명시 편입. **CLOSED**.

### 2-3. [codex 골든 문구 구분] → 설계와 실질 합의 (오독 방지)

- codex: "088-redesign COMMIT 후에도 **현행 COVERBIND 골든 유지**"라는 의미면 DISAGREE.
- 설계 §2.3/§3(golden-reproduce) 실제 문구: **COVERBIND 현행 위=34,100/159,100/796,900** · **088-redesign COMMIT 후=39,000/290,000/1,800,000**(재설계 골든)로
  **두 모델 골든을 이미 명확히 구분**. 즉 설계 주장은 "면지 통합이 **각 표지모델의 골든을 오염하지 않는다**"(면지 기여 0)이지,
  "재설계 후에도 현행 골든이 남는다"가 아님 — **codex가 AGREE라 한 해석과 동일**.
- 3자 결론: **실질 합의**. codex 지적은 문구 오독 가능성 경고 → reconcile에서 해석 고정("각 모델 골든 중립"). 설계 수정 불요.

## 4. 최종 의견

**설계 지지 (GO) — 게이트 실화면 실증 조건부.** codex 판정 **CONDITIONAL GO**와 수렴.

- codex ↔ Claude 설계 **11/11 실질 합의**. codex 신규 리스크 1건(직접단가 0건)은 라이브가 **0건 확증** → 골든 무손상 주장 완결·강화.
- 태스크 4대 수렴 판정(라이브 실측):
  - **골든 무손상**: ✅ 수렴 — 공식 0건 + **직접단가 0건**(codex 보강) → 기여 0, 현행 골든 34,100/159,100/796,900 실엔진 재현.
  - **USAGE.07 D링 보존**: ✅ 수렴 — apply usage_cd='USAGE.03' 격리, MAT_247/248/249 활성 잔존 실측.
  - **088-redesign 직교**: ✅ 수렴 — 미적재 마커 3종 0건, 겹치는 행 0, 골든 각 모델 중립(문구 해석 고정).
  - **오차단 0(false-positive)**: ✅ 수렴 — 089 무공식·면지 무공식·D링 미터치·091~93 은퇴 전부 정당(정상 셋트 구조 오판 0·codex도 동일 확인).
- 잔여 = 화면 발현 2건(면지 4택1 UI·PRICE≠0)만 게이트 몫 → **설계 결함 아님**(런타임 실증). 선존 D-3(인쇄면지 인쇄비 0)은 본 재설계 무손상 보존만·후속 §18.
