# D. 소재·보정 시트 이해 — 출력소재IMPORT · 판걸이수 · 굿즈파우치구간할인

> 대상 엑셀: `docs/huni/후니프린팅_인쇄상품_가격표_260702.xlsx` (openpyxl 직접 정독, 읽기전용).
> 목적: **진단 아님 = 권위 문서 이해**. 각 시트가 "어떻게 읽혀 최종 상품가에 들어가는지"를 실제 셀 인용으로 규명.
> 표기: `[UNKNOWN]`=모름 · `[AMBIGUOUS]`=애매. 값 날조 없음 · 모든 값은 260702 엑셀 실 셀.

## 0. 한 줄 결론

세 시트 모두 **상품명 시트(본체 가격표)가 아니다 = 보조/기반 테이블**이다. 본체 단가행에 값을 직접 쓰지 않고, **본체 계산의 입력**으로 참조된다.

| 시트 | 계층 역할 | 최종가에 들어가는 방식 | 값의 단위 |
|---|---|---|---|
| 출력소재(IMPORT) | **재료원가 기반(base cost)** | 용지비 = 절가 × 전지매수 | 연당가(원/연) → **절가(원/장)** |
| 판걸이수 | **수량→전지 환산 보정(modifier)** | 전지매수(판수) = ⌈주문수량 ÷ 판걸이수⌉ | 판걸이(개/전지, 무차원 정수) |
| 굿즈파우치(구간할인) | **수량 할인 보정(modifier)** | 최종가 = 소계 × (1 − 할인율) | 할인율(0~0.5, 배율) |

→ **출력소재 × 판걸이수가 한 쌍으로 용지비를 만든다**: 절가(원/장) × 판수(장). 굿즈파우치는 그 뒤 소계에 곱해지는 할인.

## 1. 시트: 출력소재(IMPORT) — 종이 원가 기반값 (base cost)

### 1-1. 원본 레이아웃
- 시트 인덱스 1, 데이터 행 = 2~약100 (총 1001행이나 유효 종이행 80개).
- **헤더(1행)**: `대분류 | 중분류 | 종이명 | 평량 | 파일명약어 | 구매정보 | 전지 | 연당가 | 가격(국4절) | 가격(3절) | 종이사이즈 | [프리미엄엽서 | 스탠다드엽서 | 2단접지카드… | … | 벽걸이캘린더]`
- 축: **행 = 종이(자재)** · **좌측 열 = 종이 속성/가격** · **12열 이후 = 상품군 적용 매트릭스(● 마크)**.
- 실제 셀 인용:
  - r4 `백색모조지 100g, 평량100, 약어 백모조, 전지 국전(939*636), 연당가 61460, 가격(국4절) 30.73`
  - r43 `띤또레또 200g, 전지 464*320, 연당가 122500, 가격(국4절) 245`
  - r68 `투명 PET 260g, 전지 None, 연당가 110000, 가격(국4절) 1100`
- 12열 이후 `●`: 그 종이를 쓸 수 있는 상품군 표시. 예 r6 `백색모조지 220g`에 `프리미엄엽서 ●, 스탠다드엽서 ●, 프리미엄명함 ●, …` → **종이×상품 적용 가능 매트릭스**.

### 1-2. 역할 (최종가 진입 방식)
- **본체 단가의 재료원가(용지비)** 를 공급하는 기반 테이블. 상품 본체 시트가 "이 상품 = 이 종이" 매핑을 갖고, 그 종이의 **절가(원/장)** 를 여기서 끌어온다.
- 용지비 = **절가 × 전지매수**. 전지매수는 판걸이수 시트가 결정(§2). 즉 이 두 시트가 한 쌍.

### 1-3. 값의 의미 (단위)
- `연당가` = **1연(ream) 가격, 원/연**. 1연 = 전지 500장.
- `가격(국4절)` / `가격(3절)` = **절가 = 재단 낱장 1장당 원가, 원/장**. 인쇄 계산에 실제로 쓰이는 값.
- **연당가 → 절가 환산 비율(실측)**:
  - 백모조 100g: 61460 / 30.73 = **2000** (국전 1전지 = 국4절 4장, 500전지×4 = 2000장/연)
  - 띤또레또 200g: 122500 / 245 = **500** (전지 464×320 자체가 국4절 크기 → 500장/연)
  - 투명 PET 260g: 110000 / 1100 = **100** (전지 None, 장당 매김)
  - 스티커류(전지 330×480): 149500 / 499 ≈ **300**, 253700/846≈300, 222000/740=300 → 연≈300장
  - → **환산 divisor가 종이군마다 다르다(2000/500/300/100)**. 전지 규격·재단 방식 차이 반영. `[AMBIGUOUS]` 이 divisor가 시트 어딘가 명시돼 있지 않고 역산으로만 확인됨(연당가·절가 둘 다 실 셀이므로 값 자체는 확정).

### 1-5. [아는 것 / 모르는 것 / 애매한 것 / blind spot]
- **아는 것**: 행=종이, 연당가=원/연, 절가(국4절·3절)=원/장이 실제 인쇄계산 입력. 260702에서 크라프트/홀로그램 하락·투명후지 신규. ● = 종이×상품 적용 매트릭스.

- **blind spot**: `종이사이즈`(11열)와 `전지`(7열)가 일부 종이에서 불일치/None(PET·스티커). 실사출력·아크릴·레더하드커버 행은 연당가/절가 모두 None(장당가 아닌 다른 가격모델 = 국4절 열에 4000/7000/Roll 같은 이질값) → **이 시트에 종이 외 소재(아크릴·레더·PVC)도 섞여 있고 가격모델이 균질하지 않음**.

## 2. 시트: 판걸이수 — 수량→전지 환산 보정 (imposition modifier)

### 2-1. 원본 레이아웃
- 시트 인덱스 0, 데이터 행 = 2~105 (총 104 사이즈행, 이후 1070행까지 빈행).
- **헤더(1행)**: `사이즈옵션명 | 재단사이즈 | 블리드 | 작업사이즈 | 상품 | 판걸이 | 디지털인쇄(국4절) | 디지털인쇄(3절) | [반칼 sheet size 열] | 인쇄가능영역 | 원형아이마크영역(완칼) | 격자아이마크영역(반칼)`
- 축: **행 = (사이즈옵션 × 상품)** · 열 = 사이즈 상세 + **판걸이(핵심값)** + 출력용지규격(전지) 선택 열.
- 실제 셀 인용:
  - r2 `73 x 98 mm, 재단 73x98, 블리드 1, 작업 75x100, 상품 엽서, 판걸이 18, 국4절 전지 316x467`
  - r9 `90 x 50 mm, 상품 명함, 판걸이 24, 316x467`
  - r33 `600 x 150 mm, 상품 지그재그카드, 판걸이 2, 3절 전지 330x660`
  - r76 `썬캡, 작업 320x404, 판걸이 1, 전지 330x540`
  - r77 `A6, 상품 반칼스티커, 판걸이 8, [반칼열] 317x440`

### 2-2. 역할 (최종가 진입 방식)
- **수량 → 필요 전지매수 환산 보정**. 판걸이 = "전지 1장에 몇 개 앉느냐(imposition)".
- 라이브 흐름: **판수(전지매수) = ⌈주문수량 ÷ 판걸이⌉** → 용지비 = 절가(§1) × 판수, 인쇄비 = 전지단가 × 판수.
- 즉 이 시트는 **§1 출력소재(절가)와 곱해져 용지·인쇄비를 만드는 짝**. 전지 선택 열(국4절 316×467 / 3절 330×660 / 반칼 317×440)은 어느 출력용지규격 위에 앉히는지도 지정.

### 2-3. 값의 의미 (단위)
- `판걸이` = **개수(정수, 무차원)** — 전지 1장당 제품 앉힘 수. 예 엽서 73×98=18, 명함 90×50=24, 썬캡=1.
- `블리드`=재단여분(mm), `작업사이즈`=블리드 포함 실 배치 크기(mm), `인쇄가능영역/아이마크영역`=재단 여백 규칙(텍스트). 이들은 판걸이 산출의 근거 입력.

### 2-4. 판수 이중권위 확인 ★ (사이즈시트 vs 상품마스터 판수 — 충돌 실재)
HANDOFF `pansu-repro-bothauth` 기록대로 **두 권위가 실제로 다르다**. 260702 판걸이수 시트값(A)과 상품마스터 판수(B, `auth-pansu-all-260701.json` = 자재/상품별)를 대조:

| 상품/사이즈 | (A) 판걸이수 시트 | (B) 상품마스터 판수 | 충돌? |
|---|---|---|---|
| 엽서 73×98 | **18** (r2, 상품="엽서" generic) | 프리미엄엽서 **15** / 코팅 15 / 스탠다드 15 | ✔ 다름 |
| 엽서 98×98 | **12** (r3) | 투명엽서 **8** (자재 반영) | ✔ 다름 |
| 엽서 135×135 | **6** (r5) | 투명엽서 **4** | ✔ 다름 |
| 2단접지카드 110×170 | **2** (r27, "2단세로접지") | 2단접지카드 **8** | ✔ 다름(방향/키 해석차 가능) |
| 스탠다드엽서 148×210 | **4** (r8, 상품="엽서") | 스탠다드엽서 **6** | ✔ 다름 |

- **핵심 차이**: (A) 시트는 **사이즈+상품군 단위(자재 무관)**, (B) 상품마스터는 **상품(자재)별** = 투명PET 등 임포지션 차이를 반영. 그래서 투명엽서에서 A(12) > B(8) → A로 계산 시 저청구 방향.
- 개발요청서(`DEV-REQUEST-fn-calc-pansu-260701.md`)가 이미 규명: 현행 엔진 `fn_calc_pansu`는 순수 기하패킹(면적÷면적, 물림변·칼선간격·자재 무반영)이라 A·B 어느 쪽과도 어긋나고(±7~80%), 썬캡은 0 반환 → 견적불가. **정답 서열 = 실무진 판걸이수(권위) 우선**, 단 **A vs B 단일화는 예전사이트(goods.asp) 실청구를 tiebreaker로 확정 필요(미해결)**.
- **확인 결론**: 이중권위 충돌은 문서상 주장이 아니라 **실 셀로 재현됨**. 이 판걸이수 시트 = 사이즈 단위 generic 권위, 상품마스터 판수 = 자재 단위 권위. 둘이 다를 때 자재 반영이 필요한 종이(투명 등)는 상품마스터 쪽이 production-truth일 개연성이 높으나 최종 확정은 ASP 실청구 대조 대기.

### 2-5. [아는 것 / 모르는 것 / 애매한 것 / blind spot]
- **아는 것**: 판걸이=전지당 앉힘수(정수), 판수=⌈수량/판걸이⌉로 용지·인쇄비에 진입. 시트는 사이즈+상품 키(자재 무관). 전지선택 열도 지정.
- **모르는 것**: A/B 중 어느 값이 라이브 `t_siz_pansu`/`fn_calc_pansu`에 실제 채택돼 청구되는지(적재 상태 = 진단 영역). 개발요청서상 엔진은 아직 기하계산(둘 다 미채택) 상태.
- **애매한 것**: 2단접지카드류는 시트에 세로/가로접지가 각각 행으로 있어(r19~32) 상품마스터 단일 키와 정렬이 어긋날 수 있음 — 위 표 110×170 충돌이 순수 값차이인지 키정렬차이인지 `[AMBIGUOUS]`.
- **blind spot**: 판걸이수 시트에 `상품` 값이 "엽서 / 엽서북내지"처럼 슬래시 다중귀속(r4·r5)이라 상품→행 조인이 1:N. 반칼스티커·캘린더는 전지열이 국4절 아닌 반칼/3절 열로 분리 → 상품군마다 어느 전지 열을 읽는지 규칙 필요.

## 3. 시트: 굿즈파우치(구간할인) — 수량 할인 보정 (quantity discount modifier)

### 3-1. 원본 레이아웃
- 시트 인덱스 17, 데이터 행 = 1~44 (이후 빈행). **5개의 독립 할인표가 세로로 나열**.
- 각 표 = `제목행(적용상품 명시) → 헤더(수량구간|할인율) → 구간 행들`.
- 실제 셀 인용:
  - r1 `파우치상품 수량별 구간할인 | | 파우치+에코백 전체`
  - r2 `수량구간 | 할인율`, r3 `1~49 | 0.0`, r4 `50~99 | 0.05`, r5 `100~499 | 0.1`, r6 `500~999 | 0.15`, r7 `1000~10000 | 0.2`
  - r10 `문구상품 수량별 구간할인` (동일 5구간, 0/0.05/0.1/0.15/0.2)
  - r19 `굿즈상품 수량별 구간할인 A타입` (동일 5구간)
  - r28 `굿즈상품 수량별 구간할인 B타입 | | 핀버튼/틴거울/컴팩트거울/머그컵/카드거울/틴케이스/극세사클리너/반팔티셔츠/초슬림마우스패드`, r30 `1~99|0.0`, r31 `100~499|0.05`, r32 `500~10000|0.1`
  - r35 `말랑상품 수량별 구간할인 | | 말랑키링/말랑포카홀더/말랑네임택/말랑여권케이스`, r37 `1|0.0`, r38 `2~9|0.1`, r39 `10~29|0.15`, r40 `30~49|0.2`, r41 `50~99|0.25`, r42 `100~499|0.3`, r43 `500~999|0.4`, r44 `1000~10000|0.5`

### 3-2. 역할 (최종가 진입 방식)
- **수량 구간별 할인율 곱(modifier)**. 본체 단가가 아니라, 계산된 소계에 **(1 − 할인율)** 을 곱하는 최종 보정.
- 상품군별로 **어느 할인표를 쓰는지**가 제목행의 적용상품 목록으로 결정(파우치/에코백, 문구, 굿즈A, 굿즈B[핀버튼 등], 말랑[말랑키링 등]).
- 요약 기록상 타깃 그릇 = `t_dsc_*`(구간할인 테이블). 본 하네스(가격테이블 무결성 §26 component_prices diff) **범위 밖(OUT_OF_SCOPE)** 으로 분류됨.

### 3-3. 값의 의미 (단위)
- `수량구간` = 주문수량 범위(예 `100~499`, 상한 10000). `말랑`은 `1` 단건 구간부터 시작.
- `할인율` = **배율(0~0.5)**. 0=할인없음, 0.2=20%. 말랑상품이 최대 50%로 가장 공격적, 굿즈B는 3구간 최대 10%로 완만.
- 적용 = 소계 × (1 − 할인율). **음수·1 초과 없음** = 순수 할인.

### 3-4. [아는 것 / 모르는 것 / 애매한 것 / blind spot]
- **아는 것**: 5개 할인 프로파일(파우치/문구/굿즈A/굿즈B/말랑), 값=구간별 할인율(배율), (1−율) 곱 방식. 굿즈B·말랑은 구간 구조 자체가 다름(각각 3구간/8구간).
- **모르는 것**: 소계의 정확한 정의(할인 적용 base가 자재+인쇄+후가공 전부인지, 본체만인지) — 이 시트엔 없음(본체 시트/엔진 소관). t_dsc_* 라이브 적재 여부는 범위 밖.
- **애매한 것**: 파우치·문구·굿즈A 세 표가 **값이 완전 동일**(0/0.05/0.1/0.15/0.2) — 별도 표로 나눈 이유가 상품군 라우팅 편의인지 향후 분화 대비인지 `[AMBIGUOUS]`. 굿즈A는 제목행에 적용상품 목록이 없어(빈칸) "굿즈B/말랑에 안 잡힌 나머지 굿즈"라는 fallback 해석 `[AMBIGUOUS]`.
- **blind spot**: 상한 `10000` 초과 수량, 구간 경계 겹침(예 굿즈B `500~10000` vs A `500~999`)에서 어느 표를 적용할지 = 상품→표 배정이 선결. `수량구간`이 문자열(`"100~499"`)·일부 정수(`1`)로 혼재 → 파싱 규칙 필요.

## 4. 공통 blind spot 요약

1. **세 시트 모두 "본체 가격표가 아님"이 확정** — 출력소재=재료원가 공급, 판걸이수=수량→전지 환산, 굿즈파우치=수량 할인. 최종가는 (본체 시트 + 엔진)이 이들을 **입력으로 조합**해야 나옴. 이 문서만으로 상품가 단독 산출 불가(본체 매핑 필요).
2. **출력소재 ↔ 판걸이수는 한 쌍**: 용지비 = 절가(출력소재, 원/장) × 판수(판걸이수 기반, 장). 둘 중 하나만 이해하면 용지비 오판.
3. **판수 이중권위(사이즈시트 A vs 상품마스터 B) 미단일화** = 가장 큰 미해결 리스크. 자재 반영 필요 종이(투명PET 등)에서 방향성 있는 오차. tiebreaker=예전사이트 실청구 대조(대기).
4. **라이브 적재 상태는 이 문서에서 판정하지 않음**(=진단 영역). 요약 기록상 출력소재 32 specialty 미적재·판걸이/굿즈파우치 t_siz_pansu/t_dsc_* 타깃으로 대기 중이나, 본 이해 문서는 **권위 엑셀의 의미**만 확정.
5. **가격모델 비균질**: 출력소재 시트에 종이(절가형)와 비종이 소재(아크릴·레더·PVC=None/Roll/장당 이질값)가 섞여 있어, "행=종이·연당가 있음" 전제가 하단부에서 깨짐 — 종이류만 절가 모델로 읽어야 함.
