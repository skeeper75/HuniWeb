## 7. 전수 조사 재현 방법

화면이 쓰는 URL 에서 데이터를 통째로 받아 기계로 대조한다. **사람이 숫자를 옮겨 적지 않는다.**

```bash
B=~/.claude/skills/gstack/browse/dist/browse
set -a; . ./.env.local; set +a
$B goto https://huni-admin.printly.co.kr/admin/   # 로그인(세션 만료 시 재로그인)
$B cookies                                        # sessionid·csrftoken 추출 → curl 에 전달

# 3층 데이터
/admin/widget-manager/tree/                       # 게시 위젯 분모 (296 노드 · 게시 193)
/admin/product-viewer/{PRD}/                      # 상품: 사이즈·도수·자재·공정·판형·옵션그룹
/admin/price-viewer/{PRD}/diagram/                # 가격: 공식·구성요소·차원·단가행
/admin/catalog/tprcpricecomponents/?all=          # 구성요소 129: 유형·차원·비고
/admin/catalog/tprcpriceformulas/?all=            # 공식 118: 이름·비고
/admin/price-viewer/                              # 내장 데이터에 price_src 배지(FRM/PRC/NONE)
```

**규칙 설계 시 주의** — 1차 규칙은 과대 82·미수금 103 이 나왔고 **전부 노이즈**였다.
두 오탐을 반드시 제외한다:
- 구성요소 유형이 `완제품비` 면 개별 공정 미수금 판정에서 제외(인쇄비가 완제품가에 포함)
- 판별축 목록에 `사이즈가로(이하)`·`사이즈세로(이하)` 등 구간 축 포함(비규격 치수의 정당한 축)
