> **교정문**: 「쇼핑몰은 Shopby **shop-api**(IP 제한 없음)로 연동한다. 관리자용 **server-api**(등록 IP 전용)는
> 프록시·훅만 남아 있고 실사용 0건 — 쓸 계획이면 고정 IP 등록이 선행돼야 한다.」
> **런칭 리스크**: 사문 코드를 남겨 두면 런칭 직전에 되살아나 IP 미등록으로 막힌다.

## C-11 ★[불충분] 「프로모션 충돌 미확인」 — 대부분 닫혔고, 남은 하나는 더 나쁘다

초안 `:41`·`:168` 의 미확인.

**닫힌 것** — SDK 가이드 §11(2026-08-26/27 확정)이 답한다:
- **쿠폰 안전.** 샵바이 정액 쿠폰은 「상품별 총 상품금액 기준, **수량별로 할인되지 않음**」.
  예시 5,000원×3개 + 2,000원 정액쿠폰 → `(5,000×3)−2,000 = 13,000` ○ / `(5,000−2,000)×3` ✕.
- **적립금 안전.** 현재 미사용, 켜더라도 적립률(%)이 금액 기준.
- **배송비는 유형에 따라 치명적.** 금지: `QUANTITY_PROPOSITIONAL_FEE` · `QUANTITY_FEE` · `WEIGHT_FEE`
  (+ 상품 중량 입력). 허용: `FREE` · `CONDITIONAL` · `FIXED_FEE` · `PRICE_FEE` 넷뿐.
- 추가 금지: **1회 최대구매수량 제한**(= 결제 금액 상한) · **즉시할인**(= `(판매가−할인)×수량`).
- 후니 가격엔진에 배송비 이중청구 **없음** — `raw/webadmin/webadmin/catalog/` 전체
  `배송비|delivery_fee|shipping_fee` **0건**(내가 재실행).
- 몰이 상품쿠폰을 봉인 중 — `productCoupons: []` 하드코딩
  (`use-order-sheet.ts:55,278,369` · `use-order-coupons.ts:61`).

**닫히지 않은 것 — 그리고 이게 새로 나온 것이다.**
공지된 운영정책이 **금지 기능을 이미 약속하고 있다.**
`docs/huni/후니프린팅_운영정책_260827.xlsx` 「구매배송정보」 `r2c6`(내가 직접 열어 확인):

> ex) 사인상품 중 **실외용배너거치대, 현수막상품, 봉투상품은 1000장단위로 배송비부과** 상품으로
> 무료배송에서 제외됩니다. **실외용배너거치대는 수량1개당 배송비가 부과되며**, 봉투상품은 1000장단위로 배송…

이건 정확히 `QUANTITY_PROPOSITIONAL_FEE` 와 `QUANTITY_FEE` 다. 같은 시트 `r2c3` 의
「택배배송(선불 3000원) / **결제금액 기준 10만원 이상시 무료**」도 걸린다 — 라이브 재고가 전 상품 9,999 이고
`orderCnt = 총액÷10` 이면 **단건 상한이 99,990원**이라 10만원 기준선에 닿는 주문이 성립하지 않는다
(재고 초과 주문의 거절 여부는 **미확인** — 샵바이 테스트 주문으로만 닫힌다).
「할인쿠폰」 시트에 「**배송비는 쿠폰으로 결제하실 수 없습니다**」도 있어, 쿠폰이 완화책이 되지 못한다.

> **교정문**: 「프로모션 — 쿠폰·적립금 **안전**(금액 기준). 배송비는 **수량·중량 기준 영구 금지**.

## C-12 ★[누락] 헤드리스인데도 **샵바이가 고객에게 직접 수량을 내보내는 자리**가 있다

## 미확인으로 남긴 것 (라이브·사람으로만 닫힌다)

1. 샵바이 셀러어드민에서 금지 설정 4종이 실제로 꺼져 있는가 — 가이드의 주장이지 내 관측이 아니다

4. optionInputs 값 **길이 상한** — Shopby OpenAPI 에 `maxLength` 없음, 가이드 「미측정·150자 권장」,
   몰 주석 「~5000자+ 확인됨」. **근거 없는 삼자 충돌**이고 초과 시 실패 모드가 **조용한 절단**이다
5. `inputNo` 를 함께 실어야 하는가 — 가이드 스스로 미확인
6. shopby webhook 이 샵바이 쪽에 등록돼 있는가
7. 알림 템플릿 수량 치환 제거 시점 — 가이드 ★미확정
8. 세금계산서·현금영수증 수량 표기 대응 — **대응책 자체가 없다**
9. 가상계좌 입금기한 설정값(원고 보관 30일과 맞물림)
