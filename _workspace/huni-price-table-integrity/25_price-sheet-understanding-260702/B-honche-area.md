핵심 발견 3가지:
1. **아크릴 셀 = 개당 단가**, **포스터 셀 = 총액 포함가** — 같은 면적격자라도 값 의미가 다르다(근거 §1·§2).
2. **박(소형/대형)은 면적격자가 아니라 2단계 룩업** — 면적 격자셀 값이 **가격이 아니라 등급 문자 A~E**다(근거 §3·§4). 배치가 UNMAPPED로 기록한 근본 이유.
3. **박(백업) = 소형박을 명함 사이즈로 전개한 denormalized 백업표** — 등급 추상(A~E) 없이 명함 실사이즈 컬럼(10x20…20x60)에 직접 가격(근거 §5).

면적격자 헤더 구조(B01 실인용): 행 헤더 A열 = `가로 / 세로`(A2), 첫 데이터행 A3 `20mm`. 열 방향은 `20mm, 30mm, 40mm … 200mm`. 데이터셀 예: **B3(row_key=20mm, 열=20mm) = 2500**, C3(row_key=20mm, 열=30mm)=2700.
- 추출 규약(`matrix_parse.parse_l1_area`): **row_key(`<n>mm`) = 세로(height)**, **band_header_path 첫 토큰(`<m>mm`) = 가로(width)**, value = 단가.

### 1.2 차원 축
- 격자 축 = **가로mm × 세로mm** (2축). 소재/두께는 **블록 선택**으로 분기(투명3T=B01 / 투명1.5T=B02 / 미러3T=B03 / 코롯토=B05).
- 격자 범위(실측): B01 = 가로 20~200mm(14단) × 세로 20~200mm(14단) = **196셀**. B02·B03 = 20~100mm(9×9=81셀). B05 코롯토 = 30~80mm(6×6=36셀).
- 도수는 격자에 없음 — 제목에 `양면9도 / 단면7도 통용 단가`라 명시 = **단·양면 도수와 무관하게 같은 격자를 쓴다**("통용"). 도수는 별도 인쇄비/공정에서 처리(이 시트 밖).
- 수량은 이 격자에 없음. **B04 `아크릴상품 수량별 구간할인`**(1~49=0, 50~99=0.1, 100~299=0.2, 300~499=0.3, 500~999=0.4 …)이 곱해진다 → 최종가 = 단가 × 수량 × (1−할인율).

### 1.3 값의 의미
**개당 단가**(unit price). 근거: 제목 `… 통용 **단가**`, 그리고 별도 `수량별 구간할인`(B04)이 존재 = 셀 값이 총액이면 수량할인을 또 곱할 이유가 없다. P1 셀 주석 `아크릴모든 상품에 적용` = 이 단가 체계가 아크릴 전 상품 공통.
- [판정: 단가] — 총액 아님.

### 1.4 본체 vs 추가가격
- **본체** = B01/B02/B03/B05 면적격자(소재·두께별 단가).
- **추가** = B04 하단 `아크릴상품 후가공 옵션 및 단가`(네오디움자석 12mm, 색상 옵션 등) → 별도 합산. B06 카라비너 부속(자물쇠·하트 등 사이즈별 고정단가 5800~6900).

### 1.5 라이브 대조(참고, 비판용)
배치 기록: 권위 394셀 중 **313셀 일치(79.4%)·transpose 0·불일치 0**. 매핑: B01→`COMP_ACRYL_CLEAR3T`(196), B03→`COMP_ACRYL_MIRROR3T`(81), B05→`COMP_ACRYL_COROTTO`(36). **B02(투명1.5T, 81셀)=매핑미상**(라이브에 1.5T 전용 comp 부재), B06 카라비너=면적 아님(siz_cd 본체).

### 1.6 [아는 것 / 모르는 것 / 애매한 것 / blind spot]
- **아는 것**: 격자 축=가로×세로, 셀=개당 단가, 소재/두께=블록 분기, 수량할인=B04 별도, 도수는 통용(격자 무관).
- **모르는 것**: B02 투명1.5T가 라이브 어느 comp에 붙어야 하는지(권위엔 81셀 값 존재, 라이브 comp 없음). B04 후가공 옵션의 정확한 단가 전체.
- **애매한 것 [AMBIGUOUS]**: 격자 밖(예: 가로 25mm, 세로 250mm)일 때 올림(ceiling) 규칙 — **권위 시트에는 올림 규칙 문구가 없다**. off-grid ceiling은 엔진(면적매트릭스 구간 차원) 관례로 알려짐이나 이 시트가 그렇게 하라고 명시하진 않음.
- **blind spot**: "직접입력형"이 무슨 UI 흐름인지(고객이 가로세로 직접 입력?) 이 시트만으론 불명. 카라비너(B06)는 면적이 아니라 부속 사이즈 고정가라 다른 상품과 모델이 다름.

### 3.2 차원 축 — **2단계 룩업**(단일 면적격자 아님)
가격 산출 절차:
1. **면적→등급**: 박 찍을 도안의 가로×세로 → B02(일반박)/B04(특수박) 격자에서 **등급 문자 A~E** 조회. (범위: 가로 10~80mm×세로 10~40mm, 14셀. 값이 숫자 아니라 문자.)
2. **등급×수량→가격**: 위 등급 + 주문 수량 → B03/B05 표에서 **가공비 총액** 조회.
3. **동판비**(B01) = 1회성 5000원 별도 합산.
- 즉 최종 박 가공비 = 동판비 + 수량별가격(등급, 수량). **일반박(7종)과 특수박(3종)은 다른 표**.

### 3.3 값의 의미
- B02/B04 면적셀 = **등급 코드(A~E)** — 가격 아님. B03/B05 셀 = **가공비 총액(수량 밴드 단위)** — 예 200장 A등급 = 12200(장당 아님, 200장 묶음가로 읽힘). B01 = 동판 총액.
- [판정: B02/B04=등급문자 / B03/B05=총액(수량밴드) / B01=동판 총액].

### 3.4 본체 vs 추가가격 — **박은 추가가공**
박(foil)은 본체가 아니라 **추가가공**이다. 근거: 시트명이 `후가공_박`, 제목이 `… 가공비 …`. 박은 명함·카드 등 본체 상품 위에 얹히는 후가공 → 본체 가격 + (동판비 + 박 가공비) 합산. (백업 시트 §5가 `명함 동판비`·`명함박`으로 대상 상품=명함임을 명시.)

### 3.5 박 3시트 관계 (소형↔대형↔백업)
- **소형 vs 대형 = 사이즈 구간대**. 소형 = 가로 10~80mm × 세로 10~40mm(작은 박, 명함·카드급). 대형(§4) = 가로/세로 30~170mm(큰 박). 둘 다 등급 A~E 추상 사용.
- **일반박/특수박 분리**는 소형·대형 공통(박 종류에 따라 다른 표).
- **백업(§5)** = 소형박을 명함 실사이즈 컬럼으로 **전개(denormalize)**한 백업 — A~E 등급 없이 사이즈 직접. 값은 소형박 표와 동일 계열(예 200장=12200부터).

### 3.6 왜 라이브에 "면적박 comp 부재"로 기록됐나
배치(`run_all.py`)가 박소형/대형을 **UNMAPPED**로 둔 이유(정직 분류):
1. 면적격자 diff(`parse_l1_area`)는 **셀 값이 숫자 단가**일 때만 격자로 파싱한다. 박 B02/B04는 셀 값이 **문자 A~E** → 파싱 대상에서 탈락(2단계 룩업을 배치가 모델링 못 함).
2. 라이브 DB에는 **면적 기반(siz_width×siz_height) 박 component가 없다**. 명함박만 `min_qty` 키 comp로 존재(comp_hint: `라이브 면적박 comp 부재(명함박만 min_qty)`). 즉 권위엔 소형/대형 면적박 값이 **있으나** 라이브 엔진엔 그 구조(면적→등급→수량)가 **미구현**.
- **권위엔 값이 있다**(등급 정의 + 수량별 총액 전부 존재). 라이브 미적재 = §18 설계 필요(BLOCKED), 매핑미상 아님을 이 문서가 규명.

### 3.7 [아는 것 / 모르는 것 / 애매한 것 / blind spot]
- **아는 것**: 2단계 룩업(면적→등급 A~E→수량별 총액) + 동판비. 일반/특수박 분리. 박=추가가공.
- **모르는 것**: 등급 A~E의 **면적 경계 산식**(넓이 임계? 최대변? 격자 밖 도안은 어느 등급?). 라이브에 이 구조를 어떻게 적재할지(신규 comp/차원).
- **애매한 것 [AMBIGUOUS]**: B03 수량셀이 "묶음 총액"인지 "장당"인지 — 값 크기(200장 12200)로 볼 때 묶음 총액으로 읽히나 시트에 단위 문구 없음. 격자 밖 사이즈 올림 규칙 없음.
- **blind spot**: 면적→등급 격자가 **비대칭**(가로 10~80 × 세로 10~40)이라 가로>세로/세로>가로 방향성 존재 여부 불명(transpose 위험).

## 6. 공통 blind spot 요약

1. **격자 밖 올림(ceiling) 규칙은 어느 권위 시트에도 명시 문구가 없다.** [AMBIGUOUS] off-grid ceiling(인접 큰 사이즈 대체)은 엔진(면적매트릭스 구간 차원) 관례로 알려졌으나, 아크릴·포스터·박 시트 자체는 이산 격자만 제공하고 "올림하라"고 적지 않음. 사용자 해석규칙 3("격자 밖은 올림")은 **엔진 동작 가정**이지 이 권위 시트의 명문 규칙이 아님 — 주의.

2. **같은 면적격자라도 셀 값 의미가 다르다.** 아크릴=개당 **단가**(수량할인 별도 곱), 포스터=완성 **총액 포함가**(출력+코팅+가공). 소재별로 포함 범위도 다름(포스터 B18/B20은 코팅 미포함). 한 규칙으로 뭉뚱그리면 오산정 위험.

3. **박(소형/대형)은 "면적격자"가 아니라 "면적→등급→수량" 2단계 룩업이다.** 면적 셀 값이 가격이 아니라 등급 문자 A~E. 배치가 UNMAPPED로 남긴 것은 매핑 실패가 아니라 **구조 자체가 단일 면적격자 diff로 표현 불가**하기 때문. 권위엔 값이 온전히 존재(등급 정의+수량가격+동판비) → 라이브 미적재는 §18 설계 이슈.

4. **박은 본체가 아니라 추가가공.** 세 박 시트 모두 본체 상품(명함/카드 등) 가격에 (동판비 + 박 가공비)를 **합산**한다. 사용자 해석규칙 4(박=추가가공) 확인됨.

5. **등급 A~E 면적 경계 산식·소형↔대형 사이즈 겹침 처리·수량밴드 단위(묶음/장당)**가 권위 시트에 명문화돼 있지 않아, 라이브 적재(§18) 전 반드시 확정 필요.

6. **박(백업)은 L1 추출 부재**로 배치 diff에서 빠져 있어, 명함박 무결성은 별도 경로로 대조해야 함.

### 사용자 해석규칙 3종 검증 결과
- **규칙1(상품명=본체 격자, 차원 일치 시 셀=산출가로)**: 아크릴·포스터 ✅ 성립(단 셀 의미가 단가/총액으로 갈림). 박 3시트는 본체 아님(추가가공)이라 규칙1 대상 아님.
- **규칙2(추가가격은 별도 시트 합산)**: ✅ 성립. 포스터 추가옵션·아크릴 후가공옵션·박 전체가 별도 합산 대상.
- **규칙3(면적 상품 가로×세로 격자, 격자 밖 올림)**: 격자 룩업 ✅(아크릴·포스터). **올림(ceiling)은 권위 시트 명시 없음** ⚠️ — 엔진 관례 가정. 박은 면적격자가 아니라 2단계 룩업이므로 규칙3 단순적용 불가.
