## 3. 왜 전용 구성요소인가

기존 `COMP_CUT_PERF_1H6`(타공비 6mm)는 **헤더택 값**이고 캘린더와 다르다:

| | 1구 | 2구 |
|---|---:|---:|
| 헤더택 `COMP_CUT_PERF_1H6` | 2,000 | 4,000 |
| **캘린더 `COMP_CUT_PERF_CAL`** | **1,000** | **1,500** |

그리고 `110` 엽서캘린더와 `045` 인쇄헤더택은 **타공 공정(`PROC_000126`)도 판형(`SIZ_000499`)도 같아**
한 표에 담으면 구분할 축이 없다. 그래서 표를 나눴다(지니 판단).

두 comp 가 같은 공정을 쓰지만 **서로 다른 공식에만 붙어** 충돌하지 않는다 —
실계산으로 확인했다(§5: `045` 무변화).

## 4. [HARD] 실행 중 잡은 결함 — 단가유형을 잘못 골랐다

처음에 **합가형(`PRICE_TYPE.02`)** 으로 만들었더니 `110` 이 100장에 **+100,000** 이 붙었다
(1,000 × 100). 즉시 코드로 원인을 확인했다 — `pricing.py` `component_subtotal`:

> **합가형**: unit_price(**구간 총액**) ÷ 구간 `min_qty` = 장당가, **× 수량**
> **고정금액**: unit_price 그대로 — **수량 무관(곱셈 없음)**

`min_qty=1` 행에 1,000 을 넣으면 「1장에 총 1,000」 = 장당 1,000 이 되어 수량만큼 곱해진다.
기존 헤더택 타공비가 flat 처럼 보인 것은 `min_qty=100` 구간에 2,000 이 들어 있어
2,000÷100 × 100 = 2,000 이 된 것이지, 합가형이 정액이어서가 아니다.

⇒ **권위의 「수량 무관 정액」은 `고정금액(PRICE_TYPE.03)` 이다.** 유형을 바꿔 해소했다.

> 지니의 「합가로 본다」는 **엑셀의 합가 개념**(항목을 묶은 값)이고,
> 라이브 `PRICE_TYPE` 분류로는 **고정금액**이 대응한다. 두 낱말이 같은 뜻이 아니다.

**교훈**: 단가유형은 이름이 아니라 **`component_subtotal` 의 계산식으로 고른다.**
구성요소 비고에 이 이력을 남겼다.

### 5.1.1 [HARD] 위젯 cfg 만 보고 판단하면 오판한다

`widget-builder .../load/` 의 `items` 에는 **공정 항목이 하나도 없다**
(`ref_key` 가 `siz_cd`·`mat_cd`·`print_opt_cd`·옵션그룹·`pages`·`qty` 뿐).
그것만 보고 「위젯이 공정을 못 보낸다」고 판단할 뻔했다.

**실화면에는 「후가공」 섹션이 렌더되고 그 안에 디지털인쇄(필수)·제본·타공이 있다** —
cfg 에 명시 항목이 없어도 **렌더러가 공정 블록을 구성한다.**

도메인 규칙 §7.1 「고객이 고를 수 있는 옵션의 분모는 **렌더된 화면에서만** 얻는다」가
그대로 적용됐다. `cfg` 도 `meta` 도 분모가 아니다.

### 5.1.2 덤으로 확인된 것

- **제약이 정상 작동한다** — `110` 에서 세로형 A5 를 고르자 추가상품 우드거치대가
  「선택 가능한 추가상품 없음」으로 사라졌다(권위 「세로형 우드거치대 금지」).
- **옵션그룹 「가공」이 공정과 나란히 노출된다** — `111` 은 「재단만 / 2구타공+면끈 /
  고리형트윈링제본」, `110` 은 「재단만 / 1구타공」. 골라도 가격은 변하지 않는다
  (`constraint_only` 이므로 정상). **고객 화면에서 타공을 고르는 자리가 두 곳으로 보인다** —
  공정 「2구 6mm 타공」과 옵션그룹 「2구타공+면끈」. 가격이 붙는 쪽은 **공정**이다.
  UX 혼선 소지가 있으나 **위젯 구성 영역**이라 손대지 않았다(§8).

## 8. 남은 것

- **가격표 「커팅타공」 `D42` 「헤더택 / 벽걸이캘린더」 라벨**은 여전히 미해소다.
  그 옆 「타공(합가)」 표는 2구 4,000 인데 이번에 쓴 상품마스터 값은 1,500 이다.
  **상품마스터가 상품별로 명시한 값**을 택했고(지니 판정), `D42` 는 두 표 사이에 병합 없이 떠 있어
  어느 표의 라벨인지 문서만으로 정해지지 않는다. 실무진 확인 시 이 선택을 재검토한다.
- `112` 와이드벽걸이캘린더는 타공 공정이 없어 대상이 아니다(권위에도 타공 옵션 없음).
- **위젯에서 타공을 고르는 자리가 둘로 보인다** — 공정 「2구 6mm 타공」과 옵션그룹
  「2구타공+면끈」. 가격은 공정 쪽에만 붙는다(옵션그룹은 `constraint_only`).
  기능은 정상이나 고객이 헷갈릴 수 있다. **위젯 구성 영역**이라 손대지 않았다 — 지니 판단 사항.
