## 2. 왜 이 구성요소인가 — 새로 만들지 않았다

`../missing-rows-audit/` §3 의 search-before-mint 결과:

- 전 구성요소 **123종 전수 검색** → `SIZ_000108/109/110/111` 은 **어디에도 없었다.**
- `COMP_ACC_ENV_ETC` 는 이름이 이미 「캘린더봉투·**케이스·고무판**」이고
  차원도 `['siz_cd','bdl_qty','min_qty']` 로 **그대로 맞는다.**

⇒ 새 구성요소를 만들 이유가 없었다. **행만 채우면 되는 상태였다.**

## 3. 적용일을 오늘로 한 이유

기존 캘린더봉투 2행은 `2026-08-23` 이다. 신규 4행은 **오늘(2026-08-30)** 로 넣었다 —
실제 등록 시점이 오늘이기 때문이다. 도메인 규칙 §7.2 가 UI 적재를 요구하는 근거가
「언제 가격이 등록·변경됐는지 추적」이므로, 남의 날짜를 빌려 쓰지 않는다.

신규 키라 덮어쓴 값이 없어 **이력 손실은 0**이다.
