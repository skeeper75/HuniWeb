# 반칼 스티커 4상품 CPQ 옵션 레이어 설계 (round6-sticker-bankal-cpq-260703)

## 0. 목적 · 범위

반칼 스티커 4상품에 손님 선택 옵션(자재·인쇄·커팅)을 신설한다. 대상 상품은 `t_prd_product_option_groups` 가 사실상 비어 있어(059/060/061 = 0행, 062 = 손상된 부분행) 위젯에서 **자재를 못 고른다**. 특히 무광/유광 코팅 자재는 qty10 기준 ±10,000원(57,000 vs 67,000) 차이라 CPQ 부재 시 오선택·미과금 위험(GAP-STK-CPQ-VOID, 돈영향).

- **대상**(prd_nm 으로 라이브 확정):
  - PRD_000059 반칼정사각스티커
  - PRD_000060 반칼직사각스티커
  - PRD_000061 반칼띠지스티커
  - PRD_000062 반칼팬시스티커
- **동형 원본**: PRD_000052 반칼 자유형 스티커 (CPQ 완비). 종이(자재)·인쇄(도수)·커팅(공정) 3그룹 구조.
- L1(가격사슬·차원환원·기초)은 이미 GO. 본 작업은 **L2만** — 차원행 재적재 없음, 옵션은 기존 차원행을 polymorphic 참조.

## 3. 설계 결정

1. **052 동형 3그룹** — 종이(자재 5)·인쇄(단면 1)·커팅(1). 전부 SEL_TYPE.01 택1·필수(mand_yn=Y·min=max=1). 사이즈 그룹 없음(052 동일; 사이즈는 가격축이 처리).
2. **참조 = 활성 차원행만** — 신규 자재/공정 mint 0. `mat_cd`/`proc_cd`/`opt_id` 전부 라이브 실재 재사용(search-before-mint).
3. **기본값** — 각 택1 그룹 첫 옵션 dflt_yn='Y'(종이=유포, 인쇄=단면, 커팅=단일). 052 의 유포-기본 의도 계승.
4. **코드 채번** — opt_grp_cd/opt_cd 는 상품별 고유 PK(공유 카탈로그 아님, 실측 확인). 라이브 max(OPT_000159/OPV_000638) 다음값으로 OPT_000160~171, OPV_000639~666 배정. 멱등키=PK이므로 재실행 안전. [CONFIRM] 실 COMMIT 직전 max 재확인.

## 4. 커팅 명칭 불일치 (실무진 확인 필요)

- 059/060/061 은 상품명이 "반칼"인데 등록된 활성 공정은 **PROC_000055 스티커완칼(완칼)**. 052/062 는 PROC_000122 반칼커팅.
- 본 설계는 트리거가 요구하는 **등록된 활성 공정**을 참조(커팅 옵션 라벨을 "완칼"로 표기). 상품명 "반칼"과 표시가 어긋난다.
- 판정 필요: (a) 059~061 의 공정 등록이 실수이고 반칼(PROC_000122)이어야 하는가 → 그렇다면 L1 교정(dbm-mapping-designer) 후 커팅 참조 재지정. (b) 완칼이 맞고 상품명이 관용어인가. **L1 데이터 문제이므로 L2 에서 임의 변경 금지** — 활성행 참조로 진행하고 플래그.
