- FP-4(규칙 매핑 오류) 후보 0건 — codex 는 두 규칙 모두 **`violation_test` 문언을 축자 인용한 뒤 그 항에만 대조**했고, 문언이 묻지 않는 축(운영 큐의 실체성, 구현 코드 일치 여부, 자율성 스펙트럼)을 **판정에 산입하지 않고 별도 절로 분리**했다. 원 라운드의 F6-2·F3-3(gap_owner 를 RULE-14 ③ 위반으로 건 FP-4)과 정확히 대비된다 — 이번에는 같은 함정을 피했다.
- **자발 회피 기록 1건**: codex 는 §11 자율성 축을 발견하고도 위반으로 세지 않고 "루브릭 부재로 판정 불가"에 분리 기재했다. FP-4 회피 사례로 기록한다.

### 4.1 오판 감사 (§6.2 · 정밀도 미기록 = 무효)

```
오판 감사 — R3 재심 라운드 (렌즈: 돈·사람개입 · RULE-09 · RULE-14)

  가용 외부 렌즈: 1/1 (codex gpt-5.5 xhigh · exit 0)
  제기 총건:  0
  심리:       0    (각하: 0)
  중복 병합:  0 → 0
  확정 위반:  0
  오판:       0    (FP-1 0 · FP-2 0 · FP-3 0 · FP-4 0)
  FP-4 자발 회피: 1  (§11 자율성 축 — 루브릭 부재로 분리 기재)
  근거 인용 원본 실재 확인률: 12/12 = 100%
```

[HARD] **정밀도 분모가 0인 것은 미기록이 아니다.** 제기 자체가 0건이므로 R/P 는 정의되지 않으며, 이 사실을 위 블록에 명시 기록함으로써 §6.2 의 기록 의무를 이행한다. 제기 0건을 "검증 안 함"으로 읽어서는 안 된다 — 두 규칙의 `violation_test` 는 **적용되었고**(§3 판정표), 적용 결과가 위반 미발견이다.

## 5. 이 재심의 가장 약한 지점 (은폐하지 않는다)

1. **문서 문언 대조의 한계.** RULE-09·RULE-14 는 둘 다 *"설계 출력 스키마에 필드가 있는가"* · *"경로가 문서에 정의되어 있는가"* 를 묻는 **존재 검사**다. 필드가 선언되었다는 사실이 그 필드가 **런타임에 올바르게 채워진다**는 보증은 아니다. 루브릭 §5-2 가 인정한 대로 RULE-14 는 *"정상 경로로 정의되었는가"* 판단이 개입한다.
2. **3b 발생 건수 미측정.** FIX-8 이 언더차지 경로를 **라벨링 가능하게** 만들었으나, 그 경로가 실제로 몇 건 발생하는지는 라이브 스윕(G8) 전까지 알 수 없다. 즉 **가시화는 닫혔고 실측은 열려 있다** — 원 라운드의 P-10 표기(*"가시화만 — 저청구가 사라지지 않고 보이게 될 뿐"*, `design-FINAL.md:90`)와 같은 지위다.
3. **라우팅 목적지의 "실체성"은 test 밖.** `:531` 스스로 *"착지점 중 일부는 큐가 아니라 트랙·화면이므로 쌓인 항목을 누가 언제 비우는가의 운영 실체가 완전하지 않다"* 고 적었다. RULE-14 ③ 의 문언은 이것을 묻지 않으므로 CLOSED 이지만, **운영 실체 리스크는 §11-10 에 살아 있다.**
4. **단일 외부 렌즈.** 이 재심은 codex 1렌즈 + 본 심사자 재확인이다. 원 라운드처럼 3렌즈 × 2검증자가 아니다.

**재심 트리거** — 위 2·3 중 어느 하나라도 S1 파일럿 실측에서 (i) 3b 가 유의미한 건수로 발생하는데 라우팅이 소비되지 않거나, (ii) `sim_escalation` 큐가 누적만 되고 비워지지 않으면, **RULE-09·RULE-14 의 CLOSED 는 이 문서의 §5 한계 조항에 따라 재개된다.** 이때 판정 근거는 문서 문언이 아니라 실측이다.
