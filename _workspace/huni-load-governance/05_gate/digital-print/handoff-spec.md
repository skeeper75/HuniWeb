## 2. webadmin 실화면 확인 의무 [HARD] — 위임 트랙 인계

- 전 재배선/신설 COMMIT 전, 위임 트랙(§7)은 **webadmin 가격시뮬레이터/product-viewer 실화면**으로 확인:
  - **제외 0**(옵션 항목 제외/누락 없음)
  - **PRICE≠0**(특히 E1/E2/E8 돈크리티컬 042/047/031·이중합산 0)
  - 판형 자동선택·옵션 정상 노출
- DB DRY-RUN만으로 COMMIT 금지(CLAUDE.md §1 [HARD]). 실화면 미확인 시 COMMIT 보류.
- 042/047 재배선은 **자재+연당가 선등록 → ref 교정** 2단계 순서 준수(순서 위반=트리거 위반/견적0).

## 3. 인간 승인 필요 항목

- E1~E9 재배선·N1~N9 레이어 신설 = 실 COMMIT → **인간 승인 후** §7 load-execution.
- B1(037)·A1~A7 = 실무진/도메인 답변 선행(승인 대상 아님).

## 4. undo 방향

- ref 교정(E1~E9): 교정 전 `t_prd_product_option_items` 해당 행 ref_key1 원값 백업 → undo=원 ref_key1 복원.
- 자재/단가행 선등록: 신규 INSERT분 del_yn=Y 논리삭제(물리 DELETE 금지).
- 레이어 신설(N1~N9): 신설 opt_grp/opt/item del_yn=Y 롤백.
- 전 트랙 단일 트랜잭션 래핑·롤백 전용 DRY-RUN 선행 후 COMMIT.
