# 06 · webadmin 실화면 확인 체크리스트 (병합 후 · 골든 ④게이트 엔진레벨 확정)

> **시점:** 군별 COMMIT 후, 다음 군 COMMIT 전. **도구:** webadmin product-viewer + 가격시뮬레이터 (gstack 읽기 탐색·`HUNI_ADMIN_*`).
> **판정 기준(전 항목 충족해야 GO 유지):** ① 제외 0 ② PRICE ≠ 0 ③ 판형 자동선택 정상 ④ 단/양면 정상 분기 ⑤ **병합 전=후 동일가(골든 verbatim)**.
> ★하나라도 위반(특히 PRICE=0·병합 전후 가격변동)이면 즉시 해당 군 **04-undo.sql** 복원 + 원인분석. 위젯 PRICE 0 = 우리측 결함신호[HARD].

## 공통 절차 (군당)
1. product-viewer에서 해당 상품 열기 → 구성요소/가격 사슬에 **정본 comp_cd**(예 `COMP_NAMECARD_STD`)가 seq1로 보이고 멤버(_S1/_S2 등) 미표시 확인.
2. 가격시뮬레이터에서 아래 골든 조합 입력 → **표시가 = 골든값** 확인(합가형=÷tier×수량, PCB=단가×수량).
3. 단면/양면 토글 → 값이 골든 표대로 분기(같은 값이면 안 됨, 단 MC-03 홀로는 면무관 동일가=정상).
4. "제외" 항목 0 · PRICE≠0 · 판형 자동선택(명함=해당 없음/종이류 아님) 확인.

## 배치 진행 게이트 (권장 순서)
- **배치 A (8군·무조건 GO):** MC-05 → MC-06 → MC-08 → MC-09 (단순 print_opt_cd·소규모) → MC-02 → MC-07 (2공식) → MC-03 → MC-04 (opt_cd 다축). 군마다 위 체크 통과 후 다음 군.
- **배치 B (MC-01·조건부):** 별도 인간 승인(옵션a 재명명) + COMMIT 직전 468 halt 게이트 통과 확인 후. 엽서북 시뮬레이터에서 페이지수/면/사이즈 전 조합 스팟 확인.

## 실패 시 대응
- PRICE=0 또는 제외 발생 → 해당 군 **04-undo.sql**(COMMIT) 즉시 복원 → 05 재실측으로 원복 확인 → 원인분석(정본 use_dims·배선·nat_key) 후 재설계.
- 병합 전후 가격 변동 → 골든 위반. undo 후 단가행 이관 정합(comp_cd 재지정·nat_key 충돌) 재점검.
