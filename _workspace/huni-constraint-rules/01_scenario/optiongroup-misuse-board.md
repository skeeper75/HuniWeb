## 0. 한 줄 결론 (냉철)

**현행 라이브 CPQ는 우려된 "그룹 폭발"을 광범위하게 보이지 **않는다****(상품당 그룹 1~2개가 최다,
최대 9개=책자/접지카드의 정상 다축). 옵션그룹 대부분은 깔끔한 의미축(인쇄·종이·코팅·가공·모서리·후가공·박칼라·접지).
발견된 오용은 **별색·박 의미축의 명명 비일관(정규화 후보)** 과 **잡음 그룹 1건**에 국한. 조합별 그룹 복제는 미발견.
→ 대부분 §12(기초코드/명명 거버넌스)·§7(적재 정리) 라우팅이며, **제약규칙으로 이관할 진성 오용은 소수**.

## 2. 발견 사례

### OG-1 — 별색(spot color) 의미축 명명 분열 [정규화 후보 · Medium]

같은 의미축(별색/특수색 인쇄)이 **색상을 그룹명에 박아** 상품마다 다른 이름으로 파편화.

| prd_cd | 상품 | 그룹명 | opts | 비고 |
|--------|------|--------|-----:|------|
| PRD_000019 | 투명엽서 | 화이트인쇄 | 1 | |
| PRD_000020 | 화이트인쇄엽서 | **클리어인쇄 + 화이트인쇄** | 3+2 | ★한 상품에 별색 2그룹 |
| PRD_000021 | 핑크별색엽서 | 핑크인쇄 | 2 | 조건(색상)이 그룹명에 내장 |
| PRD_000025 | 투명포토카드 | 화이트별색 | 1 | |
| PRD_000040 | 화이트인쇄명함 | 클리어(별색) | 2 | |
| PRD_000053 | 반칼 자유형 투명스티커 | 화이트별색 | 2 | |
| PRD_000122 | 접착투명포스터 | 화이트별색 | 1 | |

- **현재 구조**: 별색 처리를 `화이트인쇄`/`클리어인쇄`/`핑크인쇄`/`화이트별색`/`클리어(별색)` 등 5+ 이름으로 분산.
  같은 개념(별색 인쇄)인데 그룹명·표시가 상품마다 다름.
- **판정**: 명명 비일관(정규화 후보). ★단, **그룹 자체는 조건부 관계를 흉내내지 않음** — 각 상품은 자기 별색을
  1~2 그룹으로 제공할 뿐 조합폭발 없음. 순수 CN-6(제약 이관)이 아니라 §12 명명 거버넌스에 가깝다.
- **이관 방향**: 정규 그룹 `별색`(또는 `특수색인쇄`) 1개 + 색상=옵션항목(화이트/클리어/핑크/금은)으로 통합.
  색상↔자재/공정 물리 제약(예: 투명 PET에만 화이트 base 유효)이 있으면 **그때 CN-1/CN-3 제약으로 명시**.
- **라우팅**: §12 basecode(그룹명 정규화) 주도 + 물리 제약분만 hcr-rule-designer.

### OG-2 — PRD_000020 별색 2그룹(클리어인쇄+화이트인쇄) [AMBIG]

- **모호**: 화이트 base + 클리어 코트가 **동시 적용 가능한 별개 처리**(→ 2그룹 정상, 판례 P-2형)인지,
  하나의 별색 축을 쪼갠 것(→ 축 분열 오용)인지 **도메인 확인 필요**.
- **처리**: AMBIG — 사용자/실무진 컨펌 큐. designer로 넘기지 않음. 확인 결과가 "동시 가능"이면 정상(필요 시
  상호 조건은 CN-3/CN-4 제약), "택일"이면 그룹 통합(정규화).

## 3. 레퍼런스 (오용 아님 — 경계 원칙의 정석)

### REF-1 — PRD_000016 오시 / 미싱 [정석]
- '오시'(3 opts)·'미싱'(3 opts) = **독립 on/off 가능한 별개 축** → 그룹 2개 유지가 정상.
  "둘 다 on"만 불가 → RULE_TYPE.02 `R_DEMO_EXC` 제약 1개. **선택지=그룹, 관계=제약**의 교과서 사례.
- 이 패턴을 별색/박 정규화의 목표 형태로 참고.
