## 2. 권위가 정정한 판단 3건

### 2.1 커팅비 — 내 의심이 틀렸다. 비고가 오기였다

```
[원자합산형: 모양엽서 / 라벨텍]
판매가 = 인쇄비 + 용지비 + 커팅비
(1) 커팅비 = [출력매수] X 2000원[커팅가격테이블참조]  ‖ 참조시트 커팅/타공
```

커팅비는 인쇄비·용지비와 **따로 더하는 것이 맞다.** 라벨/택 실측(4,000+143+2,000)은 정상이고,
`COMP_CUT_FULL_DIECUT` 의 비고 「완칼(국4절) **인쇄비+소재+커팅 합가**」가 **오기**였다.
이중청구가 아니다. → 비고 정정 완료(§4.2).

### 2.2 인쇄배경지 접지비 — 앞선 조치가 권위와 일치

```
[원자합산형: 인쇄배경지 / 헤더택]
판매가 = 인쇄비 + 용지비 + 접지비 + 타공비 + 추가상품
(2) 접지비 = [제작수량] X [오시가격테이블참조]  ‖ 참조시트 인쇄후가공 > 오시
```

여기 「접지비」의 참조시트가 **오시 가격표**다. 카드접지 표가 아니었다.
`fold-card-rewire/` 에서 카드접지를 떼고 오시비를 붙인 조치가 권위 그대로였다.

커팅비·타공비는 **옵션에 따라 붙는다**(「기본형(커팅없음)」/「타공형」) — 판별축으로 갈라야
한다는 진단도 권위로 뒷받침된다.

### 2.3 미니접지카드 박 누락 — 권위로 확정

### 4.1 가격공식 60개

인쇄물 계열 게시 상품이 쓰는 공식 60개에 권위 전개식·참조시트를 인용했다.
권위 블록과 **1:1로 붙었다**(한 공식이 두 블록에 걸린 경우 0건).

예 — `PRF_DGP_B`:
```
[권위 계산공식집초안 260822_1 · 원자합산형: 모양엽서 / 라벨텍] 판매가= 인쇄비 + 용지비 + 커팅비
‖ 참조시트 커팅/타공  모양엽서·라벨택 가격. 인쇄비+용지비+커팅비(완칼)를 더함.
```

### 4.2 가격구성요소 84개

각 구성요소가 권위의 어느 **항목**(인쇄비/용지비/커팅비/오시비/후가공비/후가공박/…)인지와
그 **세부 계산식·참조시트**를 인용하고, 차원을 명시했다.

핵심 오기 정정:
```
COMP_CUT_FULL_DIECUT
[권위 … · 커팅비 ‖ 참조시트 커팅/타공] (1) 커팅비 = [출력매수] X 2000원[커팅가격테이블참조]
차원 ["plt_siz_cd", "min_qty"].
[2026-08-30 비고 정정] 종전 「인쇄비+소재+커팅 합가」는 오기 — 권위상 커팅비 단독 항목이고
인쇄비·용지비는 별도 가산이다(모양엽서/라벨택 판매가 = 인쇄비 + 용지비 + 커팅비).
라벨/택 실측도 인쇄비 4,000 + 용지비 143 + 이 항목 2,000 으로 3항 합산이다.
```
같은 오기를 쓰던 `COMP_CUT_FULL_PERF_1H6` · `COMP_CUT_FULL_PERF_2H6`(둘 다 미배선)도 정정했다.

**실패 1건**: `COMP_FOLD_LEAF_3FOLD` — 폼이 로드되지 않아 미적용. 재시도해도 동일.
원인 미규명이며 **비고만 미갱신, 데이터는 무변경**이다.

### 4.3 [HARD] 의도하지 않은 부작용 — `use_dims` 자동 정규화 20건

비고 저장 과정에서 서버가 **「수량구간은 항상 마지막 포함」 규칙을 적용**해 `use_dims` 를
정규화했다. 내가 지시한 변경이 아니다.

| 종류 | 건수 | 예 |
|---|---:|---|
| `min_qty` 추가 | 12 | `["siz_cd"]` → `["siz_cd","min_qty"]` |
| `min_qty` 위치 이동(마지막으로) | 8 | `["mat_cd","min_qty","print_opt_cd"]` → `["mat_cd","print_opt_cd","min_qty"]` |

**영향 없음을 실계산으로 확인했다.** 단가표 그리드는 원래도 「수량(이상)」 컬럼을 갖고
있었으므로 선언만 명시화된 것이다:

| 확인 대상 | 결과 |
|---|---|
| `COMP_GOODS_FIXED_SIZ`(min_qty 추가) · 클립보드 | 8,000원 정상 매칭 |
| `COMP_NAMECARD_STD`(순서 이동) · 스탠다드명함 | 3,500원 정상 매칭 |
| 코팅·투명·펄·모양·미니모양명함 | 전부 정상 매칭 |

**다만 이것은 내가 의도한 변경이 아니므로 기록으로 남긴다.** 다른 구성요소를 저장할 때도
같은 정규화가 일어난다 — 비고만 고치려 해도 `use_dims` 가 정규화된다는 사실을 알고 작업해야 한다.
