## 2. 자동 커팅 특허 (문서 A)

### 2-1. 배경·정체 (p2)
- 다품종 소량생산·1인가구 증가 → 인쇄 소량주문 수요↑. 문제=스티커 몇 장도 목형(die) 제작·디자이너 파일검수 비용이 동일 부과되어 최소수량(100장) 강제.
- 해법=**목형 재단이 아닌 클라우드 데이터 처리서버 기반 "디지털 재단(커팅)"**, 주문~출력까지 작업자 개입 최소화 자동화. "스티커 단 한 장이라도 값싸게".

### 2-2. ★자동 커팅 메커니즘 (입력→최적화→출력)
전체 여정(p7 "디지털 인쇄 및 커팅 자동화 시스템 개요"):
- **주문/인쇄 라인**: 제품 종류 선택 → 인쇄·후가공 옵션 설정 → 제품 편집·미리보기 → (자동견적 ∥ 파일처리) → 고객 검수 → 입금 → 주문 승인 → **자동 조판(배치)** → 인쇄 → 후가공
- **커팅 라인**: 재단기에 인쇄/후가공 제품 세팅 → **1차 재단선 불러와 1차 재단** → [코팅 유무 Y] 코팅기 세팅→제품 코팅 → [2차 재단 유무 Y] **레지스트레이션 마크 삽입 → 2차 재단선 추출 → 2차 재단** → 이미지매칭 물류관리 → 배송

**입력**: 고객 디자인 파일(업로드) 또는 제공 템플릿 + 고객 지정 외곽선 색상·두께 + 코팅/2차재단 옵션.
**전처리에서 커팅선 생성**(p10~11 "제품 편집 및 미리보기 시스템"):
1. 파일 업로드 → **유효성검사(Preflight)** → **전처리(Preprocess=외곽선 추출)** → 데이터 검증
2. 외곽선 유무 체크 → 고객 지정 색상·두께로 외곽선 생성 → **1차 재단선 추출 후 PDF 저장**
3. 글씨처럼 여러 객체를 붙여 외곽선 필요 시 → **그룹에디터로 객체별 그룹 생성 → 그룹 외곽선**(예: "떡뽁기/순대" p13, p27 Clipping)
4. 가변데이터(제목/메시지) 처리 → 미리보기 저장 → **인쇄·후가공·재단 레이어 분리 후 저장**

**최적화 규칙 (커팅 경로) — 실시간 견적의 "길이계산"에 내장** (p15~16):
- 면을 선으로 변환 → **중복선 제거** → **패스 정렬(오일러 한붓그리기 방식, 장비 가공시간 최소화 최적 배치)** → 커팅길이 계산(가장자리 커팅라인=**Bezier Line** 길이) → **복잡도 계산** → 길이×복잡도로 후가공 견적.

**출력(장비 명령)** — 자동 배치 시스템(p18~19):
- 내부 자재관리 연동+**머신러닝 학습 배치정보**로 유휴/중복처리 가능 장비 추천·선택 → 장비 인쇄가용영역(Registration Mark+작업영역) 로드 → **Object Locator**(장비별 모듈; 장비특성=주문Data 간 최소간격·최대/최소 사이즈·용지 최대크기; 주문 사이즈/수량/재단횟수/컬러값(잉크위치)/동일 재질 모아 배치·여유공간 재배치) → **PDF Generator**(실 데이터 배치·여러 후가공 동시처리 장비 데이터 병합) → **File Convertor** → 데이터 저장소 → **장비별 소요시간 예측 후 생산공정파일(JDF) 생성**.
- **재단장비 포맷 변환(File Convertor)**: PDF2DXF · PDF2INI · PDF2ZCC · PDF2PLT · PDF2HPGL · PDF2GPGL (p18).

### 2-3. 2차 재단선(코팅 후 재재단) 추출 — 핵심 정밀 프로세스 (p20~27)
목적: 라미네이트 코팅 후 물리적 틀어짐을 보정해 이중재단(가위질 불필요, 핵심기능 #8 p3).
1. 코팅 제품 **스캔** → 파일 저장 → 입력보다 큰 이미지에 옮김 → **배경색 제거**(외곽선 추출용)
2. 스캔 이미지에서 **특징점·중심점 추출** + **레지스트레이션 마크 좌표·중심점 추출**
3. 고객 주문 원본 이미지 로드 → **이미지 매칭 알고리즘으로 특징점 비교·매칭**
4. 매칭 특징점 vs 스캔 특징점 비교 → **회전각도·중심점** 산출 → PDF 객체 회전+중심 이동 → **2차 칼선을 회전·중심 이동으로 좌표 보정**
5. 새 외곽선을 **2차 재단선 PDF 저장** → 레지 마크 중심점을 **플로터로 코팅 제품 위 표기**(2차 재단 정렬 기준) → 재단장비 포맷 변환 → 작업자 재단
- 시각 결과(p23): **붉은선=1차 재단선, 파란선=2차 재단선**. 콘솔 로그(p25): PDF index별 cor(x,y)·w·h·**angle**·scale 산출(회전 보정 실증). 사각형 라벨형(SALE/open/영업중)도 지원(p26).

### 2-4. 견적의 "정밀 후가공" 3계산 (p15~16) — 커팅/후가공 견적 요소
- **길이계산**(칼선형: 도무송/반칼): 위 2-2 최적화 규칙(중복선 제거·패스정렬·Bezier 길이·복잡도).
- **면적계산**(코팅/도수 등 면적형): 벡터→Grayscale, 이미지→Grayscale, 픽셀 0/1 분리 → 오브젝트 면적.
- **가변오브젝트계산**: 가변영역 확인 → 가변요소 개수 카운트.
- 최종견적 = 기본인쇄(자재비+인쇄비, 가격테이블 룩업) + 일반후가공(테이블) + 정밀후가공(위 3계산).
- **의의(p17)**: 기존은 사용자정의 후가공을 상담사가 파일 열어 수동 견적+전화. 또 후가공을 **전체 크기로 견적→불필요 비용**. 본 발명은 업로드 즉시 preflight+전처리로 실시간 견적, **후가공 실제 부분 크기만 정확 산출+중복처리 제거→저렴**. (실화면 p12: 후가공=■2차재단/□스코딕스/□별색, 2차재단선 4mm+색상, 코팅 유광, 인쇄비 22,000+후가공 20,000+부가세=청구 46,200.)

## 3. ★카페/베이커리(실제=아이돌 굿즈) 상품 제안서 (문서 B)

### 3-1. 실제 분류축 = "생산유형 3버킷" (p3 "제안 제품 목록", 정본)
> 업종→목적이 아니라 **생산방식**으로 묶여 있음. 이것이 이 덱의 유일한 명시적 taxonomy.

| 버킷 | 상품(원문 그대로) |
|---|---|
| **A. 낱장물** (flat/loose) | 포스터 · 엽서 · 티켓 · 사진인화 Pack · 폴라팩 · 가랜드 / 스티커 · 조각 스티커 · 리무버블 스티커 |
| **B. 제본물** (bound) | 엽서 북 · 사진 북 · 미니 캘린더 · 캘린더 · 스케줄러 · 스프링노트 · 레더 노트 · 티켓 북/링 바인더 · 포토북/매거진 · 떡메모지 · 무비 북(플립북) |
| **C. 자재+제작 제품** (material+fabricated) | 버튼뱃지 · 문진 · 틴케이스 · 마우스패드 · 안경닦이 · 아크릴 명찰 · 아크릴 키링 · 아크릴 등신대 · 씬 키트(아크릴 무대) · ID카드(사원증) · 액자 · 아크릴 액자 · 슬리퍼 · 목걸이 지갑 · 스탬프 · 마스크 스트랩 · 폰 스트랩(제안 완료) · 폰 케이스(제안 완료) |

### 3-2. 상품별 상세 페이지 공통 shape (p4~44)
각 상품 페이지 = **[주문/제작] · [제안가/출고] · [특징] · [패키지]** 4블록. 출고=일괄 "주문 확정 후 3일내 출고". 제안가=대체로 "주문:사이즈옵션/사진 커스텀".
- **★상품-특정 진짜 정보(boilerplate 아님)** — 온톨로지에 쓸 값:
  - 포스터(p4): 사이즈옵션/디자인+사진, 출력 후 프레임 조립(캔버스액자 자동 제작 기계), 덴마크산 나무 프레임, 모서리 둥근 캔버스액자, EDITOR 있음. 패키지=지관(블랙)·골판지 박스.
  - 엽서/포토북/사진북(p5,20,13): **Layflat 제본·자동 하드커버 앨범 제작 장비**, 엽서북=프리미엄 떡 제본(깨끗이 떨어짐).
  - 사진인화 Pack(p8): **EPSON 디지털 인화기**, 사이즈군=일반(3x5~8x12)/정사각(5x5~8x8)/미니스타(35x45~70x100mm), 레트로·블랙 상자.
  - 미니캘린더(p14): 투명 폰케이스에 넣어 사용, Online Shop 디자인 캘린더 택1, 배경 디자인/텍스트 입력, 미니카드형=가격저렴·구매허들 낮음.
  - 탁상캘린더(p15): 원하는 달·년도부터 12개월, 텍스트·데코 그래픽.
  - 레더노트(p18): **프리미엄 엣지 인쇄(측면인쇄)**.
  - 버튼뱃지(p22): **박 후가공** 버튼, 특별 용지·재질 테스트.
  - 캔버스액자(p29): 캔버스액자 자동 제작 기계, 덴마크산 나무 프레임, 골판지 박스(일본 수출용), 스티커 부착.
  - 응원봉 보관함/파우치(p32): 아크릴 보관함, 하단 응원봉 꽂는 지지대, 각인/다이렉트 프린팅 커스텀.
- **★GAP — 대량 boilerplate**: C버킷 및 다수 제본물 페이지의 [주문/제작]·[특징]에 서로 무관한 상품인데 동일 문구가 반복됨("제작:미니 카드 형태의 캘린더+미니 틴케이스", "최고급 Layflat제본/자동 하드커버 앨범 제작 장비", "동영상 둘러보는 무비 떡메모지로 제작 가능"). → 템플릿 미기입. 상품별 사양은 **후니/와우/레드 라이브·가격표로 별도 권위 확보 필요**(이 덱 문구를 그대로 사실로 채택 금지).

### 3-3. 주문(추천) 프로세스 = 패싯 필터 (p2 "커스텀주문프로세스")
- 흐름: **아티스트 선택 → 사진 선택 → 에디터 커스텀하기 → 끝**.
- 필터 패싯(온톨로지 facet 후보): Time range(2019~2021), Members(전체/개별), Brand, 사진종류(All/Concert/Behind/SNS), Colors(팔레트). → 데모형 faceted recommendation.

### 3-4. 업종→목적→상품 매핑 (요청 형식) — **문서 근거 없음(GAP)**
- 이 덱은 아티스트 팬굿즈 대상이며 카페/베이커리 업종·마케팅 목적(대표성/유치/단골/게시/브랜딩)을 상품별로 명시하지 않음.
- 굳이 도출 가능한 것은 **생산유형 3버킷(3-1)**과 **상품 pool + 생산속성**뿐. "업종→목적→상품" 엣지는 프린틀리가 **새로 저작**해야 함(이 덱은 상품 후보와 생산속성만 제공).

## 4. 프린틀리 시사 (온톨로지 추천층 근거)

1. **공급측 taxonomy는 확보, 수요측(intent)은 미확보**: 3-1의 낱장/제본/자재+제작은 **생산방식 분류**(공급측). 프린틀리 북극성인 "업종→마케팅 목적→홍보물" 엣지는 이 문서에 없음 → **intent 원자분해 층은 프린틀리가 신규 저작**(§35 keystone "intent 원자 분해 미완"과 일치). 이 덱은 그 층의 **상품 노드 후보 pool + 속성**을 채워줄 뿐.
2. **상품 노드 속성 스키마**: [주문방식(사진선택/사이즈옵션)] · [제작방식·장비] · [특징] · [패키지] · [출고일(3일)]을 노드 property로 승계. 단 boilerplate(3-2 GAP)는 라이브 권위로 교체.
3. **패싯 = 온톨로지 property**: 3-3의 Time/Member/Brand/사진종류/Color 패싯 → 추천 필터 property로 재사용.
4. **후가공(커팅) 축**: 문서 A의 데이터 모델(2-5)이 프린틀리 후가공 온톨로지 축을 직접 채움 — cutline(색·두께·내외부)·1차/2차 재단선·레지마크·코팅(유무·광택)·오브젝트그룹·레이어분리·재단선 기하(Bezier 길이·복잡도)·재단장비 포맷·JDF. 도무송/반칼 상품의 **견적 요소**(길이·면적·가변오브젝트)도 여기서 온다.
5. **견적=벤더 엔진 위임 원칙 재확인**: A의 "실시간 자동 견적"은 레드/천혜명 **자체 엔진 로직**(길이·면적·가변 계산). 프린틀리는 값 생성 금지(D-18)·**벤더 엔진 연결**이므로, 이 계산식은 "레드 커팅 엔진의 내부 동작 이해"로만 쓰고 프린틀리가 재구현하지 않음.
6. **커팅 여정 내 위치(연결)**: 조판(자동 배치)↔파일처리(preflight/preprocess에서 1차 재단선 생성)↔인쇄↔후가공↔1차재단↔코팅↔2차재단선 추출↔2차재단. 즉 **커팅 데이터는 편집·전처리 단계에서 미리 만들어져 후가공 후 실행**되며, 2차 재단선만 코팅 후 런타임 스캔·매칭으로 생성 → 온톨로지에서 "커팅"은 파일처리·조판·후가공 세 축과 교차 연결.

## 5. GAP (불확실·미확보)

- **[G1·중대]** 문서 B 제목("카페&베이커리") ≠ 내용(아이돌 굿즈). **업종별 용도·마케팅 목적 매핑은 문서에 없음** → 프린틀리 "업종→목적" 근거로 직접 인용 불가. 상품 pool·생산속성만 유효.

- **[G5]** A와 B는 **발행자·연도 상이**(천혜명 2016 / Betterway 2021). 동일 시스템 연속성은 미검증(둘 다 "Red Printing" 브랜딩이나 확증 없음).
