## 2. 목표 모델 [HARD · 072 동형]

077 = **표지078 + 내지285 + 면지(1개=079)**. 면지색 화/블/그 = **079 내부 택1**.

1. **면지 멤버 079 통합** — "레더 하드커버책자-면지"로 리네이밍. 080/081은 셋트에서 은퇴(`t_prd_product_sets.del_yn=Y` + 상품마스터 use_yn=N).

3. **면지색 옵션그룹 이관** — 부모 OPT_065(+옵션 OPV_437/438/439 + 아이템)를 079로 이동(동일코드 재사용·PK=prd_cd 스코프). **★fn_chk_opt_item_ref: OPT_REF_DIM.03 아이템은 참조자재가 같은 prd_cd(079)에 실재해야 함 → 자재 이관[2] 후 옵션 이관[3~5] 순서 [HARD].**
4. **부모 077 은퇴** — 이관 완료 후 OPT_065 및 USAGE.03 면지자재 논리삭제(del_yn=Y). 셋트공식 자재 미종속 → 가격 무영향. **USAGE.07 없음(해당 없음).**
