# 옵션 축 실호출 검증 + 축④ FAIL 재판정 (2026-08-29)

M4-25. M4-24 가 남긴 「38조합 API 전수 실행 안 함」을 닫으려다 **신규 결함 3종**을 찾았고,
동시에 **기존 축④ FAIL 5건이 대부분 결함이 아니었음**을 확인했다. 라이브 읽기 전용 · 가격조회만 · 쓰기 0.

## 0. 방법과 한계

(사이즈 × 옵션) 전수로 가격을 부르고, 같은 사이즈의 옵션-없음 기준가와의 **증분**이 라이브 단가와
일치하는지 봤다. 70호출 중 **OK 64 · CALL-FAIL 6**.

**[한계] API 는 `opt_cd` 를 하나만 받는다.** 네 형식을 모두 시도했으나 두 그룹 동시 반영은 되지 않았다.

| 형식 | 결과 |
|---|---|
| `selections.opt_cd` 단일 | 반영됨 |
| `selections.opt_cd` 배열 | 거부 (`단가가 등록되지 않아…`) |
| 그룹코드를 키로 (`selections.OPT_000003`) | 무시 (가격 불변) |
| `opt_cds` 배열 / `addon_opt_cd` / 최상위 `options` | 무시 |

따라서 이 검증은 **「옵션 1개씩」**이며, 2그룹 동시 조합은 여전히 미검증이다.
위젯이 실제로 어떤 payload 를 보내는지도 확인하지 않았다.

## 1. 신규 결함 A — 마감 필수 옵션에 단가행이 없어 주문이 차단된다

`PRD_000133` 캔버스 행잉포스터 · `PRD_000134` 린넨우드봉족자.

```
마감「오버로크」선택 → ok=False
  "옵션코드 '오버로크' 선택은 '캔버스행잉포스터 우드행거+면끈 추가가격'
   단가가 등록되지 않아 주문할 수 없습니다"          (3 사이즈 전부 재현)
```

원인은 단가행 유무 하나로 갈린다. **비교군이 정확히 대칭이다.**

| 상품 | 필수 그룹 옵션 | 단가행 | 결과 |
|---|---|---|---|
| `PRD_000124` 린넨패브릭포스터 · 마감(필수) 오버로크 | **0.00 있음** | ✓ | OK |
| `PRD_000139` 메쉬현수막 · 가공(필수) 재단만 | **0.00 있음** | ✓ | OK |
| **`PRD_000133` 마감(필수) 오버로크** | **없음** | ✗ | **주문 차단** |
| **`PRD_000134` 마감(필수) 오버로크+봉미싱(4cm)** | **없음** | ✗ | **주문 차단** |

**0원짜리 옵션도 단가행이 있어야 한다.** `use_dims` 구조도 이를 뒷받침한다 —
`PRD_000138` 은 `opt_grp:OPT_000003` 과 `opt_grp:OPT_000004` 로 **그룹마다 구성요소가 하나씩** 있어
어느 옵션을 줘도 받을 곳이 있지만, `PRD_000133/134` 는 부자재 구성요소 하나뿐이라
마감 옵션을 받을 곳이 없다.

3관문: `opt_cd` 가 가격축 ✓ / 마감 옵션 `use_yn='Y' del_yn='N'` ✓ / 위젯이 마감 그룹 노출 + `mand_yn='Y'` 필수 ✓.

> **오판 하나를 걷어냈다.** 중간에 부자재「선택안함」(`OPV_000996`)도 차단된다고 봤으나,
> 그 옵션은 `del_yn='Y'`(삭제)라 고객이 도달할 수 없다. 내 쿼리에 `del_yn` 필터가 빠져 잔재를 뽑은 것이며,
> §G 함정표의 `del_yn` 미필터를 그대로 밟았다.

## 2. 신규 결함 B — 미니배너 수량규칙 오적재

`PRD_000145` 미니배너 `150x300mm` (`t_prd_product_sizes`).

| 값 | 권위 (상품마스터 실사 r142) | 라이브 | 결과 |
|---|---:|---:|---|
| 최소 | **1** | **5** | 1~4개 주문 불가 (`bad_qty`, 실증) |
| 최대 | **10000** | **1000** | 1000개 초과 불가 |
| 증가 | **1** | **5** | 5의 배수만 가능 |

같은 상품의 `180x420mm` 는 `1/1000/1` 로 최대만 어긋난다.

**돈이 딸려 온다** — 권위 가격표 r316 은 수량구간 10000(단가 2,800)까지 있는데,
라이브 max 가 1000 이라 **그 구간에 영원히 도달할 수 없다.**

비교군: `PRD_000144` 미니보드스탠딩은 사이즈 배선이 전부 NULL 이라 상품 기본값 1/10000/1 을 쓰고
**정상이다.** 수량구간 경계도 정확히 전환한다 — 오프바이원 없음:

```
qty= 4 → 6,500   qty=19 → 6,200   qty=49 → 6,100   qty=99 → 5,900   (권위와 일치)
```

M4 28상품 중 사이즈 배선에 수량규칙이 박힌 곳은 **미니배너 2행뿐**이다. 결함은 국소적이다.

## 3. 신규 결함 C — 수량규칙이 비어 상한이 걸리지 않는다

상품 레벨 `min_qty`/`max_qty`/`qty_incr` 가 전부 NULL 인 상품이 3건 있다.

| 상품 | 권위 (실사) | 라이브 | 실증 |
|---|---|---|---|
| `PRD_000141` 홀로그램 시트커팅 | 1/10000/1 (r125) | **NULL** | qty=999,999 통과 (7,999,992,000원) |
| `PRD_000142` 유광아크릴스티커 | 1/10000/1 (r129) | **NULL** | qty=999,999 통과 |
| `PRD_000139` 메쉬현수막 | **권위도 빈칸** (r115~118) | NULL | 미판정 |

짝을 이루는 상품끼리 하나만 비어 있다 — **적재 누락의 전형**이다.

```
무광시트커팅     1/10000/1 ✓        홀로그램시트커팅  NULL ✗
미러아크릴스티커   1/10000/1 ✓        유광아크릴스티커  NULL ✗
```

돈이 새는 형태는 아니고 **과다 주문 허용**이지만 권위 위반이다.
`PRD_000139` 는 권위 자체가 비어 있어 판정하지 않았다.

## 4. 축④ FAIL 11건 재판정 — 대부분 결함이 아니다

| 원인 | 건수 | 판정 |
|---|---:|---|
| **성립 불가 조합** — 자재명에 사이즈가 박혀 있다 (`A3 폼보드(화이트) 5mm`) | 8 | **결함 아님.** 「A2 사이즈 × A3 자재」는 애초에 없는 조합이며 제약규칙의 몫이다 (§G 함정표 「스윕 곱집합」) |
| 사이즈 범위 초과 (`5000x900mm`, `PRD_000138`/`139`) | 2 | **재현 불가.** 현재는 `siz`만·`siz+mat`·`qty=10` 모두 성공한다. 사이즈 코드 중복도 없다(`SIZ_000322` 하나). 그 사이 교정됐는지 도구 상태 차이인지 구분할 수 없다 |
| `bad_qty` (`PRD_000145`) | 1 | **도구 한계.** 실제 문구는 `수량은 최소 5 이상이어야 합니다` 인데 `axis4.py` 재시도 정규식은 `최소 주문수량은 (\d+)` 만 잡는다. qty=5 로는 정상(32,500 = 6,500×5). 다만 그 「최소 5」자체가 결함 B다 |

**축④ 「PASS 23 · FAIL 5」는 옵션 축을 곱지 않은 기준의 판정이다.** `PRD_000133/134` 는 축④ PASS 인데
마감 옵션을 고르면 차단되고, `PRD_000138/139` 는 축④ FAIL 인데 옵션 실호출은 전건 OK 다 —
**두 방향 모두 어긋난다.**

## 5. 미판정 2건 마무리

- **규조토코스터 사각** — 권위 굿즈파우치 **r19 「사각 100mm」 5,000** ↔ 라이브 5,000 **일치**.
  자동 매칭이 놓친 이유는 숫자 시퀀스가 `(100)` vs `(100,100)` 로 갈려서다.
  부분집합 허용으로 완화해 봤으나 트레싱지봉투 70x100 30장이 권위 32,000 행에 붙는 등
  서로 다른 사양이 엮여 **OK 46→45 / 미판정 10→12 로 나빠져 되돌렸다.**
  엄격 매칭을 유지하고 이 1건은 수동 확인으로 남긴다 — 도구 한계이지 미검증이 아니다.
- **아크릴거치대** — 두 엑셀 **전 시트 검색 0건**. 권위에 없고 라이브에만 있다(1,400원, M4 밖 `PRD_000226`).
  결함이 아니라 **권위 미등재**이며 실무진 확인 사항이다.
