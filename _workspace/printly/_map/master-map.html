프린틀리 · 전체 지도와 현재 위치

내가 만들고 있는 것, 그리고 지금 어디쯤인지

같은 여정을 세 가지 방식으로 그린 지도입니다 — RED의 WebToProduct 20단계, 시스템 6층 건물, 실행 Stage 0~6. 세 지도 위에 "지금 여기"를 찍었습니다.

무엇을·왜 만드나

손님이 평소 말로 "카페 오픈용 고급 명함 500장 얼마?" 하고 물으면 — 알아듣고, 알맞은 상품·가격을 알려주고, 주문을 받고, 여러 인쇄소(후니·와우·레드) 중 어디에 맡길지까지 정해주는 대화형 AI 인쇄 에이전트.

프린틀리는 후니 내부 시스템이 아니라 여러 벤더의 견적 엔진을 연결하는 중개(브로커)입니다. 그래서 "브랜드에 상관없는 공통 지식 지도" 위에서 추천하고, 벤더마다 다른 계산기로 견적을 비교합니다.

원칙 1 · 지식 지도가 유일한 진실 (코드에 값 박기 금지) 원칙 3 · AI는 값을 지어내지 않음 (견적·순위 = 계산기 몫) 원칙 5 · 소단위로 쪼개고 매 단계 확인
01

먼저 — 세 지도는 같은 길

아래 세 그림은 서로 다른 시스템이 아니라 한 여정을 다른 각도에서 본 것입니다. 20단계는 "주문이 흘러가는 순서", 6층은 "무엇을 쌓아 올리나", Stage는 "우리가 실제로 지어가는 차례". 색으로 진행 상태를 표시합니다.

완료 · 재사용 가능 진행 중 예정 · 미착수 지금 여기
02

지도 A — WebToProduct 20단계 (주문이 흐르는 순서)

RED 원본 덱의 파이프라인. WEB(고객 대면)에서 시작해 PRINT(생산 준비)를 거쳐 PRODUCT(생산·후가공·배송)로 끝납니다. 프린틀리가 지금 다루는 구간은 맨 앞 WEB — 추천과 견적의 "지식 토대"입니다.

WEB고객 대면
01주문 접수 (대화·추천)
02견적 (인쇄+후가공 포함)
03결제
프린틀리 지금 여기 (지식 설계)
PRINT생산 준비·결정론 엔진
04인쇄파일 검사 (프리플라이트)
05자동 수정
06똑똑한 조판 (임포지션)
07후가공별 파일 분리
08장비별 파일 변환
PRODUCT생산·후가공·배송
09인쇄 출력
10커팅 · 11금은박
12스코딕스 · 13미싱 · 14오시
15반칼 · 16재단 · 17제본
18분류 · 19포장 · 20배송

두 구간(WEB↔PRODUCT)을 잇는 다리 = 잡티켓(작업지시서 데이터 계약). 프린틀리에선 이게 브릿지(PART 2)이며 아직 착수 전입니다.

03

지도 B — 시스템 6층 건물 (무엇을 쌓아 올리나)

건물 짓기 비유. 바닥 3층(①②④)은 이미 튼튼합니다 — 새로 만들 게 아니라 재사용할 자산. 위로 갈수록 목표에 가깝고, 꼭대기 ⑥이 최종 목표입니다.

미착수 · 최종 목표
