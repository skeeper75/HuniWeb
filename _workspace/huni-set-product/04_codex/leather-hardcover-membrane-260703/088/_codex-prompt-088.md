# 독립 교차검증 요청 — 088 레더 링바인더 "면지 통합" 재설계 (셋트상품)

당신은 후니프린팅 셋트상품(부품조립형) 설계의 **독립 2차 교차검증자**다. 아래 설계·적재본·라이브 사실을 근거로
**독립 판정**하라. 다른 검증자의 결론은 제공되지 않는다(독립성). read-only. 파일을 쓰지 마라. 판정만 서술.

## 도메인 배경
- 셋트상품: 완제품 `prd_cd`(088) ← 반제품 구성원 `sub_prd_cd`(089 표지, 090~093 면지). `t_prd_product_sets`.
- 가격엔진 `evaluate_set_price`(pricing.py:854) = Σ 구성원 evaluate_price + 부모공식(copies) + 할인테이블.
- 구성원이 **가격공식 바인딩 0건**이면 그 구성원의 evaluate_price 진입 자체가 없어 기여=0.
- 옵션아이템 무결성 트리거 `fn_chk_opt_item_ref`: `ref_dim_cd='OPT_REF_DIM.03'` 아이템은 참조 자재(mat_cd+usage_cd)가
  **같은 prd_cd에 실재**해야 INSERT 통과.

## 재설계 요지 (검증 대상)

- 면지 빈멤버 4개(090/091/092/093, 전부 자재/옵션/공식 0건 빈껍데기) → **1멤버(090)로 통합**.
  091/092/093 은퇴(`t_prd_product_sets.del_yn=Y` + `t_prd_products.use_yn=N`).
- 부모 088의 면지자재 4종(MAT_382/383/384/385, USAGE.03) + 면지색 옵션(OPT_067 + OPV_444~447 + 아이템 4개)을
  **090으로 이관** 후 부모 088에서 **은퇴(del_yn=Y)**. 신규 mint 0.
- ★USAGE.07 D링 자재(MAT_247/248/249) = **부모 유지·미터치**(불가침).
- **내지 멤버 없음**(빈 바인더).
