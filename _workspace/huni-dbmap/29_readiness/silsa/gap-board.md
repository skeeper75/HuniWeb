## G1 — qty floor 저수량 silent-0 (Medium · ★돈영향)

- **현상:** 미니배너(145)·**미니보드스탠딩(144)** 는 상품 `min_qty=1`이나 단가행 격자 `min_qty` 최소 tier=**4**. 주문 1~3개 시 격자 룩업 실패 → **0원 견적**.
- **재현(라이브 simulate):**
  - 145 SIZ_000028 qty=1 → **0** / qty=5 → 32,500(6,500×5)
  - 144 SIZ_000170 qty=1 → **0** / qty=5 → 17,500
  - 단가행: `COMP_POSTER_MINI_BANNER`·`COMP_POSTER_MINI_STANDBOARD` 둘 다 min_qty tier = {4,19,49,99,10000}(1~3 없음).
- **돈영향:** 손님이 1·2·3개 주문 시 0원(무료 견적). 소량 주문 상품이라 노출 가능성 실재.
- **KB 대비 신규:** KB 게이트는 **145만** gap-145로 지목. 본 round-19가 **144도 동일 결함** 추가 적발(동형 미니 상품).
- **조치(택1·실무진 정책):** ⓐ 상품 `min_qty=4`로 정합(격자와 일치) or ⓑ 격자에 min_qty 1~3 tier 추가(단가=4tier 단가 승계). 후니 미니배너 최소주문 정책 확인 선행.
- **라우팅:** 실무진 컨펌 큐 → §26/§7(인간 승인 후 COMMIT).

## G2 — 119 아트페이퍼포스터 판형 오적재 (Low · 가격무영향)

- **현상:** 실사=비종이류(대형 롤 출력) → 판형(t_prd_product_plate_sizes) 불필요. 27상품은 판형행 `del_yn=Y`(정당 삭제). **119만 활성 3행(del_yn=N)** — 형제 118 아트프린트포스터와 동일 성격인데 118은 미배선.
- **재현:** `SELECT count(*) FILTER(del_yn=N) FROM t_prd_product_plate_sizes WHERE prd_cd='PRD_000119'` = 3(plate SIZ_000052/198/294). 118/120/125…=0.
- **돈영향:** 없음(가격=면적매트릭스, 판형 미참조). 위생 결함(비종이류 판형 배선=혼동).
- **조치:** 119 판형 3행 del_yn=Y(118과 하모나이즈). DEF-SL-PP-2와 동일.
- **라우팅:** §7/§26(인간 승인).

## G3 — 139/141/142 수량 min/max NULL (Low · 데이터위생)

- **현상:** 메쉬현수막(139)·홀로그램시트커팅(141)·유광아크릴스티커(142) 는 `min_qty`·`max_qty` **NULL**. 형제(138·140·143)는 1/10000.
- **재현:** 상품 조회 min_qty/max_qty 공란. 단, simulate는 PRICE≠0(139=20,000·141=8,000·142=9,000) — 가격 무파손.
- **돈영향:** 낮음. UI 수량 스피너 min/max 미enforce 가능(과대/과소 주문 방어 약화).
- **조치:** min_qty=1·max_qty=10000 채움(형제 동형).
- **라우팅:** §7(인간 승인).

## G4 — 133 캔버스행잉 use_dims 미스매치 (Low · 잠재)

- **현상:** base comp `COMP_POSTER_CANVAS_HANGING`.use_dims=`["siz_width","siz_height","min_qty"]`(면적템플릿)이나 실 단가행 3셀은 `siz_cd` 키(siz_width/height 빈값). 고정가·이산규격이므로 `[siz_cd,min_qty]`여야 정합.
- **재현:** simulate 133 SIZ_000172 = **6,000**(정상). 엔진이 siz_cd 폴백 룩업 성공 → 현재 가격 무파손.
- **돈영향:** 없음(현재). 향후 엔진 룩업 로직 변경 시 조회실패 잠재.
- **조치:** 라이브 use_dims를 `["siz_cd","min_qty"]`로 정정(KB gap-133 양면 보존).
- **라우팅:** §26(인간 승인). DEF-SL-PP-1과 동일.

## G5 — 코팅/후가공 옵션 비대칭 부재 (Low · 선택지·컨펌)

- **현상:** 아트페이퍼(119)·아트패브릭(123)·레더(126)·타이벡(127)·메쉬프린트(128) 는 CPQ 옵션그룹 **0**. 동형 형제 아트프린트(118)는 코팅 옵션 2그룹 보유. 단일소재 출력만 상품이면 정당하나, 118↔119 동형인데 119만 코팅옵션 없음=비대칭.
- **재현:** og count 118=2·119=0·123/126/127/128=0.
- **돈영향:** 없음(base 견적 가능). 손님이 코팅/후가공을 못 고르는 선택지 손실.
- **조치:** 도메인 BOM(§1 종이포스터=코팅 선택·§4 패브릭=오버로크)과 대조 후 필요분만 118 동형 CPQ 복제. 실무진 컨펌(코팅 제공 상품 범위).
- **라우팅:** 컨펌 큐 → §6 dbm-option-mapper(승인 후).
