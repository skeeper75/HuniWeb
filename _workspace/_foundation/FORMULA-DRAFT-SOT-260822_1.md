## 1. [원자합산형] 프리미엄엽서 / 코팅엽서 / 스텐다드엽서 / 투명엽서 / 화이트인쇄엽서 / 핑크별색엽서 / 금은별색엽서 / 종이슬로건 / 스텐다드 상품권 / 프리미엄상품권

- 판매가 = 인쇄비 + 코팅비 + 용지비 + 후가공비 + 추가상품
- (1) 출력매수 = 주문수량 / 판걸이수  ‖ 참조: **판걸이수**  ‖ *크기별 기준에 따름
- (2) 인쇄비(4도) = [수량행단가] x 출력매수  ‖ 참조: **디지털인쇄비**  ‖ *국4절 또는 3절
- (3) 별색인쇄비 =[인쇄비단가] + [출력매수 수량행]x[칼라열]  ‖ 참조: **디지털인쇄**  ‖ *3절 별색인쇄 상품은 없음
- (4) 코팅비 =  [수량행단가]x[코팅타입열] x 출력매수  ‖ 참조: **코팅**
- (5) 용지비 =  [크기별 기준단가] X [출력매수]+5장(손지율)  ‖ 참조: **출력소재**
- (6) 후가공비 = [제작수량행]  ‖ 참조: **인쇄후가공**
- (7) 후가공박(대형) = [면적별동판비] + [면적별 A,B,C,D,E군] [군별/칼라별 수량행 합가]  ‖ 참조: **후가공_박(대형)**
- (8) 추가상품 = 목록별 가격적용
