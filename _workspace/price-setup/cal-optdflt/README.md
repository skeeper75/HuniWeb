# 캘린더 「가공」 그룹 기본값 설정 — `111`·`110` (2026-08-31)

지시(지니): 「벽걸이 캘린더는 캘린더가공이 **필수**로 되어있네. 그런데 3개 중 하나를 선택할 수
있는데 **기본이 고리형트윈링제본**이고 가공없음(재단만)도 선택이 가능해」

선행: `../cal-optaxis/`(옵션그룹 가격축 전환)

## 1. 확인 결과 — 지적대로 어긋나 있었다

「가공」 그룹은 **필수(`mand=True`)** 인데 **기본값이 하나도 없었다.**

| 상품 | 그룹 필수 | 권위 기본(캘린더 시트 상품별 첫 항목) | 라이브 기본값(전) | 판정 |
|---|---|---|---|---|
| 벽걸이캘린더 `111` | **Y** | **고리형트윈링제본** (T21 = 2,000) | **없음**(3개 모두 N) | ✕ |
| 엽서캘린더 `110` | **Y** | **가공없음(재단만)** (T11/T15 = 0) | **없음**(2개 모두 N) | ✕ |
| 와이드벽걸이 `112` | Y | 고리형트윈링제본 (T26 = 2,000) | 고리형캘린더제본 = **Y** | ✔ 정상 |

**필수 그룹에 기본값이 없으면** 위젯 첫 화면이 미선택 상태로 열린다 —
고객이 반드시 골라야 하는 항목인데 아무것도 안 잡혀 있고, 가격도 그만큼 비어 보인다.

## 4. 덤으로 확인된 것 — 옵션→공정 매핑은 이미 완비돼 있었다

상품뷰어 › 가공 › (옵션) › 구성요소:

| 옵션 | 연결된 구성요소 |
|---|---|
| 2구타공+면끈 | **공정 · 2구 6mm 타공** |
| **고리형트윈링제본** | **공정 · 벽걸이캘린더제본** |
| 재단만 | 없음 (권위상 맞다) |

앞선 조사에서 「옵션에 연결이 없다」고 본 것은 **시뮬/위젯 메타에 실리지 않은 것**이었지
데이터가 없던 게 아니다(`price_views.py:3084` 가 `maps` 를 빈 값으로 고정).
`../cal-optaxis/` §2 의 진단이 맞았고, 이번에 그 데이터의 실재를 확인했다.

## 5. 남은 것

- **`112` 에 「제본없음(재단만)」 옵션이 없다.** 권위 T27 에는 0원으로 있는데 라이브
  옵션그룹 `OPT_000310` 은 「고리형캘린더제본」 하나뿐이라 **고객이 제본을 뺄 수 없다.**
  옵션 추가 + 0원 단가행이 필요하다. 상품 구성 영역 — 별도 판단.
- 위젯에 공정 「후가공」 블록이 계속 노출된다(`../cal-optaxis/` §7).
