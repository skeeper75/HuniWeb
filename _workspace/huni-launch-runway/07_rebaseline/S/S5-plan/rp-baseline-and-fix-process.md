## 4. 수정 프로세스 (코드 분석 반영 · 2026-09-17 교체판)

### 4-0. [정정] 초판의 해석 오류 — 쿠키가 안 보인 것은 결함이 아니다

초판은 `document.cookie` 0개 · localStorage 에 회원 토큰 없음을 **결함의 징후**로 적었다. **틀렸다.**
코드 확정: 회원 토큰은 **HttpOnly 세션 쿠키 안의 JWT 에만** 있고 브라우저 JS 에는 원래 노출되지 않는다
(`api/shop/[...path]/route.ts:53` · 설계 의도). 관측값은 **정상**이다.

진짜 뿌리는 그 다음이다 — **클라이언트는 인증 헤더를 붙이지 않으며, 부착 여부를 100% 서버 프록시가 결정한다.**
프록시가 쿠키에서 JWT 를 못 꺼내면 회원 호출이 비회원 호출로 흘러 카트·배송지·담기가 **동시에** 실패한다.
즉 「한 뿌리」라는 초판의 방향은 맞았고, **그 뿌리의 위치가 브라우저가 아니라 서버 프록시였다.**
