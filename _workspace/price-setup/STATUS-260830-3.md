# 위젯 공정 미전송 — 전수 단건 재실측 (2026-08-30 세션 3)

> 앞선 문서: `STATUS-260830-2.md`(세션 2). **이 문서가 그 §3 을 정정한다.**
> 이 세션은 **라이브에 아무것도 쓰지 않았다.** 전부 읽기·미리보기 시뮬레이션이다.

---

## 1. 결론 — 한 줄

**「공정을 안 보내는 위젯」은 사실상 없었다.** 세션 2 §3 이 지목한 10종 중 9종은 정상이고,
세션 2 가 고쳤다는 9종도 전부 정상이다. 실제로 손봐야 할 것은 **2종**이며, 둘 다
공정 전송과 무관한 다른 원인이다.

세션 2 §3 의 전제는 같은 문서 §4 가 스스로 폐기한 일괄 측정 도구가 만든 허상이었다.

## 2. 조사 순서 — 정정 두 가지 (지니 지적 2026-08-30)

**(1) 상품뷰어가 먼저다.**

1. **상품뷰어** — 이 상품이 실제로 무엇을 요구하나 (사이즈·도수·자재·공정·필수공정)
2. **가격 구조 보기** — 각 가격구성요소가 **어떤 차원키**로 단가행에 매칭되나
3. **위젯** — 그 요구를 고객 화면이 어떻게 연결(또는 미연결)하나

위젯부터 열면 질문이 「위젯 설정이 잘못됐나」로 갇힌다. 세션 2 가 그렇게 갇혔다.

**(2) [HARD] 화면에 안 보인다 ≠ 선택이 안 된다.**

고객에게 안 보일 뿐 생산에 필요한 것은 연결돼 있다(컨트롤 숨김 + 기본값 · 필수공정
자동 전송). 「위젯에 항목이 없다」고 말하려면 ①구성 캔버스에 숨김으로 있나
②기본값이 있나 ③가격 진단 「보낸 입력」에 키가 실제로 없나 — **셋 다** 확인해야 한다.

## 3. 실측 방법

위젯빌더에서 상품 1종 선택 → 미리보기에서 미선택 차원축을 채움 → `가격 진단`
→ 「보낸 입력」의 `procs` 와 「구성요소」 포함/제외를 읽음. **일괄 측정 도구는 쓰지 않았다.**

수량은 각 위젯의 기본값, 옵션은 각 축의 첫 선택지다. **금액의 정오는 이 조사의
범위가 아니다** — 판정 대상은 공정 전송과 구성요소 포함 여부다.

### 5.1 `PRD_000020` 을 한 번 오판했다가 뒤집은 기록

처음 실측에서 1,243원(용지비만)이 나와 결함으로 적었다. **틀렸다.**

화이트인쇄엽서는 **컬러 종이(큐리어스스킨)에 화이트 별색만 찍는 상품**이다 —
상품 공정도 화이트인쇄 `PROC_000008`(필수 Y) · 클리어인쇄 `PROC_000009` 둘뿐이고,
CMYK 디지털인쇄 공정은 **없는 것이 정상**이다. 「앞면별색」을 체크하니 별색인쇄비가
붙었다:

```
별색인쇄비  포함  3,000원   plt_siz_cd=SIZ_000499 · 공정=PROC_000008 · spot_side_cnt=1
용지비      포함  1,243원
합계                4,243원
```

**교훈**: 상세입력(앞면별색/뒷면별색)을 안 채운 상태를 「미반영」으로 읽으면 오판한다.
캘린더 4종의 제본비도 같은 형태다 — 제본은 **필수 N(선택 공정)** 이라 안 고르면 안 붙는
것이 정상이다(`PRD_000111` 공정: 디지털인쇄 필수 Y · 벽걸이캘린더제본 `PROC_000099` N ·
2구 6mm 타공 `PROC_000127` N).

## 6. 결함 A — 화이트인쇄명함 `PRD_000040`

### A-1. 관측

| 층 | 사실 |
|---|---|
| 상품뷰어 공정 (4) | 화이트인쇄 `PROC_000008` · 클리어인쇄 `PROC_000009` · 둥근모서리 `028` · 직각모서리 `027` — **전부 필수 N** |
| 상품뷰어 도수/인쇄옵션 (2) | 단면 `POPT_000001`(기본 Y) · 양면 `POPT_000002` |
| 상품뷰어 옵션그룹 (2) | 화이트인쇄 `OPT_000319` · 클리어인쇄 `OPT_000323` |
| 위젯 캔버스 | 사이즈 · 종이 · 화이트인쇄(옵션그룹) · 클리어인쇄(옵션그룹) · 귀돌이(공정선택) · 건수 · 수량 · 빈공백 · PDF · 가격요약 — **인쇄옵션 항목 부재**(숨김 아님) |
| 가격 진단 「보낸 입력」 | 인쇄옵션 키 없음 · `procs = [PROC_000027]` (화이트/클리어 미포함) |
| 결과 | **0원** — `매칭할 단가행을 못 찾음 — 필요 입력: 인쇄옵션 · 수량(이상)` |

가격구성요소 2개:

| 구성요소 | 차원 | 행 |
|---|---|---|
| `COMP_NAMECARD_WHITE` 완제품가(용지포함) | **인쇄옵션 · 수량** | 단면 ≥100 → 14,500 / 양면 ≥100 → 16,000 |
| `COMP_NAMECARD_SPOT` 명함 별색인쇄비 | **공정 · 앞면별색 · 뒷면별색 · 별색면수 · 수량** | 클리어인쇄 1면 ≥100 → 1,500 / 2면 → 3,000 |

### A-2. 해법 — 인쇄옵션 축을 버리고 **공정 축으로 매핑** (지니 지시 2026-08-30)

고객이 실제로 고르는 것은 단면/양면이 아니라 **화이트인쇄를 앞면만 할까 앞뒤 다 할까**다.
그것이 곧 면수다. 그러니 단가표를 인쇄옵션 축이 아니라 공정 축으로 다시 매핑한다 —
옆의 `COMP_NAMECARD_SPOT` 이 이미 그 모양이고, `PRD_000020` 의 별색인쇄비도 그 모양으로
정상 동작하는 것이 §5.1 에서 실증됐다(`공정=PROC_000008 · spot_side_cnt=1`).

| | 지금 | 바꿀 모양 |
|---|---|---|
| `COMP_NAMECARD_WHITE` 차원 | 인쇄옵션 · 수량 | **공정 · 별색면수 · 수량** |
| 14,500원 행 | 인쇄옵션=단면 | 공정=화이트인쇄 `PROC_000008` · 별색면수 **1** |
| 16,000원 행 | 인쇄옵션=양면 | 공정=화이트인쇄 `PROC_000008` · 별색면수 **2** |
| 위젯 화이트인쇄 노출 | 옵션그룹 `OPT_000319` | **공정선택** 컴포넌트 |
| 위젯 클리어인쇄 노출 | 옵션그룹 `OPT_000323` | **공정선택** 컴포넌트 |

**이렇게 하면 두 문제가 함께 풀린다.** 위젯에 인쇄옵션 항목을 새로 넣을 필요가 없고
(상품뷰어의 인쇄옵션은 이 상품에선 무시), 공정선택으로 바꾸면 화이트인쇄·클리어인쇄가
`procs` 에 실려 별색인쇄비 1,500원도 붙는다 — 세션 2 §5-③(옵션 참조 공정을 가격에
유입시키는 개발 안)을 **기다리지 않아도 된다.**

**돈 크리티컬 변경이므로 실행 전 인간 승인 · 변경 전후 화면 증거를 남긴다.**

## 7. 결함 B — 트윈링책자 `PRD_000071` (셋트상품)

셋트 구성원(표지·내지)에 **선택값이 하나도 전달되지 않는다.**

```
본품 선택   {"siz_cd":"SIZ_000263"}
구성원      트윈링책자-표지: qty=(파생) sel={}
            트윈링책자-내지: qty=(파생) sel={}
```

경고: `판수 환산 불가(판형=SIZ_000499/완제품=미선택)` × 5 · `셋트 합계 0원`.
공정 문제가 아니라 **셋트 구성원 선택 전달**의 문제다. 별도 트랙.

## 8. 별건 관찰 (확정하지 않음)

- **①** `PRD_000017` 코팅엽서 — 코팅을 「무광(단면)」으로 고르면 **무광코팅비가 구성요소
  목록에서 사라진다**(제외 표시조차 없음). 미선택 상태에선 6개가 뜨던 것이 3개로 줄었다.
- **②** `PRD_000043`·`044` 인쇄배경지 — 접지비 카드 2단 600원이
  `판별차원 없음 — 선택과 무관하게 항상 매칭(opt_cd 등 미적재)` 으로 붙는다.
  `huni-product-lifecycle.md` §7.4 의 확정 결함이 그대로 재현. `PRD_000030` 지그재그엽서의
  접지비 카드 6크리즈도 같은 상태다.
- **③** `PRD_000041`·`042` 쿠폰/상품권 — 가변텍스트 `PROC_000031` 이 `+0원`,
  「이 공정으로 매칭된 단가행이 없습니다」. 가변텍스트 구성요소 미배선 가능성.
