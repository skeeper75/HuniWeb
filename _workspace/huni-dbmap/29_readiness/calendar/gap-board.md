# 캘린더 — 갭 보드 (round-19 종단, S1)

> 미적재/오적재/가격 silent-0 갭 + 재현 + 돈영향 + 라우팅. 라이브 읽기전용 실측 근거.
> **원칙:** 직접 적재 안 함 — 차단유형+라우팅으로 기존 라운드에 넘김. 실 COMMIT=인간 승인+webadmin 실화면.

## 요약 — 상품별 견적 실측(evaluate_price 실호출)

기본 시뮬(procs 미지정, 손님이 사이즈·용지·인쇄만) vs 완전 선택(mand 인쇄+제본 proc 지정):

| 상품 | 기본 PRICE(용지만) | 완전 PRICE(인쇄+용지+제본) | unmatched(기본) |
|------|-------------------:|---------------------------:|-----------------|
| 탁상형 108 qty1000 | 15,550 | 2,160,550 | 디지털인쇄비·제본비 |
| 미니탁상 109 qty1000 | 5,225 | (동형) | 디지털인쇄비·제본비 |
| 엽서 110 qty1000 | 10,387 | 65,497(인쇄+용지·**제본/타공 없음**) | 디지털인쇄비 |
| 벽걸이 111 qty1000 | 35,320 | 2,130,320 | 디지털인쇄비·제본비 |
| 와이드 112 qty1000 | 149,220 | 2,369,220 | 디지털인쇄비·제본비 |

- **PRICE≠0 이지만 기본 경로는 인쇄비·제본비가 silent-0**(용지비만). 완전 선택 시 정상 매칭 확인.
- 근본: 인쇄비/제본비 구성요소가 `proc_grp:` 차원을 써서 **선택된 proc_cd 필요**. mand 인쇄(PROC_000004)는
  price-viewer가 자동선택(sim-meta `mand:true`)하나, **제본 proc는 mand_proc_yn=N=손님 선택**이라 미선택 시 제본비 0.

## GAP-CAL-1 [❌ 돈크리티컬] 장수 미모델링 → 인쇄비 낱장수 배수 저청구

- **증거:** 5상품 sim-meta 전부 `page_rule=null`. 엑셀 C17 장수=`4(8P)/8(16P)/12(24P)`·`12~16` 등
  선택형(상품별 다수). 라이브에 장수 차원(page_rule/변형)이 없음.
- **재현:** 108 qty1000 완전선택 → 디지털인쇄비 145,000(plate_qty=ceil(1000/pansu4)=250판 × 밴드단가).
  이는 **1개월 이미지 1판** 기준. 12개월 캘린더는 12종 낱장을 각각 출력 → 인쇄판수 ≈ 12배 필요.
  장수 미반영 → 인쇄비가 장수배(4~16×)만큼 저청구.
- **돈영향:** 대(인쇄비가 전체 캘린더의 주요 원가). 저청구 = 매출/원가 손실.
- **차단유형:** 가격 구조 미완(차원 부재). **라우팅:** 도메인 결정(장수=page_rule vs 인쇄 수량배수 vs
  가격차원) → `dbm-price-arbiter`(§18) 정립 → `dbm-price-import-builder`(§7) 적재. CONFIRM-CL-3 인간 결정 선행.
- **주의:** 캘린더 5상품은 예전사이트 pcode 미매핑(신규/통합상품·golden N/A) → 저청구 배수는 실무진 확인 필요.

## GAP-CAL-2 [🟡 오적재] 자재(mat_cd) 드롭다운에 부속 혼입

- **증거:** `t_prd_product_materials` 실측 —
  - 108(탁상): 스노우200·몽블랑190·아코팩·리사이클러스·매쉬멜로우·린넨커버·띤또레또·스타드림 **+ 링 블랙·삼각대(싸바리)**
  - 111(벽걸이): 용지 21종 **+ 링 블랙**(총 22행)
- **문제:** ① 삼각대(싸바리)·링 블랙=부속(거치/제본)이 "종이사양" 선택지에 노출 ② 108에 링블랙은
  벽걸이 트윈링 부속으로 **탁상형에 무관**(교차오염) ③ 자재 과다(111=22종=전 디지털 용지 무차별).
- **재현:** 손님이 mat_cd=삼각대/링 선택 → COMP_PAPER(plt_siz_cd+mat_cd) 매칭 실패 → 용지비 0 저청구.
- **돈영향:** 중(오선택 시 용지비 누락). UX 혼란.
- **차단유형:** 오적재. **라우팅:** `dbm-correctness-auditor`(§13/round-13) 상품별 자재 추출규칙 재도출 →
  부속을 mat_cd에서 제거(부속은 proc/addon으로) + 상품별 용지 목록 정합. `dbm-load-builder`(§7) 논리삭제.

## GAP-CAL-3 [🟡] 엽서캘린더·타공 가공 unpriced

- **증거:** 110 바인딩=PRF_DGP_INNER(구성요소=디지털인쇄비+용지비만·제본/타공 comp 없음). 타공 proc
  (PROC_000079군 PROC_000092/126/127)은 sim-meta proc 드롭다운에 노출되나, 캘린더 공식(CAL_DESK·
  CAL_WIDE·INNER) 어디에도 타공 가격 구성요소(COMP_CUT_PERF 계열) 미배선.
- **재현:** 110에서 우드거치대/타공 선택 → 가격 0 가산(unpriced). 111에서 타공(2구+끈) 선택 → 0 가산.
- **돈영향:** 중(가공 추가가 누락). 엽서캘린더는 가공이 정체(우드거치대·타공)라 특히 문제.
- **차단유형:** 가격사슬 미배선. **라우팅:** `dbm-price-arbiter`(§18)로 엽서캘린더 공식 재정의(제본/타공
  구성요소 포함)·타공 가격 comp 캘린더 공식 배선 → §7 적재. 우드거치대는 GAP-CAL-4(addon)와 연동.

## GAP-CAL-4 [❌] 캘린더봉투/우드거치대 addon 미연결

- **증거:** `t_prd_product_addons` 캘린더 5상품 전부 0행. 그러나 `t_prd_templates`에 캘린더봉투 템플릿
  **존재**(TMPL-000040 캘린더봉투 240x230mm 10장·TMPL-000041 캘린더봉투 150x310mm 10장). 우드거치대
  자재(MAT_000034 캘린더부자재 우드거치대 등) 존재.
- **재현:** 캘린더 주문 시 봉투/거치대를 추가상품으로 담을 수 없음(sim-meta addons=[]).
- **돈영향:** 소~중(부속 매출 누락). 봉투=사이즈종속(★사이즈선택) 캐스케이드 필요.
- **차단유형:** 미연결(템플릿은 mint됨). **라우팅:** `dbm-option-mapper`(§6/round-6)로
  t_prd_product_addons에 tmpl_cd 바인딩 + 봉투 사이즈종속 constraint → `dbm-validator` 게이트 → §7 적재.

## GAP-CAL-5 [🟡] 제본 proc mand=N + 조건부 제약 부재

- **증거:** 108/109/111/112 제본 proc(PROC_000099/100/102) `mand_proc_yn=N`(손님 선택). constraints=[]
  (링칼라=트윈링시만 조건부 미적재).
- **재현:** 손님이 제본 proc 미선택 → 제본비 0(기본 시뮬 15,550 사례). 링칼라 항상 노출(트윈링 아니어도).
- **돈영향:** 중(제본 미선택 시 대폭 저청구 — 제본비가 캘린더 원가의 큰 몫). 캘린더는 제본이 사실상 필수.
- **차단유형:** 옵션 무결성. **라우팅:** ① 제본 proc를 사실상 필수화(기본선택 or mand=Y 검토)=
  `dbm-correctness-auditor`/§34 거버넌스 ② 링칼라 조건부 제약=`dbm-option-mapper`(§6)+§31 제약규칙 → §7.

## GAP-CAL-6 [❌ 결정대기] 디자인캘린더 가격포함 고정가 미적재

- **증거:** 캘린더 5상품 `t_prd_product_prices` 0행. 디자인캘린더 별 상품(PRD_TYPE.04) 없음(병합).
  시트 §9 가격포함 고정가 4000~24000 미적재.
- **판정 대기:** 디자인캘린더 surface(에디터·디자인 제공)를 **공식형으로 동일 계산**할지, **가격포함
  고정가 별도**로 적재할지. 병합(editor_yn) 결정과 정합하면 공식형 재사용이 자연스러움 → 이 경우 §9는 불요.
- **라우팅:** CONFIRM-CL-1 인간 결정 → 공식형이면 무처리, 고정가면 `dbm-price-import-builder`(round-2) 적재.
