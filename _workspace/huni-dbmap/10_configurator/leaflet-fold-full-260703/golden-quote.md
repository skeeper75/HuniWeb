# 접지리플렛·와이드 접지리플렛 — evaluate_price 골든 (PRICE≠0 실증)

> 완전 견적 실증[HARD]: 손님 선택 → 차원 환원 → 가격 사슬 완결 → **PRICE≠0**. 이중합산 0·인쇄비 발현·
> 접지비 발현·코팅 제약 동작. 재계산기 = `golden_compute.py`(라이브 단가행 실측·엔진 산식 결정론 복제).
> 산식 모델은 **라이브 시뮬레이터 골든 2건으로 검증(오차 0)** 후 048에 적용 → 049는 라이브 실측.

## 0. 엔진 산식 모델 (라이브 골든 대조 검증 — 오차 0)

```
판걸이(pansu) = fn_calc_pansu(판형, 사이즈)          # 국4절 A5=4·A4=2·A3=1 / 3절=1 (실측)
출력매수(plates) = ceil(주문수량 / 판걸이)
인쇄비 = 인쇄단가(판형,도수,티어≤plates) × plates    # COMP_PRINT_DIGITAL_S1
용지비 = 용지단가(판형,자재) × plates                # COMP_PAPER
코팅비 = 코팅단가(판형,코팅면수,티어≤plates) × plates # COMP_COAT_GLOSSY/MATTE
접지비 = 접지단가(공정,티어≤주문수량) × 주문수량      # COMP_FOLD_LEAF_* (부 단위)
판매가 = Σ (원자합산형 PRF_DGP_E)
```

|-------------|------|-------------------|------|
| 047 소량전단지 A4/백모220/양면/1000 | 225,320 | **225,320** | ✅ 오차0 |
| 049 와이드 접지리플렛 3절/아트150/양면/3단/1000 | 639,540 | **639,540** | ✅ 오차0 |

## 2. 코팅 제약 동작 (코팅 × thin 종이 차단)

`R_EXCL_COATING_THIN_PAPER` (RULE_TYPE.02 금지) — thin(<180g) 종이 + 코팅 선택 시 **차단**:

| 선택 | thin? | 코팅 | 판정 |
|------|-------|------|------|
| 아트지150(MAT_000078) + 유광(OPV_000602) | thin(150<180) | 선택 | **BLOCKED** ✅ (제약 발동) |
| 아트지250(MAT_000081) + 유광 | 아님(250≥180) | 선택 | 허용 → Case B 정상 가격 |
| 아트지150 + 코팅없음 | thin | 미선택 | 허용 → Case A 정상 가격 |

- JSONLogic: `{"!":{"and":[{"or":[유광OPV,무광OPV]},{"or":[thin mat_cd__usage_cd 15종 열거]}]}}`.
- 048 thin 15종 열거에 MAT_000078 포함 확인 · 코팅 축 = OPV_000602(유광)/OPV_000603(무광) 확인.
- Case A(아트지150·무코팅)와 Case B(아트지250·코팅)는 **제약 통과**(정당 조합) → 오차단 0.
