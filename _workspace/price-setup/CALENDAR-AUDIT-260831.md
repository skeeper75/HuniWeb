1. **범위**: 가격공식 · 가격구성요소 · 가격뷰어. **상품뷰어·위젯은 실무진 영역 — 절대 손대지 않는다.**
2. **사실 지적 ≠ 교정 지시.** 지니가 사실을 말했다고 그 화면을 고치라는 뜻이 아니다.
   범위 밖이면 **보고까지가 내 일**이다.
3. **선택지에 교정안을 올리지 않는다.** 올리는 순간 범위 확장이 승인처럼 보인다.

## 8. 이번 세션에서 얻은 기술 지식 (다음 세션이 다시 겪지 않도록)

| # | 내용 |
|---|---|
| T-1 | **단가유형은 이름이 아니라 `pricing.py` `component_subtotal` 의 계산식으로 고른다.** 단가형=장당×수량 · **합가형=구간총액÷min_qty×수량** · **고정금액=수량 무관**. 「합가」라는 낱말과 `PRICE_TYPE.02` 는 다른 뜻이다 |
| T-2 | **차원 추가와 행 충전은 한 호흡에.** 중간에 저장하면 빈 축값 행이 **와일드카드로 이중매칭**된다(커팅비·타공비에서 2회 겪음) |
| T-3 | **옵션그룹을 가격축으로 쓰면 그 그룹의 모든 옵션에 행이 필요하다.** 0원 옵션도 0원 행이 없으면 위젯이 **「주문할 수 없습니다」로 막는다** |
| T-4 | **`opt_cd` 차원은 가격공식에서 파생된다**(`price_views.py:2213-2221`). 구성요소 `use_dims` 에 `opt_cd` 를 넣으면 옵션그룹이 가격축으로 미러된다. 선례: 일반현수막 `138`(`mirror_grps`) |
| T-5 | **옵션→공정 연결은 DB에 있어도 가격에 안 실린다** — `price_views.py:3084` 가 `maps` 를 빈 값으로 고정(`constraint_only` 하드코딩). 상품뷰어 「참조 1건」 배지가 그 연결의 화면 표현 |
| T-6 | **위젯 `cfg` 만 보고 판단하면 오판한다.** `items` 에 공정이 없어도 렌더러가 「후가공」 블록을 만든다. **분모는 렌더된 화면에서만** 얻는다 |
| T-7 | 위젯 미리보기 조작 도구: 루트 `.hw-root` · 공정 버튼 `data-psbtn`+`data-cd` · 옵션 버튼 `data-pvbtn`+`data-v`. 커스텀 컨트롤은 `mousedown→mouseup→click` MouseEvent 필요 |
| T-8 | 시뮬 API 함정: python 기본 UA → Cloudflare 403(`error code: 1010`) · 공정 상세키는 `sim-meta` 의 `detail[].key` 그대로(`"가로"` ≠ `"가로(mm)"`) · `side_sel` 공정은 `side:"F"` 필요 |
