# 상품↔사이즈 매핑 전수 감사 (260707)

**도구**: `raw/webadmin/tools/verify_size_mapping.py` (결정론·읽기전용·exit0/1). 실행 `../.venv/bin/python tools/verify_size_mapping.py [--prd|--json|--only]`.
**핵심(인쇄도메인·지니)**: **사이즈=재단사이즈**. 작업사이즈=재단+**블리드(여백)**, 블리드는 소재/상품/인쇄방식별로 다름
(엽서 1mm/변·전단지 2mm/변·반칼스티커 **0**=아이마크 격자). 그래서 형제 판정은 이름이 아니라 **재단사이즈로 묶고 블리드로 판정**.
**비규격 인지**: `nonspec_yn` — 규격(선택) vs 비규격(사용자 입력). 상품별 허용여부 표시.
**권위**: 블리드 정본 = pangeori 판걸이수 시트(상품별 블리드)+상품마스터. 교정=webadmin UI(§36).

## 도구 한계·주의
- **TAG_MISMATCH는 후보**(family=카테고리+상품명 대조). 오탐: 투명케이스↔투명PP케이스, 아크릴 교차사용(아크릴마그넷↔아크릴키링 사이즈 공유), SIZ_000007이 책자/포토북엔 A5로 정당할 수 있음(태그 미보강일 뿐). → 상품마스터 작업사이즈로 최종 판정.
