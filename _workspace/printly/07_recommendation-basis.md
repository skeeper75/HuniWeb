## 1. 추천 근거 사슬 — 3링크, 각 링크가 출처·등급을 가진다

```
업종 ──references──▶ 원자 마케팅 기능 ──references──▶ 인쇄물(아키타입)
[소진공 상권분류]      [AliCoCo 원자분해]              [셀별 전용상품 출처·●/○/△]
 강(공식기관)          방법론 근거(arXiv 2003.13230)    셀마다 실 URL + 신뢰등급
```

- 고객에게 보이는 **추천 이유 = 이 사슬 그대로** + 등급 언어. 이유가 곧 출처 사슬이라 "분명함"이 자동 성립.
- 각 링크 등급:
  - **업종**: 소진공 상권정보 분류(공식·KSIC 기반) = 강.
  - **원자기능 8**: AliCoCo 패턴(업종을 "왜 그 인쇄물이 필요한가"로 분해) = 방법론 근거.
  - **인쇄물 매핑**: 셀별 신뢰등급 ●강(전용 인쇄상품/체크리스트 실 출처)·○일반(범용 목록)·△추정(GAP).

---

## 2. 이유 표기 규약 [HARD] — 지니 확정 기준 = 출처+등급

등급을 어조로 정직하게 반영한다. **△를 ●처럼 말하지 않는다**(원칙4·지어내기 차단).

| 등급 | 근거 강도 | 고객 노출 어조 | 예 |
|---|---|---|---|
| **verified** (●·N≥3) | 강·전용상품 다중출처 | 단정 + 출처 | "카페 오픈엔 명함·도장쿠폰·A프레임을 **많이 씁니다** [오프린트미 체크리스트 외]" |
| **candidate** (○·N1~2) | 일반·소수출처 | 완충("알려져 있음") | "부동산은 보통 매물전단·현수막을 **쓴다고 알려져 있습니다** [출처]" |
| **추정** (△·N0) | 약함·GAP | 약함 명시 또는 미노출 | "~일 수 있습니다(근거 약함)" 또는 추천에서 제외 |

## 3. 워크드 예시 — "카페 오픈, 뭘 만들까?" 이유 (실 매트릭스)

`industry-classification.md §2-B` 카페 행 = 6개 ● 셀(오픈 체크리스트 8종 실 출처 = 8업종 중 최강 근거).

| 추천 홍보물 | 원자 기능 | 등급 | 이유 문장(출처+등급) |
|---|---|---|---|
| 명함 | AF-IDENTITY 신원제시 | ● | "매장 위치·SNS를 대면 전달용으로 명함을 씁니다" |
| 도장쿠폰 | AF-RETAIN 재방문 | ● | "재방문·단골화에 도장쿠폰이 효과적입니다" |
| A프레임·포스터 | AF-ACQUIRE 가두홍보 | ● | "지나가는 손님 시선 포착에 A프레임·포스터를 씁니다" |
| 메뉴판·원두카드 | AF-DISPLAY 상품노출 | ● | "취급 메뉴·원두 스토리 제시에 메뉴판·카드" |
| 포장스티커·데칼 | AF-BRAND 브랜딩 | ● | "포장 완성도·브랜드 감도에 스티커·데칼" |
| 오픈 현수막 | AF-EVENT 개업고지 | ● | "개업 단발 고지에 현수막·포스터" |

> 출처: 오프린트미 카페 오픈 체크리스트 · 비즈하우스 카페홍보(§2-B 인라인 URL). = **verified 후보(다중출처)**.
> → "카페엔 명함"이 제 판단이 아니라 **업체 오픈 체크리스트에 실린 근거**임이 사슬로 드러남.

## 4. 등급 승격 — 교차확증 증거기반 (지니 확정 = 강 근거만 verified)

> ★2026-07-04 국내외 4슬라이스 리서치로 근거를 두껍게 함 →
> **`research/print-materials-evidence-base-260704.md`**(교차확증 매트릭스·업종 8→12+·홍보물 9→50+).

- **승격 규칙**: 원자기능/셀당 **독립 출처 N≥3** → verified, 미만 candidate.
- **교차확증 승격분**(국내+해외 독립 출처): 카페·음식점·미용·학원·병원·부동산·소매 + 신규 4업종
  (헬스/피트니스·요가/필라테스·반려동물·네일). 원자기능 IDENTITY·ACQUIRE·RETAIN·DISPLAY·BRAND·
  FORM·SIGN 전부 4+ 업종 근거. 핵심: 국내 약했던 셀(음식점 메뉴판·부동산 야드사인)을 **해외 강출처
  [F](VistaPrint)가 보강**.
- **candidate 유지**: 꽃집·숙박·여가오락·자동차정비(N≤2) → 완충 어조.
- **정량 근거**: 매크로 광고비만 확보(인쇄 2조·옥외인쇄형 7,190억·KOBACO)·소상공인 세분 사용률 부재
  (GAP-IND-3) → 지니 확정대로 정량으로 등급 안 올림(출처+등급으로 충분).
- **게이트(생성≠검증)**: `okb-adversarial-verifier` / `mbo-verify-gate`로 ① [S] 출처 재fetch 실재성
  ② 원자기능↔인쇄물 매핑 타당성 ③ N 재실측 → verified 확정. 신규 4업종은 헬스만 [F]·나머지 [S](재fetch 필요).
- 게이트 결과가 §2 표기 어조를 결정(강근거=단정·나머지=완충).
