# N2 — 「정보·콘텐츠」 대분류 신설 결정

> 작성 2026-09-02 · lane `run-huniweb` · 카드 `CARDS-N.md §N2 추가`

## 결정 — **신설한다.** 단 4행만.

새 대분류 `정보·콘텐츠` 를 만들고 `STD-INF-001 ~ 004` 4행을 넣었다.
v2 의 대분류는 L1 16 + `생산·공정`(M3) + `정보·콘텐츠`(N2) = **18종**이다.

| std_id | 기능 | 근거 |
|---|---|---|
| `STD-INF-001` | 회사소개 페이지 | `IA-083`·`SCOPE-083` · L2 `SB-058` → `huni-skin-shopby/src/app/(main)/company/page.tsx:1` |
| `STD-INF-002` | 찾아오시는 길(약도·교통 안내) | `IA-086`·`SCOPE-086` · L2 `SB-058` → `location/page.tsx:1` |
| `STD-INF-003` | 이용약관 페이지 게시 | `IA-084`·`SCOPE-084` · L2 `SB-057` → `terms/page.tsx:1` |
| `STD-INF-004` | 개인정보처리방침 페이지 게시 | `IA-085`·`SCOPE-085` · L2 `SB-057` → `privacy/page.tsx:1` · `src/lib/legal/markdown.ts:1` |

## 왜 신설이 옳은가

### 1. 기존 16축 어디에도 「고객이 읽는 정적 문서」 자리가 없다

붙일 곳을 하나씩 검토했다.

| 후보 축 | 왜 안 되는가 |
|---|---|
| `상품·카탈로그` | 상품을 고르는 축이다. 회사소개는 상품이 아니다 |
| `클레임·CS` | 문의·응대 축이다. `STD-CLM-018` 공지·FAQ 가 이미 여기 있는데 **그것부터가 잘못 놓인 것**이다(아래 §3) |
| `시스템·플랫폼 › 품질` | 운영자 설정 축이다. **`STD-SYS-018` 「개인정보 보관·파기 정책 적용」에 `IA-084/085` 가 붙어 있는 것이 정확히 이 오류다** |
| `마이페이지` | 로그인 뒤 화면이다. 정보 페이지는 비로그인 공개다 |

### 2. `STD-SYS-018` 오귀속이 실제로 일어났다 — 신설하지 않으면 반복된다

`STD-SYS-018` 은 **「보관기간이 지난 개인정보를 파기한다」는 내부 정책 실행 기능**이다.
여기에 「고객이 읽는 개인정보처리방침 화면」과 「이용약관 화면」이 겹쳐 붙어 있었다.
셋은 서로 다른 일이고 담당도 다르다 — 앞의 둘은 스킨 화면, 뒤는 백엔드 배치다.
**붙일 자리가 없어서 가장 비슷해 보이는 곳에 붙은 것**이며, 자리를 만들지 않으면 같은 일이 또 생긴다.

### 3. shopby 라우트가 이미 6개 실재한다 (L2 실측)

| 라우트 | L2 asis | 상태 |
|---|---|---|
| `/company` `/location` | `SB-058` | done |
| `/terms` `/privacy` | `SB-057` | done |
| `/notice` | `SB-054` | done |
| `/guide` | `SB-055` | partial — 대부분 「준비중」 스텁 |

6개 화면이 실재하는데 표준목록에 축이 없다는 것 자체가 분모 결함이다.

## 왜 4행뿐인가 — 공지·FAQ·이용가이드는 **신설하지 않았다**

이미 표준행이 있다. 없는 것만 만드는 것이 원칙이다.

| 화면 | 기존 표준행 | 처리 |
|---|---|---|
| 공지사항 · FAQ (고객) | `STD-CLM-018` 공지사항·FAQ 열람 | **신설 안 함** |
| 공지사항 관리 (운영자) | `STD-ADC-007` · FAQ 관리 `STD-ADC-008` | 신설 안 함 |
| 이용가이드 11종 | `STD-CAT-019` 인쇄 가이드 콘텐츠(11종) · `STD-ADC-014` 관리 | 신설 안 함 |

### 다만 — 이관 권고 (v2 에서는 실행하지 않음)

의미상 아래 3행은 `정보·콘텐츠` 로 옮기는 것이 맞다.

| 현재 | 옮길 곳 |
|---|---|
| `STD-CLM-018` 공지사항·FAQ 열람 (클레임·CS) | 정보·콘텐츠 |
| `STD-CAT-019` 인쇄 가이드 콘텐츠(11종) (상품·카탈로그) | 정보·콘텐츠 |
| `STD-CAT-020` 템플릿/샘플 다운로드 제공 (상품·카탈로그) | 정보·콘텐츠 (경계 · 판단 필요) |

**옮기지 않았다.** `std_id` 는 `L4/{a,b,c}/mapping.csv` 596 매핑의 키이고, `대분류` 는 L4 3분할의 lane 경계이기도 하다.
지금 옮기면 세 lane 산출물의 도메인 경계가 사후에 흔들린다. **이관은 L4 원장을 다시 합칠 때 한 번에 하는 것이 옳다 — lead 판단 사항으로 넘긴다.**

## 미확인

- `/guide` 는 L2 가 `partial`(「준비중」 스텁)로 실측했다. **콘텐츠 실재 여부는 내가 다시 열어보지 않았다.**
- 전자상거래법상 푸터 사업자정보 표기 같은 **법정 고지 항목**은 legacy 3원장에 근거가 없어 넣지 않았다. 추정으로 행을 만들지 않는다.
