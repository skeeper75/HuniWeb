# okb-adversarial-gate — 적대 검증·질의 게이트 방법론

verifier·query-gate가 공유. 원칙: **모든 노드는 틀렸다고 가정, 반증 실패분만 생존.** 생성자 리포트는 참고만, 판정은 직접 재실측.

## 1. 기계 대조 우선 (토큰 절약·재현성)

수치·링크·lint·커버리지는 스크립트로 전수 대조하고, LLM 판단은 스크립트가 못 하는 곳(의미 왜곡·환각 개체·경로 논리)에만 쓴다. 이 레포 실증: 결정론 diff(wiring_scan·grid_diff)가 자연어 대조보다 정확하고 토큰 0. 검증 스크립트는 `05_verification/scripts/`에 보존(재실행 가능).

## 2. 6축 검증 체크

1. **출처 실재성** — 인용 원문을 직접 열어 "실재+그 주장 맞음" 확인. 왜곡 인용(원문은 🟡인데 노드는 ✅) 적발.
2. **권위 정합** — 노드 수치 ↔ 260702 CSV 캐시 스크립트 diff, 오차 0. 구권위(260610/260527) 잔재는 260702 diff 셀 목록과 교차 적발.
3. **오염 적발** — STALE 목록 인용·양면 표기 위반(라이브 오적재를 정답 표기)·환각 개체/관계(원천 어디에도 없는 그럴듯한 중간 개념 — LLM 특유 결함, 최우선 수색).
4. **그래프 무결성** — build_graph.py 직접 2회 실행(멱등)·고아/끊긴 링크/타입 위반/lint = 0.
5. **연결 완전성** — 상품→자재/공정/옵션→공식→구성요소→단가행 경로를 그래프 탐색으로 전수 확인. 끊김은 GAP 노드로 정직 선언됐는지(조용한 누락=결함).
6. **반증 패널** — 의심 노드는 3렌즈(도메인 원리=docs/kb / 데이터=엑셀·라이브 / 이력=MEMORY·CHANGELOG 확정 교훈)로 반증 시도. 불확실=🟡 강등(✅ 아님).

결함 보드 행 형식: `노드ID | 축 | 결함 | 증거(재현 쿼리/diff 출력/원문) | 심각도(가격영향=High) | 교정안 | 라우팅(builder/architect/curator/원천컨펌)`.

## 3. 블라인드 질의 프로토콜 (query-gate)

- 읽기 허용: `03_kb/`·`04_graph/`만. 원천 직접 열람=실험 무효. 가격 대조 단계에서만 라이브 허용.
- 시나리오 ≥12·유형 5종(구체 상품/용도 추천/조건 탐색/옵션 조합/거절형). 거절형 필수 — 범위 밖 질의에 환각 추천하면 최악 결함.
- 경로 기록 필수: 밟은 노드 체인을 남긴다. 경로 없이 맞은 답=FAIL(사전지식 오염).
- 가격 대조: KB 경로로 조립한 (공식·구성요소·차원) → 라이브 evaluate_price 실호출/시뮬레이터 POST → 오차 0. PRICE=0=결함신호. 라이브 자체 결함 케이스는 "KB 정답 vs 라이브 현재값" 양면 판정으로 분리.

## 4. O1~O7 판정 (단일 FAIL=NO-GO)

O1 출처 실재성 0결함 / O2 권위 정합 오차 0 / O3 오염 0(STALE·양면위반·환각) / O4 그래프 무결성(직접 재실행) / O5 연결 완전성(GAP 정직 포함) / O6 종단 질의 재현(≥12·5유형·가격 오차 0·거절 정직) / O7 생성≠검증 독립성.

NO-GO 라우팅: 지식 결함→builder, 스키마 한계→architect, 원천 부재→curator, 원천 자체 결함→사용자 컨펌 큐(실무진 질문서 패턴 재사용). 판정문에 검증 범위·표본/전수 여부·한계를 정직하게 명시("무결" 단정 금지).
