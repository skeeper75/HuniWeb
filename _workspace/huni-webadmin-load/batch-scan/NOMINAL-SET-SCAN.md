## ★권위 확정 — 떡메는 셋트 아님 (가격표 SOT·260705)
- **PRICE-SHEET-SOT-260705** 엽서북떡메 시트: `떡메 = 사이즈 × 장수/수량 · 단가(.01) · "셋트로 안 쪼갬·직접 룩업"`.
  → 후니 가격표 권위가 떡메를 **단일 완제품·직접 단가 룩업**으로 규정. 현행 `고정가세트`(097←098)는 SOT 위반.
- **상품마스터**: 떡메모지 008-0008 = 90×90mm·카테고리 008 문구·단일상품.
- **목표 모델(확정)**: 떡메모지 = 단일 완제품, 가격 차원 = **사이즈 × 장수(매수)/수량** 직접 단가. 셋트 wrapper 제거.
  - de-set 조치: 097 셋트 구성 해제(098 논리처리/흡수), 097 공식을 단일 완제품 단가룩업으로 정합(장수/수량 차원 확보).
- RED recon = 매수(장수) 축이 가격을 좌우하는지 경쟁사 실물 corroborate(사용자 지정 검증).
