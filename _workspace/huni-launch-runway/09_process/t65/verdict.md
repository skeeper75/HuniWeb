## 1. 무엇을 했는가

쇼핑몰 기능목록을 **프로세스**로 다시 묶었다. 기능 행은 "무엇을 만들 것인가"의 목록이지
"고객·운영자가 무엇을 겪는가"의 순서가 아니다. 이 카드는 담당 범위(클레임·운영·정산)의
**기능 행 151개를 38개 프로세스에 전수 귀속**시키고, 각 프로세스마다 흐름·분기 그림과
단계표·빠진 곳을 붙였다.

탑다운 순서를 지켰다 — **L0 몰 전체 → L1 대분류 5개 → L2 중분류 → L3 프로세스 38개 → L4 단계(기능 행) 151개.**

   그 사이 원본 main 에 4커밋이 더 들어가 반영되지 않았다.
2. **오픈 목표일 — `STD-SYS-032`.** 「라」 51건 대부분이 "1차에 넣는가"를 먼저 물어야 답이 나온다.

4. **프린팅머니 원장 소유(t62 `STD-MYP-051`).** t62 가 이미 6건의 선행이라고 적었고,
