# 인쇄 도메인 지식 체계 — CPQ 설계용 정리

> 출처: 260702 통화 P4(23:05–56:30). 신우진이 김동학에게 교육한 내용을 CPQ 온톨로지·견적 엔진 설계에 바로 쓸 수 있는 계층 구조로 재편성. 각 항목에 견적 로직 연결점(→ CPQ)을 명시한다.

## 1. 왜 이 지식이 필요한가 — 통화의 결론

"우리가 계속 브레이크가 걸리는 이유는 얘(엑셀)를 100% 이해하지 못해서 암묵지가 생기기 때문" (신우진, 22:36). 개발 중 막히는 지점은 코드 문제가 아니라 **도메인 개념의 공백**이다. 아래 지식은 옵션 그룹 명명, 제약조건 작성, 가격 공식 해석의 공통 언어가 된다.

## 2. 조판·판 (Imposition) — sheet_based 가격의 뿌리

### 2.1 핵심 개념

| 용어 | 동의어 | 정의 | → CPQ |
|------|--------|------|-------|
| 조판 | 터잡기, 인포지션, 합판, 판걸이 | 큰 용지(판) 위에 완성물을 여러 개 배치 | `imposition_count`(UP수)가 단가의 분모 |
| 판걸이수 (UP수) | 판수 | 한 판에 올라가는 완성물 개수 | 판걸이수 시트 = 세 시트 연결의 권위 소스(기검증) |
| 국4절 | — | 316×467mm. 디지털 인쇄 기준 판 규격 | 출력용지규격 조인 키 |
| 그리퍼 | — | 기계가 용지를 물고 있는 영역. 인쇄 불가 | 인쇄 가능 영역 = 판 − 사방 여백(예: 5mm) |
| 판 여백 | — | 상품 유형(스티커/명함/전단)마다 다름 | 판걸이수 계산이 상품 유형별 파라미터를 가져야 하는 이유 |

### 2.2 단가 산출 논리 (통화 예시 그대로)

명함 1장 원가 = 판 1장 가격 ÷ 판걸이수. "하나에 31원인데 2개를 올리면 100장에 50판만 필요" — 즉 `필요 판수 = ceil(수량 ÷ UP수)`, `지대 = 판 단가 × 필요 판수`.

### 2.3 판(版)의 역사와 용어 잔재

필름 → 아연판/동판(옵셋, CTP) → 디지털(판 없음). 디지털은 판비가 없지만 **용어는 "판"으로 남아 있음**. 옵셋/윤전(신문 롤) 분기 시 CTP 판비 항목이 부활한다. → CPQ: 인쇄 방식(디지털/옵셋/윤전/UV/특수)이 비용 항목의 존재 여부를 결정하는 **스위치 차원**.

## 3. 인쇄 방식 분류

| 방식 | 특징 | 대상 | 비용 구조 차이 |
|------|------|------|---------------|
| 디지털 | 판 없음, 다품종 소량, 자유형 커팅 가능 | 명함·엽서·소량 책자 | 판비 0, 커팅은 플로터/레이저(저속) |
| 옵셋 | CTP 판 필요, 대량, 동일 디자인 | 대량 전단·패키지 | 판비 발생, 도무송(톰슨) 커팅 |
| UV 인쇄 | 자외선 경화. 비종이 소재용 | 아크릴, 가죽 등 | 도수(7도/9도) 개념 등장 |
| 실사 출력 | 대형 잉크젯 | 현수막·포스터·배너 | 면적(area) 기반 과금 |

## 4. 소재 (Material)

- **낱장 용지**: 평량(g/㎡)이 곧 두께. "아트 150" = 아트지 150g. 낱장은 장당 가격 산정 가능.
- **롤 소재**: 폭×길이 기반. 낱장과 계산 방식이 달라 엑셀에는 "롤"이라고만 표기 → **롤 계산 로직은 시스템이 별도 구현해야 하는 미기재 영역**.
- **스티커 용지 계열**: 유포, 비코팅, 미색, 무광코팅, 유광코팅, 투명, 홀로그램 — 가격이 같은 용지끼리 묶여 있음. 후지(이형지) 개념 포함.
- 출력소재관리 시트를 보면 "후니프린팅이 쓰는 모든 소재를 알 수 있다" — 소재 마스터가 옵션 온톨로지의 1차 사전.

## 5. 후가공 (Post-processing) — 고객 옵션과 생산 공정의 분리

### 5.1 핵심 원리: 1옵션 ≠ 1공정

통화의 가장 중요한 설계 인사이트. **"카드 접지(2단 접지)" 옵션 하나 = 내부적으로 오시 공정 + 접지 공정 두 개**로 분해되어 생산에 전달돼야 한다. 두 공정은 물리적 공간·공정 라우트가 다르다.

→ CPQ: 옵션 레이어(고객 노출)와 공정 레이어(생산·원가)를 분리하는 **2계층 모델**이 필수. 가격표의 "오시+접지 합산 금액"은 옵션 레이어 가격이고, MES 전달 시엔 공정 단위로 풀어야 한다.

### 5.2 공정 사전

| 공정 | 동의어/영문 | 내용 | 가격 규칙 (통화 언급) |
|------|------------|------|----------------------|
| 오시 | crease, 누름선 | 두꺼운 종이에 자국 내기 | 접지와 합산 표기됨 |
| 접지 | folding | 2단 가로/세로, 3단 등. 가로/세로는 **동일 금액이라 묶임** | 테이블 적재 시 개별 분해 필요 |
| 미싱 | perforation | 절취선 | 구간 단가 |
| 모서리 | 귀돌이, 라운드 | 직각=무료(공정 없음), 둥근=유료 | 1~99개 2,000원 등 수량 구간 |
| 가변 | VDP, 넘버링 | 텍스트/이미지가 장마다 변경 | 가변텍스트·가변이미지 구분 |
| 코팅 | 유광/무광 | 표지 등에 결합 | 소재+인쇄+코팅 결합 계산식 존재 |
| 타공 | punching | 구멍. 명함용·배너용 크기 다름 | 배너 통풍 타공 4/6/8개 등 개수 과금 |
| 박 | foil stamping | §7 별도 상술 | 매트릭스 과금 |

### 5.3 커팅 분류

| 용어 | 정의 | 방식 |
|------|------|------|
| 재단 | 직각으로 자름 | 재단기 |
| 완칼(왕칼) | 후지까지 관통 | 도무송(톰슨 틀) 또는 플로터 |
| 반칼 | 스티커 상지만 자르고 후지 유지 | 동일 |
| 도무송 | 정형 틀(원형 10/15/20mm, 정사각, 직사각) | 옵셋 계열, 합판 도무송 |
| 자유형 | 임의 칼선 | 디지털 전용 강점 |

## 6. 책자 구조 — 세트상품의 원형

책 1권 = **내지 + 표지 + 면지** 3개 반제품의 결합 (기존 분석의 소책자 반제품 구조와 일치).

- **책등(스파인)**: 내지 종이 두께 × 페이지 수로 두께가 결정 → 표지 펼침 크기가 달라짐 → 표지 용지·조판이 달라짐. **책등 계산 공식 없이는 표지 가격을 낼 수 없다.**
- **제본 방식**: 무선, 중철(철심), 트윈링, D링, PUR, 리플렛. 중철·무선 등은 표지비가 제본가에 포함되지만, **하드커버(싸바리)는 표지비를 별도 계산** — 표지 = 종이+인쇄+코팅 결합 or 개별 합산.
- **하드커버 전용지**: 특수 인쇄(UV 등) 필요 → 인쇄 방식 스위치와 연동.

→ CPQ: 세트상품은 `구성요소별 하위 견적의 합 + 결합 규칙`. 책등처럼 **구성요소 간 파생 변수**(내지 사양 → 표지 사양)가 존재하므로 단방향 옵션 트리로는 표현 불가, 의존성 그래프 필요.

## 7. 박 (Foil)

- 색상: 금(유광/무광), 은, 먹, 청, 적, 동, 백박, 홀로그램, 트윙클 등.
- 과금: **크기(cm) × 등급(A/B/C/D/E) 매트릭스** — 행·열 교차 지점 값을 조회 (매트릭스형 아키타입의 대표 사례).
- 소형 박(명함급) vs 대형 박(책자급) 구분. **동판비**: 소형 박은 동판 5,000원이 무조건 선행 고정비. 책자 30×70은 11,000원 디폴트. → `박 가격 = 동판비(고정) + 박비(매트릭스)`.

## 8. 아크릴·굿즈·파우치 — area/unit 계열

- **아크릴**: UV 인쇄. 두께 T(1.5t/3t) × 단면/양면 → 내부적으로 **도수(7도/9도)로 변환해 생산 전달** (고객 비노출, 옵션→공정 분리의 또 다른 사례). 가격은 가로×세로 **차원(dimension)** 기반.
- **수량 구간 할인**: 아크릴·굿즈·문구·파우치 공통. 단, **아크릴 카라비너는 별도의 할인 구간** 보유 — 카테고리 상속이 아니라 상품별 오버라이드 가능해야 함.
- **액세서리**: 은색 줄, 고리, 카라비너(사각/자물쇠/하트/원형) 등 추가 옵션 가격 목록 존재.
- **코롯토**: 스탠드형 아크릴. 칼선·고리 등 인쇄 지식 없이는 옵션 존재조차 알 수 없는 상품 — 도메인 장벽의 예시로 언급.

## 9. 실사(포스터·사인) — area_based 계열

- 소재: 인화지, 매트지, 방수 포스터(접착), 접착 투명, PET, PVC, 그래픽천, 패브릭, 캔버스, 레더, 메시, 폼보드, 포맥스 등 — 실사 소재군이 가장 방대.
- 가공: 오바로크(현수막 테두리), 리본 끈, 각목, 로프, 고리, 타공 — **기본가에 미포함, 추가 가격**으로 별도 과금.
- 액자·족자 파생 상품 존재.

## 10. 상품군 상식 (옵션 명명에 필요)

- **명함**: 스탠다드/프리미엄/코팅/펄/투명/홀로그램/화이트/모양(대·미니) — 후가공 조합이 상품명이 되는 패턴. 과거 충무로 인쇄의 90%가 명함이었을 만큼 옵션 분화가 가장 심한 군.
- **포토카드**: 20장 1세트(단일 디자인 대량 B2B 딜 별도 존재 → 기업 견적 트랙 필요).
- **엽서북**: 엽서 여러 장을 북 형태로 묶은 세트상품. §02 문서의 고정가형 사례.
- **봉투**: 소봉투/자켓봉투/대봉투 — 용도가 옵션.

## 11. CPQ 설계로의 매핑 요약

| 도메인 사실 | 설계 반영 |
|------------|----------|
| 1옵션 = N공정 (접지=오시+접지, 양면=9도) | 옵션 레이어 / 공정 레이어 분리, 옵션→공정 매핑 테이블 |
| 판걸이수가 지대의 분모 | 판걸이수 시트를 권위 소스로 하는 imposition 서비스 |
| 인쇄 방식이 비용 항목을 켜고 끔 | price_component에 방식별 활성 조건(JSONLogic) |
| 책등 = 내지 사양의 함수 | 구성요소 간 파생 변수 그래프 |
| 롤·계산식 셀 = 미기재 로직 | 엑셀 밖 구현 필요 목록으로 별도 관리 (§02 암묵지 목록) |
| 카라비너 별도 할인 구간 | 할인 정책의 상품 단위 오버라이드 |
| 실사 가공은 추가 가격 | base_price 포함 여부 플래그 |
