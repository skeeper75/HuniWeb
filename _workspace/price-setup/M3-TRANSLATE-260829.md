### 닫힌 집합에서는 절대 임계가 아니라 **상대 비교**다

절대 임계 0.5 는 **열린 후보**(사이즈 641종·자재 707종)용이다. 스코프가 후보를 2~3종으로 좁힌 닫힌 집합에서는 최고점이 유일하고 여백이 있으면 그것이 판별이다.

```
「유광코팅」 vs 유광라미네이팅(GLOSSY 라이브 공정) = 0.375
「유광코팅」 vs 무광라미네이팅(MATTE  라이브 공정) = 0.222
                                   여백 0.153 · 유일 최대 ⇒ GLOSSY
```

코팅 유광·무광은 **단가가 완전히 동일**해(`huni-product-lifecycle.md` §7.4) 값으로는 영원히 안 갈린다. 이 판별이 없으면 8열 전건이 동점 미성립이 된다. → `m3_map.scoped_discriminate`

## 3. [HARD] 규칙에 박아 넣은 가드 5종 — 전부 실측된 오작동에서 왔다

| # | 가드 | 없을 때 실측된 오작동 |

| G-1 | **숫자는 이름이 아니다** — 순수 숫자 라벨은 코드 차원에 매칭하지 않는다 | 라벨 「100」이 자재 **23종**에, 「1」이 사이즈 **12종**에 붙었다 |
| G-2 | **동가 묶음 분해** — `/`·`,`·`·` 로 묶인 라벨은 조각마다 번역해 합집합 | 「A3 / A2 / A1」이 수치 `3` 으로 읽혔다. 권위 281건(가격표 206+상품마스터 75)이 이 형태 |
| G-3 | **상수 차원 선분리** — 라이브 값이 1종인 차원은 축 배정에서 뺀다 | `proc_cd`(디지털인쇄)가 제목 축을 가로채 판형이 행 축으로 밀려 0.679 로 떨어졌다 |

## 5. 잔여 11건 — 전부 사유 확정. 「나중에 확인」 없음

### 5.1 포스터사인 L1 기하 신뢰 불가 (5건)

`siz_width`/`siz_height` 부분 성립. 실패 라벨이 **사이즈가 아니다** — 인접 하위표의 머리글이다:

```
'가공옵션명' · '추가옵션명' · '사이즈 / 소재' · '사이즈 / 가공옵션' · '사이즈 / 옵션명'
'폼보드' · '화이트보드' · '블랙보드' · '포맥스보드'
'시트커팅 (무광 / 홀로그램)' · '아크릴스티커 (유광 / 미러)' · '무광(화이트/블랙)'
```

원인은 번역 규칙이 아니라 **추출본의 블록 경계**다. 포스터사인 시트는 L1 에서 **31블록 중 18블록이 수치셀 0**이고 전부 `data_start_row=None`(recovered)이다. 한 영역에 표를 여럿 겹쳐 놓은 시트라 추출기가 경계를 잡지 못했다.

**패치하지 않는다.** 휴리스틱으로 머리글을 골라내면 진짜 축 라벨을 지울 위험이 크다(§3 퇴행 이력). 이 시트의 L1 재추출이 옳은 해법이며, 그 전까지 포스터사인은 부분 성립으로 남긴다.

## 6. 이 문서가 하지 않는 것

- **미성립을 추측으로 메우지 않았다.** 목록이 비지 않은 것은 실패가 아니라 REQ-PG-011 을 지킨 결과다(`plan.md` R-1).
- **라이브를 고치지 않았다.** 제약 위반·오적재는 전부 **보고**다(§2.2.2 · R-14).
- **분모를 만들지 않았다.** 이 문서는 M3 산출 2(번역 규칙)까지다. 분모 생성(하위표별 교차곱 → 합집합)은 M1 이다.

## 7. 미검증 (경계)

- `bdl_qty` 는 **한 번도 관측되지 않았다** — 그 차원을 쓰는 구성요소 8종에 짝지어진 권위 하위표가 없다. 규칙은 수치 파싱으로 준비돼 있으나 실측 근거가 없다.
- ③ 왕복 관문은 **매핑 단계의 셀 수 대조로만** 확인했다(골든 3종). 셀 단위 단가 왕복(권위 셀 값 = 번역 키의 라이브 단가)은 M1 분모 생성 후에 가능하다.
- 포스터사인 L1 재추출은 하지 않았다(§5.1).
