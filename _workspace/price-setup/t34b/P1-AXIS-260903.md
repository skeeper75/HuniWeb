## 3. Blocker (리드 판단 대기 · 2건)

### ⛔ B-1. B1·B2 「흑백(1도)」 2열에 도달 경로가 없다

- 옛 그릇 `COMP_PRINT_DIGITAL_S1` 은 흑백/칼라를 `print_opt_cd` 에 실어 4값으로 쓴다: `POPT_000008`(단면1도)·`POPT_000009`(양면1도)·`POPT_000001`(단면)·`POPT_000002`(양면) — 권위 4열과 1:1 (`p1h`).
- 그런데 **`POPT_000008/000009` 를 등록한 상품이 라이브 전체에 0건**(`p1k`). 디지털인쇄 35상품은 전부 `POPT_000001`(단면)·`POPT_000002`(양면)만 등록 (`p1d`).
- 도수축으로 우회도 불가: 이 상품들의 도수는 `CLR_000005`(CMYK 4도)·`CLR_000001`(**인쇄 안 함**) 둘뿐 — **1도(흑백) 값 자체가 없다** (`p1g`,`p1n`).
- ⇒ 지금 그릇을 만들면 흑백 2열은 **적재는 되지만 영원히 선택되지 않는 행**이 된다. 옛 그릇도 이미 같은 상태(결함이 우리 것이 아님 · 승계된 상태).
- **판단 필요**: ① 권위대로 4열 다 적재하고 흑백 미도달을 알려진 상태로 인계 / ② 흑백 2열 보류하고 칼라 2열만 적재 / ③ 실무진에 상품 인쇄옵션 등록(POPT_000008/9) 요청 후 4열 적재.

### ⛔ B-2. B3 「금색·은색」 2열에 등록 상품이 없다

- 권위 B3 는 별색 5종(화이트·클리어·핑크·금색·은색)×단면/양면 = 10열.
- 라이브에 공정은 다 있다(`PROC_000008~012`). 그러나 **`PROC_000011`(금색)·`PROC_000012`(은색)를 등록한 상품 0** (`p1l`).
- 특히 `PRD_000022 금은별색엽서` 는 이름과 달리 **별색 공정을 하나도 등록하지 않았다** — 상품뷰어 등록 누락으로 보인다.
- **판단 필요**: 위와 동형(전 열 적재 / 3종만 / 실무진 등록 요청).

## 4. 추가 보고 (blocker 아님 · P2 유형 결정에 영향)

- **B6·B7 유형 불일치 후보**: 옛 접지 그릇은 전부 `.03`(고정가). 권위 제목은 「카드접지 **단가** (오시+접지)」이고 값은 수량 1개 5,000 → 2개 3,000 으로 **개당 단가가 내려가는 모양** — 고정 총액이면 수량이 늘 때 총액이 줄어드는 셈이라 앞뒤가 안 맞는다. `.01`(단가)일 가능성. **범위 밖(t15 유형 정정 카드)이라 손대지 않고 보고만** 한다.
- **B14 권위 오기**: r48 「옵션코드」 행의 2구 칸에 코드 대신 이름 `2구 6mm 타공` 이 들어가 있다. 이름은 `PROC_000127` 로 유일 매칭되므로 진행에 지장은 없으나, 회신 대기 목록에 넣을 것을 권함(#7 철자 건과 함께).
- **면수 축 존치 확정**: 브리프의 열린 질문(옛 그릇 `coat_side_cnt` 존치 여부)은 **존치**로 확정. 권위 B4/B5 2단 머리행이 단면/양면이고, `PROC_000013` 라미네이팅 코팅의 `prcs_dtl_opt` 가 `price_dim: coat_side_cnt` 를 직접 선언한다 (`p1c`). B3 도 동형(`PROC_000007` → `spot_side_cnt`).
- **디지털인쇄 상품 수**: 브리프 「32상품」 → 실측 **35상품** (`PRF_DGP%` 13공식 · `p1a`,`p1d`). 3상품 차이는 책자 내지 계열 포함 여부로 보임.
