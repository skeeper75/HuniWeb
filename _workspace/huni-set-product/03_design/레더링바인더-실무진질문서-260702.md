# 레더 링바인더 가격 — 실무진 확인 요청서

작성 2026-07-02 · 쉬운 말 정리(코드·전문용어 배제)

## 왜 여쭙나요 (배경)
홈페이지에 **레더 링바인더**(빈 바인더 · A4 · 레더 표지 · D링 · 면지) 상품이 올라와 있는데
**가격이 0원**으로 나옵니다. 이 상품 가격을 계산식에 넣으려고 가격표·상품마스터를 전부 뒤졌는데,
**"D링 바인더 만드는 값"이 어디에도 없습니다**(다른 건 다 찾았습니다). 아래 5가지만 정해주시면 바로 반영합니다.

이 상품은 **속지(본문 내지)가 없는 빈 바인더**입니다. 그래서 값은 크게 **① 표지(레더) + ② 바인더 제작(D링) + ③ 면지** 세 조각입니다.

---

## Q1. ★D링 바인더 "제작비"가 얼마인가요? (제일 중요)
빈 레더 D링 바인더 **한 개를 만드는 값**(표지 인쇄 빼고 — 하드케이스 만들고 D링 다는 값)이 얼마인가요?
- 수량이 많으면 개당 값이 싸지나요? (예: **1개 / 100개 / 1000개** 각각 얼마)
- 참고: 지금 우리 가격표엔 이런 제본값이 있습니다 —
  - **하드커버 트윈링 제본** = 100개 기준 8,000원/개
  - **싸바리바인더**(하드케이스) = 100개 기준 7,000원/개
  - **하지만 "D링 바인더"는 값이 없습니다.**
- → **트윈링 제본값(8,000)을 그대로 써도 되나요? 아니면 D링은 값이 다른가요?**
  (트윈링은 스프링 같은 철사링, D링은 여닫는 금속 링이라 만드는 방식이 다릅니다.)

## Q2. 표지 레더 인쇄값 — "레더아트프린트"로 계산해도 되나요?
레더 표지에 그림/디자인 인쇄하는 값을, 이미 파는 **"레더아트프린트"**(포스터쪽 레더 출력) 가격표로 계산하려 합니다.
- 표지 펼친 크기 **611×374mm**(A4 펼침) → 레더아트프린트 표에서 **19,000원/장**이 나옵니다. **이게 맞나요?**
- 표지 인쇄도 수량 많으면 싸지나요, 아니면 몇 개를 찍든 장당 같나요?

## Q3. D링 두께(31 / 42 / 56mm)에 따라 값이 다른가요?
바인더 D링을 31mm · 42mm · 56mm 중에 고르는데 —
- **두께마다 값이 다른가요, 아니면 다 같은가요?**
- (참고: 국내외 인쇄소·바인더 도매를 조사해보니, 두께는 "담을 수 있는 종이량"만 정하고 **값은 같게** 두는 곳이 대부분이었습니다. 두께 굵어져도 링 원가 차이는 몇백 원 수준이라서요.)

## Q4. 면지(맨 앞·뒤 색지)는 추가금인가요, 무료인가요?
면지(화이트 / 블랙 / 그레이 / 인쇄면지) 선택이 **돈을 더 받나요, 무료인가요?**
- 참고: 지금 자료가 서로 다릅니다 — **하드커버 링책자는 "면지 유료"**, **레더 하드커버 책자는 "면지 무료"**로 되어 있어서, **레더 바인더는 어느 쪽인지** 확인이 필요합니다.

## Q5. O링 / D링 선택이 값에 영향 주나요?
링 종류(O링 / D링)를 고르는데, **종류에 따라 값이 달라지나요?**

## 참고 — 다른 레더 상품은 이렇게 받고 있습니다 (판단 도움용)
| 상품 | 일반 | 레더 | 레더 추가분 |
|---|---|---|---|
| 만년다이어리 | 하드커버 12,000원 | 레더 하드커버 15,000원 | **+3,000원** |
| 하드커버 책자(구 사이트) | 전용지 | 레더 | **+3,900원** |

→ 레더라서 더 받는 값은 대략 **+3,000~3,900원** 수준이었습니다. 바인더도 이 정도인지 함께 봐주시면 좋겠습니다.

## 우리가 이미 정한 것 (확인만)
- 표지 레더 인쇄 = 레더아트프린트로 계산(Q2) · D링 두께는 값 무관 예상(Q3) — 이 둘은 조사로 거의 확정, **맞는지 확인만** 부탁드립니다.
- 실제 반영은 위 답 받은 뒤, 가격시뮬레이터 실화면으로 값 확인하고 진행합니다.
