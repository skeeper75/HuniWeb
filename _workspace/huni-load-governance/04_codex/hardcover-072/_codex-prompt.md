# 독립 적대 교차검증 요청 — PRD_072 하드커버책자 셋트 옵션 판정

당신은 후니프린팅 "적재 거버넌스"(옵션 그릇 규범)의 **독립 2차 교차검증자(codex)**다.
1차 검증자(Claude)의 결론에 동의하는지가 아니라, **원자료(규범+라이브 인벤토리 사실)로부터
스스로 판정을 재도출**하고, 아래 4개 가설을 **적대적으로 공격**하라. FP(정상 배치를 결함으로
오판)도 FN(진짜 결함을 놓침)도 둘 다 지적 대상이다. 근거 없는 단정 금지.

## A. 판정 규범 (유일 기준)

### 옵션 정당 3용도 (이 셋 중 하나 이상이면 KEEP 자격)
- **U-1 혼재 묶음(BUNDLE)**: 한 선택지가 자재+공정 등 2개 이상 축을 동시에 의미(옵션아이템 ref가 복수 축·item_seq 다중). 예: 아일렛=금속링 자재+타공 공정.
- **U-2 기준정보 밖 선택**: 손님이 골라야 하는데 기초마스터 6축(자재·사이즈·도수·인쇄옵션·공정·판형)에 대응 축이 없음.
- **U-3 생산 전달**: 선택 결과가 생산 작업지시에 자재·공정 BOM으로 전달돼야 함.

### 중복(MOVE-기준정보)의 정의 [핵심 적발]
"기준정보를 적재하고 **똑같이 옵션도 넣은 것**." 자재/사이즈/도수/공정/판형이 이미 기준정보로
바인딩돼 가격·생산이 성립하는데 옵션에도 같은 값을 넣어 **이중 관리**하는 경우 = MOVE-기준정보.
단, 옵션이 참조하는 ref_dim_cd.03 자재는 부모에 실재해야 하는 **필수 참조 백킹**(트리거
fn_chk_opt_item_ref 강제)이며 이는 중복이 아니라 필수 짝이다.

### 셋트 규범
- §3-4 [도수/인쇄옵션 print_opt]: 일반완제품=MUST · **셋트 부모=금지**(부모 본체는 제본, 도수는 인쇄 구성원 내지의 것) · 인쇄 반제품=MUST.
- §4 셋트 배치: 부모=그릇(제본/조립 본체 공식) · 표지·내지=구성원(member) · 면지=색상 자재·제본비 포함 **무가격**. 부모엔 옵션참조 자재만 유지.

### BLOCKED/처분 규칙
- 가격종속 옵션(ref_dim_cd로 단가행 매칭 또는 price_component 참조로 evaluate_price에 0 아닌 금액 기여)은 즉시 처분 시 가격 파손 → **BLOCKED** 분리.
- 최우선 가드: **손님 선택지 손실 0(오차단 0)**.
- 처분 6종: KEEP / RETIRE(잡음) / MOVE-기준정보(중복) / MOVE-제약(CN-6 오용) / MOVE-템플릿(addon) / EXTEND(불완전).

## B. 라이브 인벤토리 실측 사실 (2026-07-03 · 읽기전용 SELECT · 이 값을 사실로 사용)

셋트 PRD_000072 하드커버책자(셋트 완제품 .01 부모):
- **구성원(t_prd_product_sets)**: 073 표지(전용지), 284 내지, 074 면지(화이트), 075 면지(블랙), 076 면지(그레이). 전부 del_yn=N, sub_prd_qty=1.
- **옵션그룹 전수**: 정확히 1개 = 면지색(OPT_000064, use=Y, del=N), 옵션 3개.
  - 화이트 OPV_434 → item ref OPT_REF_DIM.03 = MAT_000382 (item_seq 1, 단일)
  - 블랙 OPV_435 → OPT_REF_DIM.03 = MAT_000383 (단일)
  - 그레이 OPV_436 → OPT_REF_DIM.03 = MAT_000384 (단일)
- **부모 072 자재**: MAT_000382/383/384 실재(del=N) — 옵션 ref 백킹.
- **면지 자재 가격**: MAT_382/383/384의 t_prc_component_prices = **0행**(무가격). 3색 동일.
- **면지색 옵션의 가격종속**: OPT_000064를 use_dims에 참조하는 price_component = **0개**(라이브 전수 — opt_cd 참조 component는 전부 아크릴·명함 상품).
- **면지 멤버 074/075/076 바인딩**: materials=0, processes=0, sizes=0, plate_sizes=0, print_options=0, price_formulas=0 → **전 바인딩 0(완전 빈 껍데기, 색 자재조차 없음)**.
- **부모 072 print_options**: POPT_000001(단면)·POPT_000002(양면) 보유, del_yn=N(활성). 내지 284도 동일 보유.
- **가격공식**: 부모 072 = PRF_HC_MUSEON_SET(표지+제본 합산) 바인딩 · 내지 284 = PRF_DGP_INNER · 표지 073 = 공식 없음(부모공식에 표지 포함).
- §23 선행: evaluate_set_price PRICE≠0·이중합산 0 이미 골든 입증(동작하는 셋트).

## C. 적대적으로 공격할 4개 가설 (각각 AGREE/DISAGREE + 근거)

**가설 1 — 삼중표현 중복 부정**: 면지색 옵션(OPT_064) + 면지 자재 MAT_382/383/384 + 반제품 멤버 074/075/076이 모두 "면지 색"을 나타내는데, 1차 검증은 이를 "중복 아님(옵션=selector, 자재=필수 ref 백킹, 멤버=빈 껍데기)"으로 KEEP 판정했다. 이 판정이 안일한가? 위 B의 "멤버 3종은 색 자재조차 없는 완전 빈 껍데기"라는 사실을 근거로, 이것이 진짜 구조 중복/오배치인가 아니면 정당한 참조 백킹 구조인가? 멤버 074/075/076의 존재 이유가 무엇이어야 하는가?

**가설 2 — 가격종속 N 오류 가능성**: 1차 검증은 면지 무가격(component_prices 0)이므로 면지색이 evaluate_set_price에 0 영향 = 가격종속 N = BLOCKED 불필요로 판정했다. 위 B 사실(면지 자재 무가격·opt 참조 component 0)이 이 결론을 지지하는가? 면지색 옵션을 지우면 셋트 가격이 파손될 위험이 있는가?

**가설 3 — 셋트 계층 정합(O-2)**: 부모 072가 print_opt 단면/양면(POPT_001/002)을 활성 보유. 규범 §3-4는 셋트 부모 도수/인쇄옵션 "금지". 이것은 규범 위반(처분 대상)인가, 아니면 "셋트 UI 부모가 손님선택을 내지로 전파하는 계층" 예외인가(내지 284도 동일 보유)? 셋트 공식이 제본만이라 이중청구가 없다는 점을 고려하라.

**가설 4 — O-1이 지금 처분할 실 결함인가**: 1차 검증은 멤버 3종 latent 합산 위험(향후 면지 자재에 단가가 붙으면 멤버 3종이 합산)을 "지금 무해·컨펌 큐(Low)·지금 처분 금지"로 유보했다. 이 유보가 정당한가, 아니면 지금 즉시 처분/정리해야 할 실 결함인가?

## D. 산출 형식
각 가설별로: `[가설N] AGREE / DISAGREE — 판정: <중복 여부/처분/BLOCKED 등> · 근거: <규범조항+라이브사실>`
그리고 1차 검증이 **놓쳤을 수 있는 새 결함**(FN)이나 **과잉 결함 오판**(FP)이 있으면 별도로 열거하라.
당신은 파일을 쓸 수 없다. 판정문만 출력하라.
