**무엇을 한 문서인가**: 실무진이 9/18에 확정한 운영정책 엑셀(`후니프린팅_운영정책_260918.xlsx`)을 현재 사이트의 이용약관·개인정보처리방침·화면과 한 줄씩 맞춰 봤습니다. 맞춰 보니 **엑셀만으로는 정할 수 없는 것 21건**이 나와, 그 결정을 요청드리는 문서입니다.

**왜 그냥 고치지 않았나**: 정답이 하나가 아니었습니다. 같은 항목을 두고 엑셀·FAQ·개발계획·정기미팅 확정본이 서로 다른 값을 말하는 경우가 반복해서 나왔습니다. 어느 쪽이 맞는지는 만든 분들만 아십니다.

| 출처 | 시점 | 값 |
|---|---|---|

| 개발 계획 `STD-MYP-025` | 미착수 | 소멸 없음 |

**같은 질문에 값이 세 가지**입니다. 그리고 개발 쪽 완료 판정 기준이 이렇게 적혀 있습니다.

> `check_method` — 이용약관에 **「프린트머니 소멸 없음」이 고지되고**, 충전권 상품의 적립률이 0으로 설정되어 있으면 완료

약관에 「5년」을 쓰면 이 항목은 완료 판정을 받을 수 없습니다. 문구 하나가 개발 완료 조건과 맞물려 있습니다.

### 이 건은 오늘 끝낼 수 있습니다

`STD-MYP-025` 는 상위 「토스페이먼츠 계약 회신 대기」 밑에 묶여 목표일이 비어 있지만, 실제로는 이렇습니다.

- `prereq` = **없음** (선행 조건 없음)
- `작업량` = **반일**

**토스 회신을 기다리는 건이 아닙니다.** 사내에서 값만 정하면 반일이면 끝납니다.

## 4. 결정 없이 바로 반영 가능한 것 (20건)

엑셀이 유일한 출처이고 충돌이 없는 항목입니다. 승인해 주시면 약관에 반영하겠습니다.

**쿠폰** — 특가·맞춤제작 제외 명시 / 만료 쿠폰 재발급 불가 / 복원 조건을 「접수대기 이전 + 전체 취소 + 유효기간 내」로
**회원등급** — 구매금액 산정 = 배송완료 상태 기준
**리뷰** — 작성기한 배송완료 30일 이내 / 등록 즉시 노출 / 비노출 사유 3종 보강(개인정보 노출·타사 광고·저해상도)
**증빙서류** — 발행 대상 결제수단 한정 / 쿠폰·머니 제외 실결제금액 / 프린팅머니는 충전시만 / 주문월 말일까지 / 미신청·취소분 재발행 불가 / 카드는 승인일 자동발행 / 이메일·온라인 전용
**프린팅머니** — 가상계좌 전용 충전 / 충전·환불 시 증빙 처리

여기에 하나 **정정**이 있습니다. 현행 약관 제12조의2에 「증빙 발급 및 정정 기한은 관련 세법에서 정한 바에 따릅니다」 라는 문장이 있는데, **운영정책 어디에도 없는 문장**입니다. 실제 기준은 「주문일자의 해당월 말일까지」이고, 세법 기한이 더 길어서 이 문장이 회사를 불리하게 만듭니다. 삭제하고 실제 기준으로 바꾸겠습니다.

## 확인한 방법과 한계

**어떻게 확인했나** — 엑셀 두 판을 프로그램으로 읽어 셀 단위로 비교했습니다. 사람이나 AI가 눈으로 옮겨 적으면 숫자가 틀리므로, 값은 전부 셀에서 직접 읽었습니다. 각 항목에는 어느 시트 어느 칸에서 나왔는지가 붙어 있습니다.

**확인하지 못한 것** — 실제 결제 연동 설정(가상계좌인지 지정계좌인지), 자동취소 배치의 실제 동작 여부는 문서로는 확인할 수 없어 확인 요청 항목(16번)으로 넘겼습니다. 구현 현황 판정은 개발 계획서와 코드 두 가지 근거로만 했습니다 — 관리자 화면 목록은 고객 화면을 담고 있지 않아 이번 판정에는 쓰지 못했습니다.
