## 2. 앞 분류 대비 핵심 정정

### ★정정-1 (최대) — 자유치수 크기 범위 27상품: "누락(제약신설 필요)/C-9 개발 필요" → "정합검증만·엔진이미처리·제약불필요"
- **앞 분류**: 포스터 13 + 아크릴 14 = 27상품을 CN-5 NONE-BOUND로 두되, "누락(미등록)" 또는 "제약있음(RULE_001)"으로 표기하고
  **C-9 폼빌더 수치범위 개발**을 공통 병목으로 지목(가격 리스크는 낮다고 했으나 여전히 제약 트랙 후보로 둠).
- **재판정(사상)**: 크기(siz_width/siz_height)는 **TIER_DIMS로 엔진이 ceiling+ERR_ABOVE_MAX로 이미 처리**하고, 범위 하한은
  **상품컬럼 nonspec_*_min/max에 이미 존재**. CN-5 규정 "상품컬럼에 이미 있으면 제약 금지(중복)"에 정확히 해당 →
  **제약규칙 불필요**. 필요한 건 "권위 max ↔ 단가행 max tier 정합"뿐이고 **21상품 전수 PASS**(불일치 0).
  ★**C-9 폼빌더 수치범위 개발은 가격 정확성엔 불필요** — 크기 범위를 제약규칙으로 만들 이유 자체가 소멸.

### ★정정-2 — 포스터 기존 RULE_001 .01 (7상품): "정상(강제계층)" → "중복제약·은퇴 후보"
- 118·120·121·122·124·125·139의 RULE_001 .01 논리 = nonspec width/height min·max 범위 체크 = **상품컬럼 + 엔진 ceiling과 삼중 중복**.
- 단가행 자동유도 원칙 위반·drift 위험 → 은퇴 후보(DB 미적재·사용자 결정). 오차단 위험은 없음(범위는 실제로 정합).

### ★정정-3 — 박크기 범위 7상품: "CN-5 BLOCKED-VAR(제약 후보)" → "엔진외·가격영향無·주문가드(§6)·제약 트랙 제외"
- 박크기(foil_w/foil_h)는 `evaluate_price`가 참조하지 않는 차원 + 박비용은 박칼라(옵션)가 가름 → **무가격**.
- 제조 경계(CN-1)+주문가드일 뿐 → 위젯 UI 유효범위 배선(§6)으로 처리. 제약규칙 대상 아님(권위 min/max 실재는 §6 입력).

### 정정-4 — 아크릴 NULL고정가 4상품: "누락(C-9)" → "엔진이미처리(크기 무가격·주문가드만)"
- 153·155·156·171: 단가행 크기 tier가 전부 NULL=크기 무관 고정가 → 크기가 가격을 안 가름. 정합검증조차 불요.

### 유지(변동 없음)
- 진짜 가격영향 제약 확정 6(폼보드·포맥스보드 GRID-GATE / 소량전단지·접지리플렛·와이드접지리플렛 코팅×종이 / 프리미엄엽서 오시미싱)은 사상과 정합 — 정확매칭 조합/PROC on-off로 엔진 미처리 → 제약 정당.
- AMBIG(오시미싱 3·커팅사이즈 2·박최소수량 6)·ZERO-DEFECT 5(§7)·058 죽은규칙은 앞 판정 유지.

## 3. 냉철 결론
- 사상 적용으로 **"제약신설 필요" 실질 후보가 대폭 축소**: 앞 CSV에서 제약 트랙으로 잡혔던 자유치수+박크기 34상품(27+7)이
  **전부 제약 대상 아님**으로 정정(엔진 tier / 상품컬럼 / 엔진외 무가격). 진짜 신설 필요는 **정확매칭 조합 엇갈림·PROC·조건부**뿐.
- **크기 범위 정합 불일치(매출 차단 위험) = 0** — 21상품 전수 단가행 max tier가 nonspec max 커버.
- **C-9 폼빌더 수치범위 개발의 가격 정당성 소멸** — 크기 범위는 제약규칙이 아니라 §6 UI 배선/엔진 tier의 몫.
- 기존 중복 제약 정리 대상 = **포스터 RULE_001 .01 7건**(은퇴 후보·오차단 위험 없어 저위험).
