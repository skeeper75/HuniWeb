## PRD_000016 프리미엄엽서 — R_DEMO_VIS / R_DEMO_EXC → **PASS (무수정)**

### R_DEMO_VIS (RULE_TYPE.01)
```json
{"or": [{"!": {"in": ["OPV_000018", {"var": "sel_opts"}]}},
        {"in": ["OPT-000007", {"var": "sel_opt_grps"}]}]}
```
- **역파싱**: PARSEABLE ✅ (`.01` or-implication, 조건=옵션 in, 결과=옵션그룹 in — 역파서가 복원).
- **명명**: `R_DEMO_VIS` + 규칙명 `[DEMO] 양면 선택 시 가변텍스트 노출` — 데모 표기 규칙명 내장(규약 정합).
- **err_msg**: 비어 있음. 단, 이 규칙은 `.01` **가시성/호환(옵션 노출)** 규칙 — 손님 선택을 막는
  차단 규칙이 아니라 조건 충족 시 옵션그룹을 드러내는 성격 → err_msg 부재가 기능상 정당.
- **판정**: **PASS(무수정)**. (선택 권고: 필요 시 안내문 추가 가능하나 필수 아님.)

### R_DEMO_EXC (RULE_TYPE.02)
```json
{"!": {"and": [{"in": ["OPT-000005", {"var": "sel_opt_grps"}]},
               {"in": ["OPT-000006", {"var": "sel_opt_grps"}]}]}}
```

- **명명**: `R_DEMO_EXC` + `[DEMO] 오시·미싱 동시 불가` — 정합.
- **err_msg**: `오시(접지선)와 미싱(절취선)은 동시에 적용할 수 없습니다.` — 왜(동시 불가)+무엇(택일 암시).
  쉬운 한국어. 정합.
- **판정**: **PASS(무수정)**. 판례 P-2/REF-1 "선택지=그룹, 관계=제약"의 교과서 사례.

## PRD_000058 반칼원형스티커 — RULE_001 → **FAIL (수정안: CONFIRM-QUEUE)**

```json
{"!": {"and": [{"===": [{"var": "siz_cd"}, "SIZ_000426"]},
               {"in": ["OPV-000066", {"var": "sel_opts"}]}, ... (OPV-000067~073) ]}}
```

### 결함 3건
1. **type↔shape 불일치**: `rule_typ_cd=RULE_TYPE.03`(필수동반)인데 logic 은 `{"!":{"and":...}}`
   = `.02`(금지 not-and) 형태. `.03` 역파서는 최상위 `"or"` 를 기대 → **RAW-ONLY(역파싱 실패)**.
2. **부패(dead rule)**: 조건 `siz_cd === "SIZ_000426"` 인데 이 상품 제공 사이즈는
   **SIZ_000170(A5)·SIZ_000520(A4 반칼)뿐 — SIZ_000426 미제공**. antecedent 영구 거짓 →
   `and` 영구 거짓 → `!`=영구 참 → **어떤 조합으로도 발동 안 됨(죽은 규칙)**.
3. **옵션 미해소**: OPV-000066~073 이 이 상품 옵션에서 조회되지 않음(코드 실재성 미검증).
   err_msg 도 비어 있음.

### 수정안 (직접 재author 하지 않음 — 이유)
- 규칙명 `A5 커팅` 과 코드(SIZ_000426)가 **불일치** → 원 의도가 "A5(SIZ_000170)일 때 커팅
  옵션 필수"인지 불명확. spec §"에러 핸들링"(후보 근거가 라이브 재실측과 불일치 → 설계 보류+
  curator 반송 · AMBIG 는 컨펌 큐)에 해당.
- **처리 = CONFIRM-QUEUE** (본 designer 가 apply-fix 에 미포함). 실무진/curator 컨펌 필요:
  - Q. 원 의도가 "A5 크기 선택 시 커팅 옵션 필수동반"인가?
  - 컨펌 시 정형 수정안(폼빌더 역파싱 가능·`.03`):
    ```json
    {"or": [{"!": {"===": [{"var":"siz_cd"}, "SIZ_000170"]}},
            {"in": ["<실재 커팅 opt_cd>", {"var":"sel_opts"}]}]}
    ```
    (조건=siz A5, 결과=커팅 옵션 in — 단, 실재 opt_cd 재확인 후).
  - 원 의도가 없거나 데모 잔재면 **논리삭제**(del_yn='Y') 권고.
- **현 단계 산출**: 결함 기록 + 수정 방향 제시까지. **RAW-ONLY·dead·코드불일치 3중** → 무단 재author 금지.
