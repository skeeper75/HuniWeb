# 샵바이 상품정보 재매핑 — 세션 핸드오프 (2026-08-22)

## [HARD] 대전제
1. **라이브 DB가 권위이고 불가침** — 실무진이 만든 구조. 카테고리는 분류가 아니라 상품 뷰어의 실무 동선이라 건드리면 매일 쓰는 화면이 바뀐다.
2. **샵바이를 라이브에 맞춘다** — 한 방향.
3. **이미지는 샵바이가 사실상 원본** — 라이브 `t_prd_main_imgs`에 PRD_000027 6행뿐. 나머지 265상품 이미지는 샵바이에만 존재. 지우면 복구 불가.
4. **이번 범위는 상품정보뿐** — 이름·관리코드·전시카테고리·이미지. 주문옵션(위젯)은 다음 단계이고 샵바이와 무관.
