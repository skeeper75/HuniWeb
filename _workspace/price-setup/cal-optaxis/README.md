# 캘린더 「가공」 옵션그룹을 가격축으로 전환 (2026-08-30)

지시(지니): 「위젯에서 **가공으로 보여지는 부분이 모두 옵션그룹**으로 보여지는 거네..
이 부분 확인해서 **가격과 연결**해줘」 · 승인: 타공+제본 함께 전환

선행: `../cal-tagong-wire/`(공정축 배선) · `../calendar-structure-audit/`

## 1. 지니 지적이 정확했다 — 위젯 DOM이 증명한다

| 위젯 라벨 | 정체 | DOM | 전환 전 가격 |
|---|---|---|---|
| **후가공** | 공정 | `data-psbtn` · `data-cd="PROC_000127"` | **붙음** |
| **가공** | 옵션그룹 | `data-pvbtn` · `data-v="OPV_000971"` | **안 붙음** |

「가공」이 **권위 상품마스터 「캘린더가공(필수)」 S열과 1:1**이고, 고객이 실제로 고르는 자리다.
그런데 가격은 별도의 「후가공」 공정에서만 붙었다 — **고객 선택과 과금 지점이 어긋나 있었다.**

## 2. 왜 옵션→공정 연결이 안 먹었나

상품뷰어 › 가공 › 2구타공+면끈 › 구성요소에 **「공정 · 2구 6mm 타공」이 이미 등록돼 있다.**
그런데 `price_views.py:3084` 가 옵션그룹의 `maps` 를 **무조건 빈 값으로 고정**한다:

```python
"maps": {"dims": {}, "procs": []}   # (옵션별)
"constraint_only": True,   # 가격 미반영(maps 없음) — 신·구 그룹 전부 유지
"price_relevant": False,
```

⇒ DB의 옵션→공정 연결이 가격·위젯 경로로 **전달되지 않는다.** 코드 레벨 미구현이다.

## 3. 연결 경로 — 선례가 있었다

`opt_cd` 차원은 **가격공식에서 유래**한다(`price_views.py:2213-2221, 2405-2418`).
구성요소 `use_dims` 에 `opt_cd` 를 넣으면 그 상품의 옵션그룹이 **가격축으로 미러**된다.

**일반현수막 `138` 이 정확히 그 구조다**:

```
opt_cd dim | label: 「가공 / 부자재」 | priced: true
           | mirror_grps: ['OPT_000003','OPT_000004']
```

캘린더도 같은 방식으로 전환했다. **코드 수정 없이 가격층 데이터만으로 해결된다.**

## 5. [HARD] 실행 중 잡은 것 둘

### 5.1 빈 축값 행이 남았다

차원을 `opt_cd` 로 바꾼 직후 저장하니 **`opt_cd` 가 빈 행이 1건 남았다**(자연키가 달라 별도 행).
빈 축값은 와일드카드로 동작해 이중매칭을 낸다(이번 세션 커팅비에서 겪은 것과 같은 형태).
**즉시 제거**했고, 이후 모든 저장에서 빈 행 0을 확인했다.

### 5.2 0원 행이 없으면 「주문할 수 없습니다」로 막힌다

「재단만」을 고르자 위젯이 가격을 내지 않고 이렇게 막았다:

> 옵션코드 '재단만 (OPV_000970)' 선택은 '제본비 벽걸이캘린더(가공 옵션축)' 단가가
> 등록되지 않아 **주문할 수 없습니다**

도메인 규칙 §7 의 첫 번째 결함 형태(필수 옵션에 단가행 없음 → 주문 불가)다.
**권위상 재단만은 0원**이므로 0원 행을 채워 닫았다.

⇒ **옵션그룹을 가격축으로 쓸 때는 그 그룹의 모든 옵션에 행이 있어야 한다.**
값이 0인 옵션도 0원 행이 필요하다 — 없으면 주문이 막힌다.

## 7. 남은 것

- **공정 「후가공」 블록이 위젯에 여전히 노출된다.** 이제 거기서 골라도 가격은 안 붙는다
  (가격은 「가공」 옵션그룹으로 이동). 생산 전달용으로는 공정이 필요하나,
  **고객 화면에서 두 자리로 보이는 것은 그대로다.** 위젯 구성 영역 — 지니 판단 사항.
  숨기려면 위젯빌더에서 해당 항목의 `visible_yn` 을 조정한다.
- **`112` 에 「제본없음(재단만)」 옵션이 없다.** 권위 T27 에는 있다(0원).
  라이브 옵션그룹 `OPT_000310` 은 「고리형캘린더제본」 하나뿐이라 고객이 제본을 뺄 수 없다.
  상품 구성 영역이라 손대지 않았다.
- 가격표 「커팅타공」 `D42` 라벨 귀속 미해소(`../cal-tagong-wire/` §8).
