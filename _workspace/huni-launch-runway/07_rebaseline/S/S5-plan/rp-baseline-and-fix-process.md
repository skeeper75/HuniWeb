### 4-1. 선행 — 뿌리 하나를 먼저 확정한다

결함 **B·C·E** 와 `/mypage/address` 미로드는 **한 뿌리로 추정**된다: 서버 렌더 화면은 세션을 인식하는데, 브라우저가 직접 부르는 API 화면만 회원 토큰을 못 찾는다.
관측 근거: `document.cookie` **0개** · localStorage 에 회원 토큰 **없음** · `huni_guest_cart` 만 존재. 그런데 `/mypage`·`/mypage/orders`·`/mypage/point` 는 회원 데이터로 렌더된다.

**따라서 코드 확인의 1순위는 「회원 토큰이 어디에 저장되고, 클라이언트 호출에 어떻게 실리는가」 한 곳이다.** 이것이 확정되기 전에 B·C·E 를 각각 고치면 같은 버그를 세 번 고치게 된다.

- **병행**: 6(증빙·사업자번호)은 1~5와 무관하다. 담당이 다르면 동시 착수.
