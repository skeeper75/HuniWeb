## 1. 인쇄/제책 도메인 지식 — 링바인더 원가 구조

### 1.1 링 메커니즘(금속) 원가는 두께에 "미미하게" 비례
- 바인더링(O/D 금속 부속)은 규격(내폭·지름)별로 **수용량**이 결정된다. 대표 규격: O링 지름 38mm(폭 26)·58mm(폭 36) 등. `[celltong/akobigs/misumi 도매]`
- **도매/소매 단가 = 규격에 따라 약 800~2,100원/개** 수준(북바인딩 부속 리테일). `[WebSearch 바인더링 규격]`
- 즉 31mm→56mm로 커져도 **금속 원가 절대 차이는 수백 원**. 완제품가(빈 레더 바인더 수천~수만 원)에서 차지하는 비중이 작다 → **두께를 가격 차등축으로 삼을 근거가 도메인상 약하다.**
- **D링 vs O링**: D링은 'D'자라 넘김이 부드럽고 다량 보관 시 종이 쏠림이 적어 **O링보다 수용량↑**. 기능/수용량 차이지 원가 차이는 미미. `[WebSearch·레드 landing]`

### 1.2 링 두께의 진짜 역할 = "수용량 제약"
- 검색 도메인 정리: "규격(A4/A3) 외 가장 중요한 옵션은 **'내폭' 또는 '링 사이즈'이며, 이는 바인더가 수용할 수 있는 최대 종이량을 결정**." `[WebSearch]`
- → 링 두께(31/42/56)는 **면지/속지 최대 매수의 상한**을 정하는 축. 가격이 아니라 **제약(constraint)·수용량 스펙**으로 모델링하는 게 도메인 정합.

### 1.3 빈 바인더 vs 내지 포함 — 후니 088은 "빈 바인더"
- 088 = **내지 없음**(표지 레더 + 면지4 + 링). 즉 책 본문(내지) 가격이 없다 → 082(하드커버링·내지 있음)보다 **부품이 하나 적다**(내지 member 불요).
- 원가 = **레더 표지(인쇄+코팅+용지) + 링 조립(제본공정) + 면지**. 면지는 후니 권위상 유·무료 결판 필요(082=유료 명시 / 077=무료).

### 1.4 제책 방식별 원가 부품 수(내부 지식·booklet 벤치마크)
`[_workspace/.../absorption-candidates-booklet.md:54-56]`
- 중철: 부품 최소(제본비 단일항 정당) → 무선/PUR(표지+내지+제본 3항) → **트윈링/링(+링자재)** → **하드커버(싸바리): 표지=하드보드+싸개+면지 = 최다 부품**.
- **링바인더는 "표지 + 링자재 + 제본공정" 조합** — 무선보다 링자재 1항이 더 붙는다. 후니는 이미 이 분기를 comp 11종으로 보유.

`[[leather-hardcover-077-live-commit-260701]]`
- **082 하드커버링 = 088의 직전 형제**(이미 라이브 COMMIT: 0원→44,123). 082에서 배운 것:
  - 링 제본은 무선 부모공식 `PRF_HC_MUSEON_SET` **재사용 불가**(S8 옵션 오염=링에 무선 제본단가) → **링 전용 `PRF_HC_TWINRING_SET` 신설**(분해형)로 해소.

- **레더 프리미엄 "정액 addon" 실패(엔진)**: `COMP_HC_MUSEON_COVERBIND.use_dims=["min_qty"]`만 → 레더 단가행(mat_cd) 추가 시 `_row_matches`(pricing.py:94)가 use_dims 무관하게 mat_cd 검사 → NULL밴드+레더 combo 2개 = **ERR_AMBIGUOUS → 합산 제외(전체 0원)**. → **뭉친 COVERBIND에 레더 정액행 넣으면 오히려 0원.** 레더는 **분해된 표지의 용지(자재)축**으로 넣어야 함(정액 addon 아님).

- **068 소프트커버 = 표지 3비목 분해 성공 사례**: `PRF_BOOK_COVER`(인쇄+코팅+용지) 신설·표지 member 분리(완제품 판형≠표지 단가행 판형 → member 필연)로 158,688 동작. **(d) 커버 분해가 후니 라이브에서 이미 검증된 패턴.**

## 5. 종합 권고 — 088 레더 링바인더 가격 구조

### 5.1 구조 권고 (a~d 중)
**채택: (d) 커버 분해 = 표지(레더인쇄 + 코팅 + 레더용지) + 링제본공정 + 면지.** (088은 빈 바인더라 **내지 member 없음** → 082보다 단순)

근거 3중 수렴:
1. **후니 권위(계산공식집)**: 하드커버 표지비를 인쇄+코팅+용지+제본으로 분해 → (d)와 일치. **레더 프리미엄은 "레더용지 단가 차액 + 레더 특수인쇄"에서 발생**(ASP +3,900 정액은 뭉뚱그림).
2. **후니 라이브 검증 패턴**: 068(`PRF_BOOK_COVER` 3비목 분해)·082(`PRF_HC_TWINRING_SET` 링 분해) 이미 동작 — (d)가 실현 가능 입증됨.
3. **엔진 제약**: 뭉친 COVERBIND + 레더 정액행 = AMBIGUOUS 0원(§4). 레더는 분해 표지의 용지축이라야 정합.

### 5.2 기각/보류
- **(b) 링 두께(31/42/56) 차등 = 기각.** 국내(레드)·국외(Hartnack)·도메인 3자 모두 **링 두께 비가격축**. 링 두께 = **수용량 제약(최대 면지 매수 상한)**으로 모델링(가격 아님). 금속 원가 차(수백 원)를 반영하려면 링자재 단가행을 별도로 둘 수 있으나, 경쟁사 정합·단순성상 **비과금 스펙**이 권장. → **제약(constraint) 축**.
- **링 타입 O/D = 비가격 스펙 선택**(수용량/편의 차이).
- **(c) 레더 정액 addon = 채택 안 함**(ASP 임시방편·엔진 BLOCKED). 레더는 (d)의 용지/자재축에 흡수.
- **(a) 크기별 정액 = 폴백.** 경쟁사(레드) 단순형과 정합하고 즉시 "0원 아님" 달성엔 유효하나, 후니 권위가 원하는 레더 프리미엄 분해 표현을 잃음. (d) 실현 전 임시 동작화용.

### 5.3 실현 방식 — §23 동형 전파 (082 패턴), §18 아님
- **082:088 = 072:077.** 088 = 082(하드커버링)에서 **내지 member 제거 + 표지자재를 레더로**.
- 재사용: `PRF_HC_TWINRING_SET`(링 분해 부모공식)·`COMP_BIND_HC_TWINRING`(PROC_000024 링제본 격리)·레더자재(077의 `MAT_000186` 계열)·표지 분해 패턴(`PRF_BOOK_COVER` 또는 TWINRING_SET). **신규 공식 mint 최소화**(search-before-mint).
- 표지 member 분리 필연(완제품 판형 ≠ 표지 단가행 판형 → NO_MATCH, 068/082에서 실증).
- **§18(신규 가격공식 설계)은 불요** — 형제 082/077에서 공식 shape 확보됨. 데이터/배선 gap 닫기(§23 셋트 트랙 + dbmap 적재)가 실질 과업.
- **잔존 BLOCKED(082/077과 동일·C트랙/개발팀)**:
  - cover_mult ×2(링 표지 앞뒤 2장) 저청구 — 엔진 phantom.
  - 레더 프리미엄 정확 델타 — use_dims 확장 필요 시.
  - 면지 유·무료 = **CONFIRM(실무진)**(082=유료 명시 / 077=무료 — 088은 권위 재확인 필요).
- **★[HARD] 라이브 COMMIT 전 webadmin 실화면(가격시뮬레이터) "제외 0·PRICE≠0" 확인 필수**([[harness-domain-rules-12-260701]]).

### 5.4 단가값
- 표지 레더용지 단가·링제본 tier·면지 단가·크기별 값 = **전부 후니 권위(상품마스터 260610·가격표 260527)에서 verbatim** 추출 + 실무진 확인. 본 리서치는 임의 단가 생성 금지. 경쟁사 수치(레드 8,900/A4·Hartnack £187.50)는 **합리성 오라클**일 뿐 후니 정답 아님.
