# 수량·최소주문수량 정합 진단 (260705)

> 사용자 원칙(지니 260705): **인쇄상품 가격표의 처음 시작되는 수량 = 최소주문수량**. 사이즈별로 다를 수 있다.

## 엔진의 수량 처리 (engine.py `match_component` = pricing.py verbatim)

- `min_qty`는 **하한 tier(floor)**: 주문수량 `qty` **이하**의 tier 중 **최대값** 선택(구간 시작).
  후보 없으면(qty < 최소 tier) → **`ERR_BELOW_MIN`**(견적 불가).
- 사이즈(siz_width/height)는 **상한 tier(ceiling)**: 주문 크기 이상의 최소 tier.
- 매칭은 **선택 사이즈에 맞는 단가행 그룹 안에서** 수량 tier를 봄 → 엔진은 사이즈별로 정확히 처리.

∴ **최소주문수량 = 그 단가행 그룹 min_qty tier의 최소값**. 가격표 시작수량이 이 값이어야 한다.

## 진단 결과

### 저청구 메커니즘 = 옵션 comp 시작수량 > 상품 min
- 명함(펄/프리미엄): 완제품가 시작=상품min=100 **일치**이나 **박 가공비 시작=200** → 100~199개+박 = 박 무료.
- 2단접지카드: 박 대형 시작=10 > 상품min=8 → 8~9개+박 = 박 무료.
- → QtyRuleDx TRAP_MIN 8건이 정확히 이걸 잡음(박·후가공 comp band_min > 상품 min).

### 완제품가형(.06) 수량 정합 — `finished_price_minqty.py`
완제품가는 주문 장수 기준이라 사용자 원칙 직접 적용:
- **OK 일치 39**: 명함(100)·포토카드(20)·봉투(1000)·엽서북(2)·떡메(6) — 완제품가 시작=상품min ✓
- **저청구 2**: 미니보드스탠딩·미니배너(상품min=1 < 완제품가시작=4) → 1~3개 주문 시 완제품가 무료.
  교정=상품 min을 4로(권위=완제품가 시작).
- **검토 11(원칙 위반)**: 라벨/택·반칼스티커류·스프링수첩·중철노트(상품min 4~20 > 완제품가시작 1).
  저청구 아님. 완제품가 단가행 시작(1)이 권위 엑셀과 맞는지 대조 필요(반칼은 최소 4~8이 실제일 가능성).

### 미해결 / 백로그
- **원자합산형(엽서·쿠폰)**: 완제품가 없음. 디지털인쇄비는 **판수 기준**이라 장수 min과 차원이 달라
  직접 적용 불가 → 판수↔장수 환산 or 상품규칙 권위로 별도 진단 필요.
- **사이즈별 시작수량 차이**: 현 라이브 0건(모든 사이즈 동일 시작수량). 미래 데이터 대비 감시.
