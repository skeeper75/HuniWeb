1. **필수 공정 자동선택**: 상품이 그룹당 1개만 제공하는 공정그룹(제본류)을 빈 detail로 선택 → 책자 5개 정상.

## 스캐너 사용법
- `python3 gen_scan.py <start> <end>` → /tmp/scan_run.js (슬라이스 임베드)
- browse 세션(admin 로그인)에서 `eval /tmp/scan_run.js` → JSON 결과
- `run_all.sh` 백그라운드 전체 배치 → results/all-v4.jsonl
