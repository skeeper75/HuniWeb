# 전 사슬 정합 검증 프레임워크 + 아크릴 파일럿 (260706)

> 원칙(지니): **상품 → 가격공식 → 가격구성요소 → (구성요소 차원) → 기준정보 마스터**, 그리고 이 전체가
> **인쇄상품가격표 각 시트의 모든 차원**과 정합해야 한다. 진단·검증은 이 사슬 전체·전 차원으로.
> ★grid_diff는 시트당 **한 차원(면적 셀값)만** 봐서 "아크릴 100%"라 했으나, 전 사슬은 다른 차원의 사슬 끊김을
> 드러낸다 — 셀값 대조만으로는 위험하다.

## 1. 검증 링크 (시트 × 차원마다 전 사슬)
| 링크 | 검사 | 끊김 = 결함 |
|---|---|---|
| **L0 시트차원** | 권위 시트가 그 차원+값을 정의 | (기준) |
| **L1 상품** | 그 차원이 적용되는 상품 집합 | 상품 누락 |
| **L2 공식** | 상품→공식 배선(t_prd_product_price_formulas)·죽은공식 아님 | 미배선/죽은공식 |
| **L3 구성요소** | 공식→구성요소(t_prc_formula_components)가 그 차원 담당 | 구성요소 미배선/부재 |
| **L4 차원** | 구성요소 use_dims 선언 + 단가행 충전 | 미선언/미충전(silent) |
| **L5 마스터** | 차원 코드값 → 기준정보 마스터 해결(mat/opt/siz/proc/dsc) | 고아 코드 |
| **L6 값정합** | 셀값이 권위와 verbatim 일치 | 미적재/불일치 |
- **어느 링크든 끊기면 결함**. grid_diff는 L6(그것도 한 차원)만. 전 사슬은 L1~L6 전 차원.

## 3. ★전 사슬이 드러낸 결함 (grid_diff "아크릴 100%"가 놓친 것)
1. **수량할인 7상품 미배선**(L1): 아크릴명찰·뱃지·네임택·스마트톡·맥세이프·코스터·포카키링 — 권위 B04a는
   전 아크릴 적용인데 t_prd_product_discount_tables 미배선 → **대량주문 과청구(돈 크리티컬)**.
2. **키링 고리 후가공옵션 도달불가**(L2): COMP_ACRYL_KEYRING/BALLCHAIN → PRF_ACRYL_KEYRING(**상품0·죽은공식**)에
   갇힘. 라이브 아크릴키링은 PRF_CLR_ACRYL(면적)만 써 **고리옵션 선택 불가**. opt_cd 고아 11도 여기서 발생.
3. **TBD 5상품 견적불가**(L3/L6): PENDING_TBD 0행 → 가격 안 나옴.
4. siz_cd 본체 4개: 마스터 해결 OK, **L6 값 미검증**(카라비너/명찰GS/볼펜/자유형 권위 대조 필요).

→ 면적 차원만 100%였고, **나머지 3차원에 돈·기능 결함이 실재**. "셀값 100%"는 위험한 부분정보였다.

## 4. 확장 (전 19시트)
아크릴 파일럿의 링크 검사를 전 시트에 동형 적용해야 한다(각 시트의 차원 목록×전 사슬). 우선순위:
- 결정론 배치화: 시트별 (차원 인벤토리 → L1~L6 트레이스) 스크립트. grid_diff(L6 면적)에 L1~L5·타 차원 추가.
- 시트별 차원 수 = 아크릴4·포스터사인(면적+소재+옵션)·명함(면/소재/수량/박)·스티커(사이즈/소재/수량/커팅) 등 다차원.
- **[HARD] grid_diff "N% 일치"를 "시트 정합"으로 읽지 말 것** — 그건 한 차원 L6일 뿐. 정합=전 차원 전 사슬 GO.
