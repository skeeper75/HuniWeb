> 실측 오라클 = `contribution_sim_scan.py`(simulate 기반·정적스캔 금지) + 표적 simulate 재현.

## 요약 판정

- **PRICE≠0 = 35/36**(유효 선택·유효 수량). 예외 1 = 형압명함(미출시·미바인딩).
- silent-0 자동스캔 HIGH **11건 → 표적 재현 결과 전부 거짓 결함(FP)**. 진짜 저청구/견적0 = **0**.
- **즉시 COMMIT 필요분 = 0.** (형압명함은 런칭 조건부 후속 1건.)
- freshness: 온톨로지 KB §33의 "디지털36 가격오차0" 검증 상태가 **라이브에 유지됨** 확인.

## B. 형압명함(미출시) — 미바인딩

- 증상: `t_prd_product_price_formulas` 0행 · 자재 0행 → simulate = no-formula(견적불가).
- 돈영향: 견적0(단, **use_yn=N 미출시**라 고객 노출 없음 → 현 손실 0).
- COMMIT 필요분(런칭 조건부·§8 제외 대상): 형압명함 가격공식 바인딩(형압명함 = 형압 완제품가형 → `PRF_NAMECARD_*` 계열 재바인딩 + 자재 적재). 즉시 아님.
- 라우팅: 런칭 결정 시 §18(공식 설계)→§7(적재)·webadmin 실화면.

## C. 봉투제작 — 견적0 오해 정정(FP)

- 자동스캔 qty=100에서 final_price=0으로 나옴 → **미적재 아님**.
- 원인: `COMP_ENV_MAKING` 완제품가 최소수량 밴드 = **1000**. qty<1000이면 밴드 미만 → 0. qty=1000 → **96,000** 정상.
- 봉투제작 수량규칙(min_qty)이 1000 이상으로 강제되면 정합. → 갭 아님(수량규칙 정합 확인 권장).

## D. 미적재/오배선 실측 결과 = 없음

- 종이류 판형 미매핑 0(전 36상품 plate_sizes 보유).
- option_items.ref_dim_cd NULL 0(②차원환원 완결).
- 고아 구성요소·삭제오염 = 이 상품군에서 미검출(직전 §27 배선 round22 잔여는 아크릴 TBD뿐).
- 오적재(표시↔실제 불일치) = 이 상품군 신규 검출 0.
