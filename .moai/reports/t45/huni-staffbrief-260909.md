## 위젯 (라이브)

- 위젯 = 고객이 상품 주문 시 보는 주문서 화면 전체. 임베드 = 스크립트 2줄 + `<huni-widget widget-id site-key>`.
- 라이브 구현 = Web Component + Shadow DOM · 바닐라 JS(프레임워크 무관). React 재구현 트랙은 별개 사내 작업 산출이며 라이브 전환 여부 미확인.
- 게시 모델: 저장(0.6초 자동저장)=초안 ≠ 게시. [게시] 시점 구성 전체가 t_wgt_widget_versions.cfg(jsonb, 불변) 스냅샷, 활성(act_yn=Y) 버전만 서빙, 롤백 지원.
- 고객 여정 5단계: 상품 페이지 양식 → 옵션 선택(불가 조합 즉시 잠금+사유, 순서 무관) → 가격 갱신(약 0.3초, 서버 계산) → 원고(업로드 S3 직접·파일당 500MB 상한 2GB 또는 Edicus 편집) → 장바구니/주문(서버 전체 재검증 + HMAC 서명 토큰 1시간, 원고 30일 보존 초과 시 주문 불성립).
