## 1. 게이트 관점 권고 (근거 有·강제 아님)

### 권고: 옵션 C (독립 빌드 → 검증 후 머지) 우선 — 단, 초기는 B로 시작

게이트가 산출을 재실측한 결과, **초기 B(독립)·최종 A(단일 그래프) 지향의 하이브리드 C**를 권고 기울기로 본다. architect 권고와 일치하며, 게이트가 다음 재실측 근거로 뒷받침한다:

| 근거 | 재실측 사실 | 함의 |
|------|------------|------|
| **§33 안정성 보호** | §33 275노드 골든이 git-clean·H-1 드리프트 2회 실증(MEMORY) | 초기 머지(A)는 안정 자산에 노후(2025-10-14) 와우를 섞을 위험 → **B 격리가 안전** |
| **와우 데이터 노후·GAP** | catalog generatedAt=2025-10-14·templated 6 전량 에러·GAP-PRICE-1~4·optioninfo 경계 불명 | 불확실성을 §35에 가둬야(A는 §33 오염) → **B 격리** |
| **사용자 최종 목표** | "자연어→브랜드무관 추천→가격→주문"은 단일 그래프 교차질의 직결(Q1~Q10 경로가 단일 그래프서 최강) | **최종 A** 지향(조인 오버헤드는 장기 부채) |
| **mint 검증 필요** | DEFECT-M1: E18/E20 mint가 인간 검증 대기 | B로 먼저 실측·안정화 후 A 머지 시점에 mint 정식 등재 → **C의 2단이 mint 검증 창구** |

### 왜 즉시 A(머지) 아닌가
- 와우 catalog 노후분 라이브 재확인·mint(E18/E19/E20) 실물 안정화 전 §33 v1.1 머지는 **되돌리기 비용 큼**(브리프 단점 A 재확인).
- §33 안정성 게이트를 와우 적재마다 통과하는 부담(느림).

### 왜 영구 B(독립) 아닌가
- same_family_as 크로스-그래프 조인은 사용자 목표(교차 추천)에 장기 부채.
- 스키마·lint·빌드 2세트 중복 유지·드리프트 위험(H-1 교훈).
